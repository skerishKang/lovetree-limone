- 파일: `녹화_2026_08_18_00_25_47_646.mp4`

  - Codex 13 리퀴드 글라스 비디오월은 영상 미디어가 표시되지 않음.

## V4 적용

### 반복 타이핑

- `type → 완성 상태 유지 → 빠른 지우기 → 짧은 정지 → 다시 type` 무한 반복
- 입력 속도: 38ms/문자
- 문장부호: 일반 문자보다 약 2.1배 길게 정지
- 완성 유지: 1,850ms
- 지우기: 18ms/문자
- 재시작 대기: 520ms

### 타자기 소리

- 외부 음원 파일을 추가하지 않고 Web Audio API로 기계식 키 클릭을 합성함.
- 입력 글자와 타자음 동기화.
- 지우기에는 더 낮고 작은 클릭음 적용.
- 문장 완성 시 짧은 캐리지 벨 적용.
- 브라우저 자동재생 정책 때문에 첫 화면 클릭/키 입력 또는 `타자음 켜기` 버튼 이후 활성화.
- 사용자가 다시 눌러 끌 수 있음.
