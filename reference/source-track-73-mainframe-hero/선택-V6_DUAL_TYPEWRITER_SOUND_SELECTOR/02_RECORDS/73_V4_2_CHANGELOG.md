# Track 73 V4.2 변경 기록

## 상태
- V4.1 보존
- V4.2 별도 후보 생성

## 사용자 지시 반영
1. 타자기 소리를 두 가지 중 선택 가능하게 구성
2. `타자기소리 1` = 기존 Web Audio 합성형
3. `타자기소리 2` = 사용자 제공 실제 녹음형
4. 실제 녹음형은 다음 두 음원을 결합
   - 입력 키음: `typewriter-key-1.mp3`
   - 문장 완성/줄바꿈음: `typewriter-line-break-1.mp3`
5. 선택 UI: `끄기 / 타자기소리 1 / 타자기소리 2`
6. 선택 즉시 타이핑 루프를 처음부터 재생하여 비교 가능
7. V4.1의 클릭 고정 데스크톱 메뉴 유지

## 구현 방식
- 실제 녹음 음원은 앞뒤 무음만 짧게 정리하고 보수적으로 정규화함.
- 두 실제 음원은 HTML 내부에 base64로 포함됨.
- 따라서 V4.2 HTML 한 파일만 더블클릭해도 `타자기소리 2`가 동작함.
- 외부 CDN이나 별도 오디오 경로에 의존하지 않음.

## 소리 동작
- 타자기소리 1: 기존 합성 키 클릭 + 합성 캐리지 벨 + 지우기 클릭
- 타자기소리 2: 실제 키 타격 녹음 + 실제 줄바꿈/완성 녹음
- 실제 녹음형은 글자를 지우는 구간을 무음 처리하여 실제 타자기 감각을 유지함.
