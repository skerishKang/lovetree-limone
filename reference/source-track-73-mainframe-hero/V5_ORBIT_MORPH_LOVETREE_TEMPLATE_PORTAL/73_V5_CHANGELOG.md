# Track 73 V5 — Orbit Morph LoveTree Poster

## 적용 기준
- 사용자가 제공한 Orbit 포스터 좌표·색상·두 이미지 URL·입장 애니메이션·마우스 모프 트레일을 보존했습니다.
- 제품 문구와 메뉴만 LoveTree에 맞게 교체했습니다.
- 기존 Track 73 V4.2는 수정하지 않았습니다.

## LoveTree 문구
- 거대 워드마크: `LOVETREE`
  - `LOVE`: 흰색
  - `TREE`: 핑크 그라데이션
- 상단 메뉴: `둘러보기 / 내 러브트리 / 이야기 / 가이드`
- 흰색 필: `첫 순간 심기`
- 좌측 카피: `마음이 움직인 순간을, 놓치지 않고 심습니다.`
- 우측 카피: `다음 순간으로 이어진 이유를, 나만의 경로로 남깁니다.`

## 73 템플릿 링크
- 둘러보기: 62, Codex 12-1
- 내 러브트리: 35, 39, 58, Codex 14
- 이야기: 43, 70
- 가이드: Codex 15, 64 첫 순간 심기
- 모든 템플릿은 새 탭으로 열립니다.
- 데스크톱 메뉴는 클릭 고정형이며 바깥 클릭·ESC·다른 메뉴 선택으로 닫힙니다.
- 모바일은 스크림·프로스티드 시트·ESC·Tab trap·closed inert를 적용했습니다.

## 단일 파일
- 실행 파일은 `index.html` 하나입니다.
- 꽃 이미지는 사용자가 지정한 두 Higgsfield URL만 사용합니다.
- 별도 JavaScript·CSS·이미지 파일은 생성하지 않았습니다.

## 확인된 제한
- 사용자가 지시한 원본 `Orbit Sans`, `Orbit Display` base64 TTF가 현재 제공 자료와 File Library 검색에서 발견되지 않았습니다.
- 따라서 동일 family name을 유지하되 로컬 Arial/Helvetica와 Times New Roman/Times에 매핑했습니다.
- 원본 font-face 블록이 제공되면 레이아웃·동작을 건드리지 않고 해당 두 블록만 교체할 수 있습니다.
