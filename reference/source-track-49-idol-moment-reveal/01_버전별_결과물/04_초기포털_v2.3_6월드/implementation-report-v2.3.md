## Cast/source choice

The first V2.3 attempt used darker studio portraits and produced visible rectangular studio-background boundaries. That visual defect was rejected internally before submission.

Final candidate therefore uses three existing LoveTree clean portraits with light studio backgrounds and state-aware blending/linear edge feather. The purpose is to preserve a large natural Hero person without introducing the forbidden oval/portal mask.

## Moment bubble limitation — explicitly disclosed

The four Stage / Smile / Backstage / Walking bubbles are **identity-safe contextual crops/treatments of each cast's canonical portrait source**, not four separately generated action photographs.

Reason: this V2.3 prioritizes 6-state architecture, identity consistency and interaction fidelity. No claim is made that the bubbles are source-distinct performance photography.

If the product owner adopts the V2.3 system and later requests content-production fidelity, the bubble slots can be replaced with approved same-identity performance/candid masters without changing the architecture.
