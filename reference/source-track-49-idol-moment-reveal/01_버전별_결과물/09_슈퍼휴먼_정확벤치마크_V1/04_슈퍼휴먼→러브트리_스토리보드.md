## Color system
- **Black / silver**: memory surface and contrast, not 48 Neon Pilot HUD.
- **Magenta / red / pink**: emotional portal and face-hold intensity.
- **Cyan / electric blue**: movement through the next Moment.
- **Bright white**: a memory becoming clear.
- **Tree finale**: purple + magenta + cyan + champagne-white star light.

## Cast allocation
- CAST A CENTER — S02
- CAST B BLOND — S04

- Group shots use anonymous silhouette choreography so no low-resolution face asset is enlarged and no extra fictional identity is falsely implied.

## Identity / repetition rule
Each full-screen face appears once. The same high-res face assets may recur only as small saved-Moment thumbnails in the finale/experience, where repetition is semantically intentional.
