## 4. 중요한 시행착오

- 이미지 자산이 충분한데도 새 shot 생성을 계속하게 한 지시가 있었다. 이후 `IMAGE GENERATION = STOP`으로 정정했다.
- HTML을 늦추는 방식보다 기존 고화질 자산을 빠르게 편집해 실제 사이트 후보를 만드는 쪽으로 전환했다.
- v1.2 Tree 지시에서 승인 Tree를 “참고해 재구성”하게 한 표현이 문제였다. 결과적으로 procedural stick-tree가 다시 나왔다.
- 이후 v1.3에서 승인 Tree PNG 자체를 **FINAL VISUAL MASTER**로 쓰고 SVG는 보이는 나무가 아니라 light-motion rail로만 쓰도록 정정했다.
- 기술 수치(가지 개수, endpoint 오차)가 시각 승인보다 우선하면 안 된다.
- Standalone에서는 media broken frame이 단 한 프레임도 허용되지 않는다.
