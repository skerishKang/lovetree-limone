# LoveTree 49 / 4-3기 — v1.2 Tree Climax 구조개선지시

**상태:** `SUPERSEDED_BY_14`  
**중요:** 이 문서는 실패 원인을 보존하기 위한 역사 기록이다. 현재 실행 기준으로 사용하지 않는다.

## 당시 목표

v1.1의 Tree가 막대기·추상 선다발처럼 보여 Tree 자체의 시각 완성도가 낮았다. 빛 흐름과 사진 frame glow는 좋았으므로 Tree 실루엣만 개선하려 했다.

당시 요구:

- root → trunk → major branch → sub branch 계층을 읽히게 함
- photo를 branch endpoint/branch junction에 정확히 결착
- cyan/violet/magenta light flow 유지
- 정지 frame만 봐도 아름다운 cyber-organic tree
- 기존 teaser/SAVE/CONNECTION은 수정 금지

## 지시상의 오류

당시 표현 중 “승인 Tree reference를 그대로 평면 복붙하지 말고 HTML/SVG/Canvas에서 motion-capable structure로 재구성”한다는 취지가 들어갔다.

이 문장이 제품 오너의 실제 의도인 **‘승인된 예쁜 Tree 자체를 써라’**를 **‘비슷한 나무를 새로 그려라’**로 바꾸는 결과를 냈다.

그 결과 procedural root/leader/canopy Tree가 다시 만들어졌고, 기술 구조는 좋아졌지만 제품 오너가 승인한 Tree 외형과 달랐다.

## 교훈

- 제품 오너가 특정 Visual Master를 승인하면 그것은 reference가 아니라 asset lock일 수 있다.
- “재구성”, “재해석”, “같은 느낌”이라는 표현은 승인 asset exact-use 단계에서 금지한다.
- 가지 수, endpoint 오차 등 기술 QA는 시각 동일성을 대체하지 못한다.
