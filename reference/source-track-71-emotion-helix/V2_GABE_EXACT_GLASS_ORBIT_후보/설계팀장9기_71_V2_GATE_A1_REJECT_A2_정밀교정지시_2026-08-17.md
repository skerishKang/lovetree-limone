## 0. 총평

이번 A1은 V1과 달리 **참고영상의 레이아웃 방향은 제대로 잡았다.**

다음은 유지한다.

- 좌상단 작은 LoveTree
- 좌중단 설명문
- 좌하단 검정 원형 CTA
- 중앙~우측 초대형 흑백 타이포
- 우측 6개 독립 오브젝트
- LoveTree 키워드 치환
- white editorial background
- blue/orange chromatic accent

그러나 **GATE A의 핵심인 우측 오브젝트 자체가 아직 참고영상과 다르다.**

현재 후보는 `얇은 투명 torus / wire loop / spaghetti coil`처럼 보인다.

참고영상은 `넓은 면적을 가진 두껍고 납작한 liquid-glass / jelly ring / inflated lens`다.

따라서 현재 상태에서 motion/video 기능으로 넘어가지 않는다.

# 1. 가장 중요한 수정 — TORUS GEOMETRY 자체를 바꿔라

현재 HTML의 WebGL geometry는 본질적으로 circular tube 기반 `torus()`다.

이 방식은 아무리 shader를 조정해도
참고영상의 **넓고 평평하며 부풀어 오른 투명 링 표면**이 아니라
`투명 호스 / 와이어 / 튜브`처럼 보이기 쉽다.

## A2에서는 아래로 교체

### 금지
- 원형 tube cross-section torus 그대로 유지
- 얇은 원선 여러 겹
- CSS ellipse outline을 겹쳐 두께를 흉내 내기

### 요구
각 오브젝트를 **broad annular band / flattened inflated loop**로 만들 것.

권장 형태:

1. 바깥 elliptical contour
2. 안쪽 elliptical contour
3. 두 contour 사이에 **충분히 넓은 실제 face surface**
4. front/back 면
5. rounded/beveled inner edge
6. rounded/beveled outer edge
7. 얕은 depth extrusion
8. 부분별 width variation
9. 비대칭 vertex deformation

즉 단면이 `O`형 호스가 아니라
**납작하고 둥글게 부푼 젤리 띠**여야 한다.

---

# 2. 오브젝트 두께/면적을 최소 2~3배 키워라

현재 비교본에서 우측 루프는 선이 많고 면이 적다.

참고영상은 각 ring 하나가 화면에서
**하나의 독립된 투명 덩어리**로 읽힌다.

A2 기준:

- ring 전체 지름은 현재 수준 유지 가능
- 실제 glass band width는 현재보다 최소 2배 이상
- 표면 하이라이트가 `선`이 아니라 `면`에서 보여야 함
- ring 내부와 외부 경계가 모두 두껍게 굴절되어야 함

정지 화면을 25% 축소해도
각 ring이 여전히 하나의 물체로 읽혀야 한다.

---

# 3. 6개가 한 덩어리 코일처럼 보이지 않게 분리

현재 A1은 6개 loop가 너무 연속적으로 겹쳐
하나의 긴 spring/coil처럼 보인다.

참고영상에서는 겹치지만
`Home / Projects / About / Contact`가 붙은 각 오브젝트가
개별 개체로 구분된다.

## A2 배치 수정

- 6개 모두 세로축은 공유
- 그러나 각 ring의 중심 X를 서로 ±3~7vw 정도 엇갈리게
- 각 ring의 Z depth도 다르게
- ring 사이에 일부 white negative space 확보
- 상단 1~2개는 더 크게 겹쳐도 됨
- 중단/하단은 개체 구분이 명확해야 함

**“6개가 한 줄로 이어진 helix”처럼 보이면 FAIL.**

---

# 4. 형태를 더 비대칭·유기적으로 만들어라

현재는 대부분 정돈된 ellipse/torus다.

참고영상은 완벽한 타원이 아니라
눌리고 늘어나고 비틀린 **liquid loop**다.

각 오브젝트마다 다르게:

- 한쪽이 더 두꺼움
- 한쪽이 더 납작함
- inner hole 중심이 outer contour와 약간 어긋남
- 부분적으로 twist
- 앞면이 살짝 접혀 보임
- 일부 edge가 화면 앞쪽으로 튀어나옴

단, 불규칙 노이즈를 많이 넣어 찌그러뜨리는 게 아니라
**매끈한 비대칭**이어야 한다.

---

# 5. 굴절은 “색 테두리”보다 배경 왜곡이 먼저다

A1은 blue/orange edge는 보이지만
참고영상의 핵심인 **뒤의 검정 타이포가 유리 안에서 실제로 휘어지는 느낌**이 약하다.

A2 우선순위:

1. background typography distortion
2. broad white specular highlight
3. dark internal reflection
4. edge Fresnel
5. 마지막에 chromatic split

즉 파랑/주황 선만 세게 보이면 안 된다.

## 요구

링 안쪽/표면을 통해 보이는 `PATH / MOMENT / MEMORY / LOVE` 글자가:

- 확대
- 압축
- 휘어짐
- 좌우 displacement
- 부분 inversion/contrast increase

등으로 실제 렌즈처럼 변형되어야 한다.

가능하면 WebGL에서 scene/background를 offscreen texture로 렌더링하고
glass mesh에서 screen-space refraction을 적용한다.

CSS duplicate typography는 fallback으로만 둔다.

# 6. 중앙 타이포 구조도 A2에서 다시 맞춰라

방향은 맞지만 현재 후보의 `MOMENT / MEMORY` 세로 글자는
서로 너무 촘촘하게 겹쳐 **검정 덩어리**처럼 읽히는 구간이 있다.

참고영상은 글자가 매우 크지만
각 letterform의 구조가 비교적 명확하다.

A2:

- 중앙 글자 사이 horizontal gap 확대
- baseline/column offset을 reference에 맞춤
- glass 뒤에 가려지는 것은 허용
- glass가 없을 때부터 읽을 수 없는 수준의 중첩은 금지
- `PATH` 상단 crop은 유지 가능하나 reference crop 비율과 맞출 것
- 화면 오른쪽의 추가 단어는 reference처럼 일부만 crop되도록 조정

# 8. 키워드 배치

키워드 방향은 맞다.

다만 현재는 일부가 loop 위에 “텍스트 레이어”로 떠 있는 느낌이다.

A2에서는:

- 글자가 오브젝트 표면 curve를 따라 약간 휘거나
- perspective/rotation이 mesh orientation을 따라가게 하고
- 일부는 glass에 의해 살짝 굴절/가려짐

이 필요하다.

목표:

`label on top of glass`가 아니라  
**`text printed/embedded on the liquid object`**.

# 11. A2 PASS 기준

아래를 모두 만족해야 GATE B로 간다.

### 1. Object Read
25% 축소해서 봐도
각 오브젝트가 `얇은 선`이 아니라 **두꺼운 투명 젤리 링**으로 읽힌다.

### 2. Separation
6개가 하나의 spring/helix가 아니라
**6개의 독립 오브젝트 군집**으로 읽힌다.

### 3. Material
파랑/주황 테두리보다
**투명·굴절·specular·배경왜곡**이 먼저 느껴진다.

### 4. Typography
거대 흑백 타이포가 reference와 비슷한 밀도/위계로 배치되고
glass 뒤에서 실제로 왜곡된다.

### 5. Left Editorial Block
좌상단 logo / 좌중단 copy / 좌하단 CTA가
reference의 위치·크기·무게에 충분히 가깝다.

### 6. Overall Recognition
두 화면을 나란히 봤을 때
“같은 디자인을 LoveTree 내용으로 바꿨다”는 인상이 먼저 와야 한다.
