## 3. V1이 실패한 이유

현재 V1은 다음 이유로 REJECT다.

1. 중앙에 거대한 **검정 리본 Helix**가 화면을 지배한다.
2. 참고영상의 핵심인 **투명한 유리/젤리 원형 오브젝트**가 없다.
3. 원본은 좌측 정보영역 + 중앙 거대 타이포 + 우측 오브젝트 군집인데,
   V1은 중앙 조형물 중심의 전혀 다른 레이아웃이다.
4. 원본의 흑백 고대비 편집 타이포가 사라졌다.
5. 원본의 투명 재질 가장자리에 나타나는
   **굴절 / 하이라이트 / 크로마틱 색 번짐**이 없다.
6. 원본의 오브젝트는 여러 개의 개별 투명 링/렌즈가 겹쳐 떠다니는데,
   V1은 하나의 연속 검정 구조물이다.
7. LoveTree 내용을 넣는 과정에서 원본 조형 자체를 바꾸었다.

따라서 V1 코드를 계속 다듬지 말고 V2를 별도 제작한다.

## 4. 화면 레이아웃 — 참고영상과 최대한 동일하게

이번 V2의 첫 화면 구조는 아래를 고정한다.

### 4-1. 전체 화면

- 16:9 데스크톱 우선
- 기본 배경: **순백 또는 거의 순백**
- 전체 인상: 흑백 편집 디자인 + 고광택 투명 오브젝트
- 여백을 과도하게 LoveTree식 크림/감성 디자인으로 바꾸지 말 것

### 4-2. 좌측 상단

참고영상의 `GABE` 위치에:

**LoveTree 로고 / 워드마크**

를 작게 배치한다.

- 좌측 상단 모서리에 가깝게
- 화면을 지배하지 않을 것
- 참고영상과 비슷한 시각적 무게 유지

### 4-3. 좌측 중간

참고영상의 소개문 위치와 비슷하게
LoveTree 설명을 **짧고 굵은 산세리프 문장**으로 배치한다.

예시 방향:

`Moments that moved your heart,`
`connected into the path`
`that made you a fan.`

또는 한국어 3~4줄.

중요:
- 제목형 대문구로 키우지 말 것
- V1의 `Follow what made you care.`처럼 지나치게 커지지 말 것
- 참고영상처럼 **설명 블록**으로 보일 것

### 4-4. 좌측 하단

참고영상의 검정 원형 `Book a call` 버튼 위치에
검정 원형 CTA 1개를 둔다.

후보:
- `MENU`
- `OPEN TREE`
- `EXPLORE`
- `MY TREE`

가장 단순한 1개만 사용한다.

### 4-5. 중앙 대형 타이포

참고영상에서 `DESIGNER` 등 초대형 글자가
세로/가로로 화면 뒤에 겹쳐 있는 구조를 그대로 가져온다.

LoveTree 치환 후보:

- `MOMENT`
- `MEMORY`
- `CONNECTION`
- `PATH`
- `LOVE`
- `TREE`

대형 문자는 단순 배경 장식이 아니다.
우측 투명 오브젝트 **뒤/사이로 가려지고 굴절되어야 한다.**

### 4-6. 우측 핵심 영역

화면 오른쪽 절반은
**5~7개의 투명하고 매끄러운 젤리/유리 오브젝트**가 겹쳐 떠다니는 구조로 만든다.

중요:

> 단일 Helix 금지.  
> 검정 리본 금지.  
> 직사각형 카드 금지.  
> 구체 하나 금지.

각 오브젝트는 서로 분리된
**투명 lens / ring / inflated loop / jelly button**처럼 보여야 한다.

## 5. 투명 젤리 오브젝트 재질 — 이번 작업의 최우선

이번 V2의 성공 여부는 이 재질에서 결정한다.

### 필수 시각 특성

- 투명
- 매우 매끄러운 표면
- 두께가 있는 glass/jelly
- 둥글고 부풀어 오른 edge
- 강한 specular highlight
- 내부 배경 글자가 굴절되어 보임
- 가장자리에서 약한 rainbow / chromatic aberration
  - blue
  - orange/yellow
  - 미세한 red
- 유리 가장자리의 검정 또는 짙은 윤곽 반사
- 완전히 투명한 플라스틱이 아니라
  **말랑하고 고급스러운 liquid glass / jelly lens** 느낌

### 금지

- 단순 `opacity: 0.3` 원
- CSS blur만 쓴 유리 카드
- 평평한 원형 div
- 검정색 리본에 반사광만 넣기
- 금속 torus
- 일반 투명 구체

실제 3D mesh + shader/WebGL 구현을 우선한다.

## 6. 오브젝트 형태

참고영상과 마찬가지로
각 오브젝트는 완전한 정원보다는 약간 찌그러지고 비틀린 형태가 좋다.

예:

- 납작한 투명 ring
- 늘어난 donut
- 투명한 inflated loop
- 둥근 lens
- 비대칭 jelly ring

각각 약간 다른 Z 회전과 기울기를 가진다.

### 권장 배치

우측 세로축을 따라 약 5~7개를 겹친다.

위 → 아래 예시:

1. `FIRST MOMENT`
2. `MOMENTS`
3. `CONNECTION`
4. `REPLAY`
5. `MY TREE`
6. `RETURN`

원본의 `Home / Projects / About / Contact`처럼
**검정 키워드가 투명 물체의 표면 또는 내부를 따라 움직이는 느낌**을 만든다.

## 7. 영상 적용 방식

사용자가 말한 두 방식을 모두 검토하되,
V2 기본안은 아래 방식으로 한다.

### 기본안 — Video Under Glass

투명 젤리 오브젝트 아래/안쪽에
실제 Moment 영상 또는 poster를 배치한다.

구조:

`video/poster plane`
→ 그 위에
`transparent refractive jelly shell`
→ 그 위 또는 내부에
`LoveTree keyword`

즉 영상 자체가 평범한 직사각형 카드로 보이지 않고
**투명한 젤리 렌즈 안에서 보이는 움직이는 기억**처럼 보여야 한다.

### 일부 오브젝트는 Pure Glass Keyword 사용 가능

모든 오브젝트에 영상을 억지로 넣지 않는다.

예:
- 3~4개는 video-under-glass
- 2~3개는 투명 keyword object

이렇게 섞어도 된다.

## 14. V2 PASS 기준

### PASS

정지 화면을 처음 본 사람이
참고영상과 나란히 놓았을 때

> “LoveTree 내용으로 바꾼 같은 계열 화면이다”

라고 알아볼 수 있어야 한다.

### FAIL

아래 중 하나면 즉시 FAIL:

1. 검정 Helix가 다시 등장
2. 카드 캐러셀처럼 보임
3. Sphere/Globe로 바뀜
4. 투명 오브젝트가 평평한 CSS 원처럼 보임
5. 좌측 소개 영역이 참고영상과 완전히 다른 비율
6. 중앙 대형 타이포가 없음
7. 우측 오브젝트가 1~2개뿐임
8. 투명 오브젝트가 영상보다 장식에 그침
9. 참고영상보다 LoveTree 자체 해석을 우선함
10. 정지 화면 단계에서 reference resemblance가 약한데 기능부터 추가함
