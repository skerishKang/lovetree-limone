## 3. 이번 작업의 핵심 목표

이번 V1의 목표는 단순히 “예쁜 3D 오브젝트”를 만드는 것이 아니다.

정확한 목표는 다음이다.

> **LoveTree에서 사용자가 사랑에 빠져온 여러 Moment와 감정 Connection이 하나의 살아 있는 3D 구조물처럼 보이는 인터랙티브 대문을 만든다.**

즉,

- Moment가 그냥 카드로 진열되면 안 되고
- 단순 영상 썸네일 월이어도 안 되며
- 단순 구체/행성형 3D여도 부족하고
- 단순 인물 중심 히어로도 안 된다.

이번 V1은 반드시 아래 두 축을 동시에 만족해야 한다.

### 축 A — 첫 번째 참고영상의 강점
- 연속된 3D 조형물
- 텍스트와 이미지가 구조물 표면에 붙어 있는 느낌
- 화이트/블랙 전환
- 페이지가 아니라 **하나의 세계가 상태를 바꾸는 느낌**

### 축 B — 두 번째 참고영상의 강점
- 장면 위계
- 시네마틱 몰입
- 선택된 대상이 통째로 강조되는 연출
- 단순 모달이 아니라 **장면 전환 자체가 경험이 되는 방식**

## 5. 최종 콘셉트

### 5-1. 콘셉트 문장

**Living Emotion Path Helix**

사용자가 좋아하게 된 순간들이 독립 카드로 분리되지 않고,  
감정의 인과관계를 따라 **하나의 헬릭스/리본 구조물**로 이어진다.

### 5-2. 사용자가 처음 느껴야 할 인상

사용자가 첫 화면을 보자마자 느껴야 할 건 이것이다.

- “아, 카드가 떠 있네”가 아니라
- “이건 감정 경로가 살아 있는 조각처럼 떠 있네”여야 한다.

즉 첫 인상 기준은:

#### 실패 인상
- 카드 갤러리
- 썸네일 월
- 회전 캐러셀
- 구체 안에 포스터들

#### 성공 인상
- 하나의 거대한 메모리 조형물
- 리본/띠/헬릭스/루프가 살아 움직이는 느낌
- 그 표면에 순간, 날짜, 감정, 짧은 문장이 실제로 붙어 있는 느낌

## 6. 화면 구조 지시

### 6-1. 기본 화면 구성

초기 화면은 아래 구성으로 설계한다.

#### 배경
- 첫 화면 기본 배경은 **밝은 ivory / warm white**
- 필요 시 선택 순간에 **black mode / dark inversion**으로 전환 가능

#### 좌측
- LoveTree 로고 또는 워드마크
- 한 줄 카피
- 아주 짧은 설명
- 필요 시 현재 경로/현재 Moment 번호

#### 중앙~우측
- 핵심 구조물인 **Memory Helix**
- 화면의 시선 70% 이상을 이 구조물이 가져가야 함

#### 배경 타이포
- 초대형 글자 허용
- 다만 장식이 아니라 구조물과 깊이 관계를 만들어야 함
- 예: `MOMENT`, `CONNECTION`, `PATH`, `LOVE`, `MEMORY`

### 6-2. 구조물 형태 지시

Memory Helix는 다음 조건을 만족해야 한다.

1. **8~12개 정도의 리본/띠/플레이트**가 하나의 연속 구조를 이룰 것
2. 각 요소는 서로 독립 카드처럼 보이기보다 **연결 구조**처럼 보여야 함
3. 표면은 곡면 또는 휘어진 평면처럼 보여야 함
4. 구조물 자체가 세로로 서 있거나 약간 비틀린 **totem / helix / ribbon tower** 느낌이어야 함
5. 앞뒤 깊이, 겹침, 회전이 분명히 느껴져야 함

## 7. 꼭 들어가야 할 콘텐츠 문법

이번 작업은 단순 시각 효과보다 **LoveTree 데이터 문법**을 표현해야 한다.

각 구조 요소에는 아래 정보가 들어가야 한다.

### 7-1. Moment 정보

각 Moment 표면에 일부 또는 전부를 배치한다.

- Moment 번호
- 날짜 또는 시퀀스 번호
- 대표 이미지 또는 대표 영상 프레임
- 짧은 감정 키워드
- 한 줄 설명

예시:

- `01 FIRST LOOK`
- `설렘`
- `처음 표정이 계속 생각났다`
- `2026.08.04`

### 7-2. Connection 정보

A에서 B로 넘어간 이유가 반드시 보이게 할 것.

예시:

- `그 표정이 계속 생각나서`
- `다른 무대를 찾아봤다`
- `리액션을 보다 더 좋아졌다`
- `무심한 장면이 오히려 결정적이었다`

LoveTree의 핵심은 **콘텐츠 목록**이 아니라 **감정의 인과 경로**이므로,  
이 문장이 화면에 드러나지 않으면 이번 작업의 철학적 핵심을 놓친 것이다.

## 8. 인터랙션 지시

### 8-1. 기본 인터랙션

필수:

1. **드래그**
   - 사용자가 구조물 전체를 회전·탐색
   - 앞뒤 깊이 이동감이 보여야 함

2. **휠 또는 스크롤**
   - 구조물의 특정 section을 더 앞으로 가져오거나
   - 현재 선택 Moment를 진행시키는 방식 허용

3. **Hover / Focus**
   - 현재 가장 앞에 온 Moment 또는 사용자가 건드린 Connection이 강조되어야 함

4. **선택**
   - 선택된 Moment는 구조물 내에서 명확히 앞으로 나와야 함

### 8-2. 가장 중요한 전환 인터랙션

선택한 Moment를 열 때 일반 모달처럼 단순 fade로 띄우지 말 것.

반드시 다음과 같이 설계할 것.

#### 권장 방식
- 선택된 리본/띠가 앞으로 회전
- 곡면이 점점 펴짐
- 좁은 구조물이 넓은 화면처럼 펼쳐짐
- 그 결과 **Moment 상세 뷰 / 영상 재생 뷰**로 이어짐
- 나머지 구조는 뒤로 물러나거나 사라짐
- 배경은 필요 시 밝은 화면 → 어두운 감상 모드로 전환

즉,

`Helix 구조물 → 선택 리본 분리 → 펼쳐짐 → 상세 순간 감상`

이 흐름이 되어야 한다.

### 8-3. 복귀 인터랙션

- `ESC`
- 닫기 버튼
- 뒤로 가기 UI

중 하나 이상으로 복귀 가능해야 하며,

복귀 시에는

`상세 뷰 → 다시 구조물로 접힘`

느낌이 살아야 한다.

## 10. 기술 구현 지시

### 10-1. 권장 기술 스택

이번 Track은 가능하면 다음 우선순위로 구현한다.

#### 1순위
- **Three.js / WebGL 기반**
- 리본/곡면/헬릭스 구조를 실제 3D mesh처럼 다루기 위함

#### 2순위
- 불가피할 경우 CSS 3D 보조 사용 가능
- 단, 이번 작업은 **단순 카드 rotateY 구조로 끝내면 안 된다**

### 10-2. 구현 원칙

1. **외부 CDN 금지**
2. 로컬 파일로만 실행 가능해야 함
3. 초기에 모든 영상을 동시에 재생하지 말 것
4. 첫 화면은 poster texture 중심
5. 선택된 1~2개 Moment만 video 재생 허용
6. 성능 우선. 저사양에서도 기본 인터랙션이 깨지면 안 됨

### 10-3. 자산 운영 원칙

- 모든 89개를 동시에 heavy texture로 올리지 말 것
- 우선 **대표 Moment 6~12개 정도를 V1의 hero helix용 핵심 세트**로 사용
- 나머지는 Index나 상세 보기에서 접근 가능하게 설계 가능
- 큰 구조물 표면에는 실제 이미지뿐 아니라 텍스트 텍스처도 적극 사용

## 13. V1에서 반드시 보여줘야 할 것

V1은 완전한 최종 제품이 아니어도 된다. 하지만 아래는 반드시 보여줘야 한다.

### 필수 시연 범위

1. **첫 화면 Hero Helix**
   - 구조물이 실제로 인상적으로 보일 것

2. **드래그 탐색**
   - 전체 구조를 돌릴 수 있을 것

3. **최소 6개 이상의 Moment**
   - 서로 다른 이미지/영상/텍스트가 구조물에 반영될 것

4. **Connection 표현**
   - 최소 3개 이상의 감정 연결 문장이 보여야 함

5. **선택 전환**
   - 선택한 Moment가 상세 감상 상태로 넘어갈 것

6. **복귀**
   - 다시 구조물 상태로 복귀 가능할 것

7. **보조 Index**
   - 전체 Moment에 접근하는 서브 구조 최소 1개 있을 것

## 15. PASS / FAIL 기준

### PASS 기준

아래 4개를 모두 만족하면 1차 PASS다.

#### PASS 1. 정지 화면 품질
정지 화면 1장만 봐도
- 카드 나열이 아니라
- **연속된 메모리 조형물**로 보여야 한다.

#### PASS 2. 움직임 품질
드래그/회전 시
- 요소가 따로 노는 것이 아니라
- **하나의 구조가 같이 반응하는 느낌**이어야 한다.

#### PASS 3. LoveTree 문법
Moment와 Connection이 읽혀야 한다.
- 단순 포스터/썸네일 집합이면 FAIL
- 감정 경로가 드러나야 PASS

#### PASS 4. 상세 진입 연출
선택 후 상세 감상으로 갈 때
- 단순 모달보다 한 단계 높은
- **구조물이 풀리거나 전개되는 전환감**이 있어야 한다.

### 즉시 FAIL 기준

아래 중 하나라도 해당하면 FAIL이다.

1. 첫 인상이 card carousel이다
2. 사실상 14번의 카드 구조 확장판이다
3. 사실상 13번의 video wall 변형판이다
4. 구조물보다 UI 패널이 더 눈에 띈다
5. Connection이 읽히지 않는다
6. 선택 전환이 그냥 modal popup이다
7. 3D가 약해 2D 레이아웃처럼 보인다
8. LoveTree가 아니라 generic portfolio처럼 보인다

## 17. 마지막 지시

이번 작업에서 가장 중요한 건 “멋있어 보이는 것” 자체가 아니다.

**LoveTree의 순간과 감정 경로가 시각적으로 하나의 조형물로 살아나야 한다.**

다시 말해 이번 16번은

- 12의 연구를 반복하는 것도 아니고
- 13의 대량 목록을 더 화려하게 만드는 것도 아니며
- 14의 카드 스택을 더 비틀어보는 것도 아니고
- 15의 히어로를 더 감각적으로 다듬는 것도 아니다.

이번 16번은 이 모든 연구를 통합해

> **“Moment가 감정 Connection에 의해 연결되어 하나의 살아 있는 Memory Helix가 되는 LoveTree 대문”**

을 만드는 작업이다.

**이 핵심을 놓치면 실패다.**
