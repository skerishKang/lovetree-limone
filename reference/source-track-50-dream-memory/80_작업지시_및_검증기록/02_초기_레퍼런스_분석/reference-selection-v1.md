## 리듬 관찰

간이 장면전환 검출(동일 기준)에서 대표 영상의 전환 밀도는 크게 달랐다. `It’s Me`와 `Drunk-Dazed`는 비교적 긴 hold가 두드러졌고, `ASAP`과 `How Sweet`는 더 조밀한 기억 파편이 많았다. 따라서 DREAM MEMORY V1은 동일 길이 컷 반복을 피하고 **짧은 기억 파편 ↔ 2~3초 숨**을 교차한다.

## 선택 결론

- **주 문법:** NewJeans — 기억/자연광/handheld/빛·물·바람
- **Save UX:** ILLIT — 작은 사물/종이/방/촉각적 저장
- **감정 무게:** ENHYPEN — 얼굴 hold/세부/기다림→충격
- **보조만:** aespa surreal shock 1회 이하, NMIXX 공간 왜곡 개념, CORTIS는 6~15초 파생본 우선
- **배제:** NCT의 HUD/Neon/Cockpit/Radar는 4-1기 영역이며 V1에서 사용하지 않는다.
