- 상태: **기존 V1 및 캐스트 전략 보존 / 실사용 자산 생성 단계 진입**

# 0. 현재 제출물 판정

현재 제출한 두 장의:

- 신규 K-pop 캐스트 전략 보드
- Cast Structure / Scene Slot Map / New Image Request List 보드

는 **기획·캐스팅·슬롯 설계 자료로는 승인**한다.

그러나 이 두 이미지는:

> **HTML에 직접 삽입할 최종 원본 사진 자산이 아니다.**

텍스트, 표, 라벨, 여러 사진 타일이 하나의 큰 보드에 합쳐져 있기 때문이다.

따라서 이 보드는 삭제하지 않고 분석/검토자료로 보존하고,
이제 동일한 캐스트 전략을 바탕으로 **실사용 개별 사진 원본**을 생성한다.

# 1. 기존 작업은 절대 초기화하지 않는다

현재까지 완료한 다음 작업은 유지한다.

- Pinterest Moodboard 해석
- Main / Secondary / Group Cast 전략
- 10 Scene Slot Map
- 신규 이미지 요청목록
- 기존 Dream Memory V1 HTML
- Save / Connection / Tree 구조
- Desktop / Mobile architecture

이번 3차 지시는 다시 설계하라는 명령이 아니다.

> **현재 전략을 실제 이미지 파일로 구현하는 Gate**

다.

# 2. 첫 번째 생성 Batch는 여성 8컷으로 진행 승인

4-2기가 제안한 첫 Batch:

- F-A 동일 인물 2컷
- F-B 동일 인물 2컷
- F-C 1컷
- F-D 1컷
- 여성 2인 관계컷 1컷
- 여성 활동/보조컷 1컷

총 **8컷**

으로 진행한다.

이 Batch가 승인되기 전에는 남성/그룹/환경 자산을 한꺼번에 대량 생성하지 않는다.

# 3. 가장 중요한 생성 규칙 — “한 파일 = 한 사진”

다음 형식은 금지한다.

- contact sheet
- moodboard
- storyboard
- 여러 사진이 붙은 grid
- 텍스트 설명이 들어간 board
- 표
- 라벨
- ID가 화면 안에 적힌 이미지
- before/after panel
- 포스터 레이아웃

각 생성 결과는 반드시:

> **사진 한 장만 존재하는 독립 이미지 파일**

이어야 한다.

예:

```text
F_MC01_first-moment_v1.png
F_MC01_person-reveal_v1.png
F_MC02_save-moment_v1.png
F_MC02_memory-field_v1.png
F_SC01_portrait_v1.png
F_SC02_activity_v1.png
F_PAIR01_connection_v1.png
F_AMBIENT_CAST01_v1.png
```

이미지 안에 파일명/ID/설명/로고를 넣지 않는다.

# 4. Main Cast 동일성 규칙

## F-MC01
동일 여성 인물로 최소 2개 Scene을 만든다.

예:
- First Moment
- Person Reveal

얼굴, 눈, 코, 입, 헤어라인, 전체 인상은 같은 사람으로 읽혀야 한다.

단:
- 표정
- 카메라 각도
- 빛
- 배경
- 행동

은 달라야 한다.

즉 “같은 사진을 약간 변형”하는 방식이 아니라:

> **같은 아이돌의 서로 다른 순간**

이어야 한다.

## F-MC02
동일하게 2개 Scene 이상 유지.

Main Cast 두 명이 서로 닮아 보이면 FAIL.

# 5. Secondary Cast 차별화

F-SC01 / F-SC02 등 보조 캐스트는 Main Cast와 확실히 구분되어야 한다.

차별화 요소:
- 얼굴형
- 눈매
- 헤어 길이/질감
- 헤어 컬러
- 스타일링
- 분위기
- 표정

단순히 머리색만 바꾼 같은 AI 얼굴처럼 보이면 반려한다.

# 6. Pinterest Reference 사용 기준

사용자가 제공한 Pinterest 여성 아이돌 / 여성 전신 / 혼합 무드보드는 다음 요소만 참고한다.

- 실제 K-pop스럽게 보이는 얼굴 비율
- 헤어
- 메이크업 강도
- 전신 비율
- 무대복 / 사복
- 자연스러운 활동 포즈
- 사진의 거리와 구도

특정 실제 아이돌 한 명의 얼굴을 그대로 복제하지 않는다.

목표는:

> **실존하지 않지만 실제 K-pop 그룹에 있을 법한 새로운 캐스트**

다.

# 7. 여성 Batch 8컷 상세 기준

## 7-1. F-MC01 / First Moment
- close-up 또는 medium close-up
- 자연광
- candid
- 카메라를 꼭 정면으로 보지 않아도 됨
- 첫눈에 저장하고 싶은 순간
- 배경: 창가 / 공연장 외곽 / 이동 중 / 대기 공간
- 과한 화보 포즈 금지

## 7-2. F-MC01 / Person Reveal
- 동일 인물
- 3/4 또는 profile 가능
- 머리카락 움직임 / 빛 / 시선 변화
- 첫 컷과 확실히 다른 Moment

## 7-3. F-MC02 / Save Moment
- 자연스러운 close/half
- 미소 또는 조용한 표정
- 밝고 친밀한 분위기
- skin retouch 과도 금지

## 7-4. F-MC02 / Memory Field
- 동일 인물
- full 또는 half-body
- 걷기 / 무대 밖 / 거리 / 창가 등
- 첫 컷과 다른 공간

## 7-5. F-SC01
- Main Cast와 얼굴 차별화
- half/full 중 하나
- Dream Memory의 다른 감정 결

## 7-6. F-SC02
- Main/SC01 모두와 구분
- 활동감 있는 순간
- performance / rehearsal / street / 이동 중 가능

## 7-7. F-PAIR01
- 여성 2인
- 어깨를 붙이고 카메라 보는 단체 프로필 금지
- 서로 바라봄 / 웃음 / 걷기 / 대화 / 함께 무언가 보는 관계 순간
- 관계가 느껴져야 함

## 7-8. F-AMBIENT_CAST01
- 인물이 장면 전체를 지배하지 않음
- backstage / stage edge / street / train / room
- 환경과 함께 기억되는 인물

# 8. 해상도 및 비율

원본 생성:

```text
최소 긴 변 2048px
권장 2560px 이상
```

Scene용 Hero/환경 결합 컷:
```text
16:9 권장
```

Portrait 재활용 가능 컷:
```text
4:5 또는 3:4 허용
```

원본을 작게 생성한 뒤 HTML에서 크게 확대하지 않는다.

# 9. 사진적 품질 기준

PASS:
- 자연스러운 피부
- 실제 카메라 렌즈 같은 depth
- 머리카락의 세부 질감
- 손/팔/다리 해부학 정상
- 실제 의상 소재감
- 빛 방향 일관
- 배경 원근 자연스러움
- K-pop 활동사진/티저 스틸처럼 보임

FAIL:
- 플라스틱 피부
- AI 특유의 과도한 피부 광택
- 얼굴 비대칭 오류
- 손가락 오류
- 비정상적으로 긴 다리
- 목/어깨 연결 이상
- 옷 장식이 녹아내림
- 귀걸이/마이크가 얼굴에 융합
- 배경 글자 오류
- 워터마크
- text/logo
- 특정 신체부위의 불필요한 성적 강조

# 10. 첫 Batch 생성 후 즉시 HTML에 넣지 않는다

여성 8컷 생성 후 먼저 다음 자료를 만든다.

```text
female-batch01-review-v1.jpg
female-batch01-manifest-v1.md
```

Review Board는 검토용으로만 만들 수 있다.

중요:
- 원본 8개 파일은 개별 보존
- review board만 별도로 생성
- board를 원본 대신 사용 금지

검수 항목:
- identity consistency
- cast differentiation
- K-pop plausibility
- anatomy
- skin
- lighting
- scene suitability

# 11. 8컷 중 품질 미달은 전부 다시 만들지 않는다

예:
8개 중 6개 PASS, 2개 FAIL이면

> FAIL 2개만 재생성

한다.

PASS 파일을 이유 없이 다시 생성하지 않는다.

# 16. 최종 중요 원칙

지금 만든 캐스트 전략 보드는 잘못 만든 것이 아니다.

> **전략보드로는 유효하다.**

잘못된 것은 그것을 HTML용 “사진 자산”으로 간주하는 것이다.

따라서:

```text
전략 보드 보존
→ 개별 Raw Photo 생성
→ Batch 검수
→ 부족분만 재생성
→ Web 최적화
→ V1.1 적용
```

순서로 진행한다.
