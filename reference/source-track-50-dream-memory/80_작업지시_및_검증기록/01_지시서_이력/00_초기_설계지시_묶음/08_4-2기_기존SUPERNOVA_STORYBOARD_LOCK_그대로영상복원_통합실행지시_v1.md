# 5. Storyboard의 "Moment"를 다른 얼굴 쇼릴로 바꾸지 않는다

여러 cast가 있더라도:

```text
A 얼굴
→ B 얼굴
→ C 얼굴
→ D 얼굴
```

만 빠르게 넘기는 식으로 구현하지 않는다.

기존 Storyboard가 보여주는 핵심은 **서로 다른 Moment Scene**이다.

예:

- stage
- interview
- backstage
- walking
- smile
- hand/detail
- live
- photo

즉:

> **사람 얼굴 수가 아니라 장면과 순간의 차이**가 보여야 한다.

# 6. LoveTree 의미는 기존 Storyboard대로 유지

이번 50번은 아래 흐름을 유지한다.

```text
FIRST MOMENT
→ MEMORY DISTORTION
→ NEW WORLD OPENS
→ EMOTION INTENSIFIES
→ MOMENT BECOMES CLEARER
→ STAGE / INTERVIEW / BACKSTAGE / DETAIL
→ RECORD / SAVE
→ LIGHT CONNECTION
→ MOMENTS GATHER
→ TREE BEGINS TO BLOOM
→ LOVETREE
```

Connection은 장식이 아니라:

> **한 Moment 때문에 다음 Moment로 계속 이어지는 감정의 길**

로 보이게 한다.

Tree는 마지막에 갑자기 뜨는 별도 PNG가 아니라
앞의 light / path / gathered moments가 수렴해 자라는 구조로 구현한다.

# 9. STEP 1 — Storyboard Scene Master 복원

기존 Storyboard 각 shot을 16:9 고해상도 scene으로 복원한다.

### 반드시 사용

- 해당 storyboard frame
- 해당 cast의 기존 identity asset
- 동일 camera distance
- 동일 lighting
- 동일 environment
- 동일 color family
- 동일 emotional read

### 금지

- text prompt만 보고 새로 생성
- 얼굴 교체
- 의상 교체
- 장소 교체
- shot composition 재설계

### 최소 해상도

```text
1920×1080 이상
```

저화질 확대 금지.

---

# 10. STEP 2 — Storyboard ↔ Scene Master 비교 Gate

각 shot마다:

```text
LEFT  = 기존 승인 Storyboard
RIGHT = 새 Scene Master
```

로 나란히 비교한다.

각 shot에서 아래 7개를 판정한다.

| 항목 | PASS / REVISION / FAIL |
|---|---|
| Cast / Identity | |
| Composition | |
| Camera Distance | |
| Lighting | |
| Color | |
| Environment | |
| Emotional Read | |

### 규칙

2개 이상 REVISION/FAIL이면 다시 만든다.

---

# 11. STEP 3 — Shot Motion Clip

Scene Master가 통과한 shot만 영상 clip으로 만든다.

권장:

```text
1920×1080 이상
30fps 이상
가능하면 60fps master
```

### Motion은 다음을 사용

- subject micro-motion
- eye/head movement
- hair/clothing movement
- camera push/pull
- parallax
- walking
- hand movement
- mic/performance movement
- environmental light change
- lens distortion movement
- foreground pass
- depth
- transition motion

### 금지

- 사진 한 장 `scale()`만 사용
- `translateX/Y()`만 사용
- opacity fade만 사용
- portrait card가 떠다님
- 얼굴 cutout collage

# 15. 바로 Full HTML을 만들지 않는다

## PHASE A — SCENE MASTER PACK

먼저 모든 핵심 scene master 제출.

## PHASE B — EXACT TIMING ANIMATIC

정지 scene master를 실제 timing으로 이어 붙인 animatic 제출.

## PHASE C — MOTION PROOF

가장 중요한 10~12초 구간만 실제 motion으로 제출.

권장 구간:

```text
FIRST MOMENT
→ DISTORTION
→ CITY / NEW WORLD
→ PINK INTENSITY
→ WHITE REVEAL
→ RAPID MOMENTS
```

또는 기존 storyboard가 가장 강한 구간.

## PHASE D — FULL CINEMATIC

Motion Proof PASS 후에만 전체 영상 제작.

## PHASE E — HTML

Final cinematic 영상 승인 후에만 HTML wrapper 제작.

HTML에서 storyboard를 수정하지 않는다.

→ branches expand
