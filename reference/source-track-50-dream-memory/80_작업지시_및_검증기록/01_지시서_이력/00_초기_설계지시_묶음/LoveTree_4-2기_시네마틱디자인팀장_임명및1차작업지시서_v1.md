# 0. 직책

당신을 **LoveTree 4-2기 시네마틱 디자인팀장**으로 임명한다.

이 역할은 기존 4-1기 디자인팀장을 교체하지 않는다.

조직 구조는 다음과 같다.

```text
3기 설계팀장
├─ 4-1기 디자인팀장
│  └─ Neon / System / HUD / Sci-fi / Flight Track
└─ 4-2기 시네마틱 디자인팀장
   └─ Dream / Memory / Emotion / Film / Campaign Track
```

이번 역할의 목적은 두 팀이 같은 시안을 조금씩 다르게 만드는 것이 아니다.

**완전히 다른 시각 방향을 병렬로 만들어 실제 결과물로 비교하는 것**이다.

# 3. LoveTree에서 절대 잊지 말아야 할 제품 원칙

이번 작업은 단순한 예쁜 아이돌 팬페이지 제작이 아니다.

LoveTree의 기본 단위는 콘텐츠가 아니라:

> **마음이 움직인 Moment**

다.

그리고:

> **Connection = 다음 탐색을 일으킨 감정의 인과관계**

다.

따라서 시네마틱 화면도 반드시 다음을 느끼게 해야 한다.

```text
한 순간을 만남
→ 마음이 움직임
→ 저장
→ 다음 순간이 열림
→ 계속 따라감
→ 나만의 경로가 생김
```

Tree는 단순 목록이 아니라
**처음의 감정을 다시 살릴 수 있는 재생 가능한 경로**다.

# 6. 첫 프로젝트의 핵심 질문

이 프로젝트는 다음 질문에서 시작한다.

> **“내가 어떤 사람을 좋아하게 된 최초의 순간을 다시 들어가 볼 수 있다면 어떤 화면이어야 하는가?”**

기능을 먼저 설명하지 않는다.

첫 화면에서 사용자가 느껴야 하는 것은:

```text
제품 설명
```

이 아니라:

```text
아, 저 순간 때문에 좋아하게 됐지.
```

다.

# 7. 벤치마킹 영상 사용법

`티져` 폴더의 영상을 단순히 “비슷하게” 만들지 않는다.

각 그룹에서 다음 문법을 선택적으로 가져온다.

---

## A. NewJeans — 최우선 비주얼 기준

우선 분석:
- `ASAP`
- `How Sweet`
- `Right Now`
- 필요 시 폴더 내 다른 영상 추가 분석

가져올 것:
- 자연광
- 숲
- 물
- 바람
- 길
- 자동차
- handheld
- 오래된 기억 같은 grain
- 현실 ↔ 그래픽/애니 전환
- 인물이 UI보다 먼저 보이는 화면
- 화면 전체를 가득 채우는 Moment

중요:

**NewJeans를 복사하는 것이 아니라 “기억처럼 보이는 영상 문법”을 가져온다.**

---

## B. ILLIT — Personal Memory / Save UX

우선 분석:
- `Magnetic`
- `Cherish`
- `It’s Me`

가져올 것:
- 침대
- 카드
- 사진
- 종이
- 작은 물건
- 방
- 일상 공간
- pastel
- 가까운 거리의 인물 관계
- 저장한 기억을 실제 물건처럼 느끼게 하는 연출

LoveTree의:
```text
Save Moment
```
에 특히 활용한다.

---

## C. ENHYPEN — Emotional Weight

우선 분석:
- `Bite Me`
- `Drunk-Dazed`
- `Knife`

가져올 것:
- 얼굴을 너무 빨리 소비하지 않는 편집
- 정적 긴장
- 옆모습
- 손
- 옷의 질감
- 어두운 공간
- 빨강 / 파랑 대비
- 기다림 후 충격

LoveTree에서:
```text
“이 장면을 왜 못 잊었는지”
```
를 보여주는 구간에 활용한다.

## D. aespa — 1~2개의 Surreal Shock만 사용

우선 분석:
- `Armageddon`
- `Supernova`
- `Dirty Work`

가져올 것:
- 한 장면에 하나의 비정상적 사건
- reality break
- beauty shot 뒤의 uncanny cut
- 강한 typography
- visual shock

주의:
4-2기 전체를 aespa식 SF로 만들지 않는다.

## E. NMIXX — 공간 전환 참고

`V Teaser`

가져올 것:
- horizon bend
- 공간 왜곡
- 갑작스러운 scale shift
- quiet → impact

Moment를 클릭했을 때
단순 fade가 아니라 **공간 자체가 휘며 다음 기억으로 들어가는 transition**에 사용한다.

---

## F. CORTIS — 홍보용 짧은 실험

가져올 것:
- fisheye
- handheld
- raw texture
- single-color concept
- 사물만 보여주는 컷
- 짧은 6초/10초 광고 문법

메인 홈페이지보다 홍보용 파생물에 우선 사용한다.

## G. NCT — 이번 Track에서는 최소 사용

NCT는 현재 4-1기에서 이미 충분히 활용 중이다.

4-2기에서는:

정도만 보조 참고.

HUD / Neon / Cockpit / Radar를 다시 만들지 않는다.

# 9. SCENE 01 — First Moment

처음부터 로고 애니메이션을 길게 보여주지 않는다.

첫 0.5~1초 안에:
- 얼굴
- 무대
- 웃음
- 뒤돌아보는 장면
- 자연광 속 한 순간

중 하나가 크게 보인다.

텍스트는 처음에는 없어도 된다.

약간 늦게 아주 작은 문장:

```text
그 순간부터였다.
```

또는:

```text
I remember when it started.
```

둘 중 하나.

긴 서비스 설명 금지.

---

# 10. SCENE 02 — Memory Breath

첫 Moment 다음에 바로 UI를 띄우지 않는다.

0.7~1.5초 정도 **숨 쉬는 컷**을 넣는다.

예:
- 바람에 흔들리는 커튼
- 햇빛
- 물 표면
- 흔들리는 머리카락
- 공연장 조명
- 자동차 창문
- 빈 복도
- 손에 들린 사진

이 장면이 매우 중요하다.

4-1기 Neon Pilot에서 부족했던 것이 바로
**UI가 없는 여백**이다.

---

# 11. SCENE 03 — Person Reveal

인물을 더 깊이 본다.

그러나:
- 얼굴 위 Radar
- 원형 HUD
- 분석 수치
를 넣지 않는다.

대신:
- slow push-in
- focus shift
- reflected light
- masking by foreground object
- curtain / glass / water reflection
을 사용한다.

“분석”이 아니라:

> **기억이 선명해지는 것**

처럼 보이게 한다.

---

# 12. SCENE 04 — Detail

인물 전체만 계속 보여주지 않는다.

다음 중 2~4개:
- 눈
- 손
- 귀걸이
- 머리카락
- 옷의 한 부분
- 무대 조명
- 마이크
- 신발
- 종이
- 사진
- 휴대폰 화면
- 창문에 비친 얼굴

을 사용한다.

중요:
하반신이나 신체 일부를 이유 없이 확대하는 장면 금지.

모든 Detail에는 감정적 이유가 있어야 한다.

---

# 13. SCENE 05 — Save Moment

LoveTree의 핵심 행동이 처음 등장한다.

거대한 SaaS modal 금지.

권장:
화면 아래 또는 인물 옆에 아주 작은 translucent UI.

```text
SAVE THIS MOMENT
```

사용자가 클릭하면:
- 작은 촉각적 애니메이션
- subtle pulse
- thumbnail이 기억 보관함으로 들어가는 느낌

이후:

```text
MOMENT SAVED
```

를 0.4~0.8초 정도만.

---

# 14. SCENE 06 — Connection Appears

저장 뒤에 다음 Moment가 나타난다.

중요:
Connection을 “원 + 선” 도식으로 만들지 않는다.

권장 방식:

### 방법 A
현재 영상/사진 가장자리에서
다음 Moment의 색이나 빛이 새어 들어옴.

### 방법 B
한 소품 Match Cut:
```text
마이크
→ 다음 공연의 마이크
```

### 방법 C
눈 방향 Match Cut:
```text
현재 인물 시선
→ 다음 영상 속 같은 방향
```

### 방법 D
공간 Match Cut:
```text
문
→ 다음 Moment의 문
```

이게 LoveTree의 Connection이다.

---

# 15. SCENE 07 — Follow the Connection

사용자가 다음 순간으로 이동한다.

이때 작은 텍스트:

```text
FOLLOW THE CONNECTION
```

또는:

```text
ONE MOMENT OPENS THE NEXT.
```

화면 전체를 그래픽으로 덮지 않는다.

Transition 자체가 Connection을 설명해야 한다.

---

# 16. SCENE 08 — Memory Field

여러 Moment가 존재한다는 것을 보여준다.

그러나 일반 grid dashboard 금지.

추천:
- 어두운 방 벽
- 흩어진 사진
- 창문 밖 풍경
- 자연 landscape
- floating film frames
- 공간 속 여러 작은 화면

Moment들이 동일한 카드 크기로 정렬되지 않아도 된다.

핵심은:
```text
많은 순간이 한 사람의 기억 속에 존재한다.
```

는 느낌.

기존 LoveTree 48에서 확보한 여러 인물 이미지도 사용할 수 있다.

---

# 17. SCENE 09 — Tree Emerges

Tree를 literal한 나무 일러스트로 먼저 만들지 않는다.

먼저:

```text
Moment
→ Moment
→ Moment
```

사이의 연결이 쌓이면서
하나의 경로가 형성되는 모습을 보여준다.

그 경로 전체가 결국:

```text
MY TREE
```

가 된다.

즉 Tree는 결과다.

---

# 18. SCENE 10 — End / Brand

End Card는 매우 단순하게.

```text

```

아래:

```text

```


# 20. 이미지 자산 정책

기존 자산을 우선한다.

사용 가능 후보:

억지로 사용하지 않는다.

## 신규 생성 허용

필요하면 신규 이미지 생성 요청 가능.

단 첫 V1에서 필요한 이미지의 상한을 둔다.

권장 최대:
- Hero portrait 2~3장
- natural environment 3~5장
- detail/object 3~5장
- memory texture 2~3장

총 10~15장 내외.

**이미지 수십 장부터 만들지 않는다.**

HTML 구조를 먼저 만든다.

# 21. 신규 이미지 요청 방법

신규 이미지가 필요하면
그냥 “예쁜 아이돌 사진 필요”라고 요청하지 않는다.

반드시 다음 형식으로 요청한다.

```text
SCENE
WHY NEEDED
SUBJECT
CAMERA
LIGHT
COLOR
BACKGROUND
ASPECT RATIO
MIN RESOLUTION
DO NOT INCLUDE
```

예:

```text
SCENE: First Moment
WHY: 첫 1초의 감정 훅
SUBJECT: 20대 초반 남성 아이돌 느낌
CAMERA: candid medium close-up, slight profile
LIGHT: late afternoon window light
COLOR: warm ivory + faded blue
BACKGROUND: moving train window
ASPECT: 16:9
MIN: 2560×1440
DO NOT: text, logo, HUD, sci-fi, studio white background
```

# 22. Motion 원칙

이번 Track은 **빠르게 움직이는 것 = 멋있다**가 아니다.

필요한 리듬:

```text
Impact
→ Breath
→ Intimacy
→ Discovery
→ Connection
→ Expansion
```

컷 길이를 일부러 다르게 한다.

예:
```text
0.3s
0.5s
1.4s
0.7s
2.0s
0.4s
```

같은 1초 컷 반복 금지.

- 인물
- 장소
- 빛
- 물
- 바람
- 물건
- 기억
이 주인공이어야 한다.

즉 화면마다:
```text
label
line
circle
panel
```
을 붙이지 않는다.
