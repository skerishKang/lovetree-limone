# Dream Memory V1.2 · Scene Map

상태: **신규 후보 / 제품 오너 시각 검토 전 / Production 금지**

| Scene | Time | Product meaning | Visual composition | Rhythm |
|---|---:|---|---|---|
| 01 First Moment | 0.0–4.0s | 마음이 움직인 최초의 순간 | 짧은 얼굴 파편 2회 후 자연광 인물 long hold | 0.5s → 0.4s → 2.5s hold |
| 02 Memory Breath | 4.0–7.2s | 감정을 설명하지 않고 남기는 여백 | 커튼·창·잎 그림자·물빛, 인물 없음 | 3.2s 거의 정지 |
| 03 Moment Reveal | 7.2–11.5s | 다시 보고 선명해진 사람/순간 | 남성 인물 3/4 감각 + 유리/foreground masking | 4.3s slow reveal |
| 04 Detail | 11.5–14.4s | 좋아하게 된 사소한 단서 | 머리카락→무대 손동작→걷는 발/의상→backstage 물체 | 0.52/0.76/0.42/1.20s uneven fragments |
| 05 Save | 14.4–19.0s | 이 순간을 붙잡음 | 반신/상반신 Moment + 작은 Save UI | 2.2s hold → 0.32s freeze event → breathing tail |
| 06 Connection | 19.0–23.8s | 이 Moment 때문에 다음 Moment가 열림 | 무대 원형 빛 → 빛만 남음 → 창의 같은 빛 match cut | 기다림→갑작스런 전환→1s 의미 보조 |
| 07 Next Moment | 23.8–28.0s | 다음 기억으로 이동 | 밝은 복도 전신 walking + 마지막 1s 다른 인물 fragment | 2.7s full-body hold → 1s flash |
| 08 Memory Field | 28.0–34.0s | 여러 사람·공간·무대·관계의 기억 축적 | Pair / backstage / stage / quiet portrait를 비정형 physical print로 순차 등장 | 6s accumulation, grid 금지 |
| 09 Tree Emerges | 34.0–40.5s | 축적된 Moment의 감정 경로가 Tree가 됨 | 줄기→가지→Moment light nodes가 천천히 나타남 | 6.5s slow emergence |
| 10 End / Brand | 40.5–44.5s | 제품 기억점 | Warm ivory `LOVETREE / FOLLOW THE MOMENT` | 4s calm end |

## Shot-balance intent
Close-up을 연속 전시하지 않는다. V1.2의 체감 비중은 close/portrait, half-body, full-body, detail, environment/light/empty가 교차하도록 설계했고, 환경/빛/Tree가 전체 시간의 약 1/3을 차지한다. 이 수치는 평가 기준이지 고정 quota가 아니다.
