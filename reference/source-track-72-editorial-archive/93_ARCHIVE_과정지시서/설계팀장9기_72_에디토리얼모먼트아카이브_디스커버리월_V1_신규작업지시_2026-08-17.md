# 0. 이번 Track의 정의

이번 Track 72는 기존의 또 다른 3D 대문을 만드는 작업이 아니다.

정확한 역할은:

> **서로 다른 종류와 원본 비율을 가진 LoveTree Moment들을 동일한 카드 규격에 강제로 맞추지 않고, 각각의 콘텐츠 성격과 중요도에 따라 크기·비율·배치가 달라지는 Editorial Masonry Archive / Discovery Wall로 보여주는 평면형 탐색 화면**

이다.

사용자 경험 문장은 다음과 같다.

> **“내가 저장해온 수많은 순간을 한눈에 훑다가, 지금 다시 보고 싶은 순간을 발견한다.”**

# 3. Track 72의 제품 역할

Track 72는 **대문이 아니라 Archive / Discovery View**다.

제품 내 후보 진입 위치:

`MY TREE`
→ `ALL MOMENTS`
→ `EDITORIAL ARCHIVE`

또는 View 선택에서:

- Tree
- Timeline
- Album
- Map
- **Archive**

처럼 들어가는 별도 보기 모드가 될 수 있다.

이 제품 위치는 아직 제안 상태이며,
이번 디자인 작업에서는 **화면 형식과 사용성 검증까지만 수행**한다.

제품 navigation 정책을 임의 확정하지 않는다.

# 4. 가장 중요한 원칙 — 원본 비율을 죽이지 말 것

이번 Track의 핵심은 이것이다.

> **모든 콘텐츠를 같은 4:5 카드나 같은 16:9 썸네일에 넣지 않는다.**

Moment 원본의 성격에 따라
화면에서 차지하는 모양과 크기가 달라져야 한다.

## HARD RULE

`object-fit: cover`로 모든 것을 같은 프레임에 잘라 넣는 방식 금지.

필요한 경우 일부 crop은 허용하지만,
**각 콘텐츠의 native aspect ratio와 시각적 성격을 우선한다.**

---

# 5. 기본 Grid System

Desktop 1440px 이상 기준 권장:

- Left sidebar: `180~240px`
- Main canvas: 나머지 영역
- Main grid: **12 column**
- gutter: `14~24px`
- row gap: `16~28px`
- page horizontal padding: `24~40px`

콘텐츠는 rigid dashboard grid가 아니라
**editorial masonry**처럼 보여야 한다.

CSS Grid + explicit span,
또는 Masonry engine을 사용할 수 있다.

단, layout shift가 심한 random masonry는 금지한다.

각 Moment는 데이터에 따라 안정된 span을 가진다.

# 6. 종류별 / 비율별 타일 규칙

이번 작업에서 가장 중요하다.

최소 아래 8종을 실제로 구현한다.

## TYPE A — HERO WIDE VIDEO

대상:
- 16:9
- 1.85:1
- 2:1
- 공연/뮤직비디오/무대 핵심 장면
- Conversion Moment
- 매우 중요한 video Moment

권장:

`grid-column: span 6~8`

특징:
- 원본 가로비 유지
- poster를 크게 보여줌
- duration / play glyph 최소
- hover 시 muted preview 가능

**큰 가로영상이 작은 정사각 카드에 들어가면 FAIL.**

## TYPE B — CINEMATIC ULTRAWIDE

대상:
- 21:9
- panoramic still
- cinematic scene

권장:

`grid-column: span 8~12`

높이는 비율 유지.

한 화면에 여러 개 남발하지 않는다.

Section rhythm을 만드는 **visual break** 역할.

## TYPE C — PORTRAIT MOMENT

대상:
- 3:4
- 4:5
- 9:16
- 인물 사진
- 세로 무대 영상
- Shorts/Reels/TikTok형 Moment

권장:

`grid-column: span 3~4`

중요 Portrait:
`span 4~5`

일반:
`span 3`

세로 영상의 인물을 과하게 crop하지 않는다.

## TYPE D — SQUARE MOMENT

대상:
- 1:1 이미지
- album art
- SNS post
- graphic
- object

권장:

`grid-column: span 3~4`

일반 square를 모두 같은 크기로 반복하지 말 것.

중요도에 따라:
- small square
- medium square
- feature square

3단계 정도 허용.

## TYPE E — LANDSCAPE PHOTO / SITE CAPTURE

대상:
- 4:3
- 3:2
- 16:10
- 웹페이지 캡처
- 인터뷰
- 기사
- landscape still

권장:

`grid-column: span 4~6`

웹사이트 캡처는 브라우저 mockup 장식을 억지로 추가하지 않고
원본 surface를 우선한다.

## TYPE F — MEMO / QUOTE

대상:
- 사용자의 한 줄
- 긴 메모
- 당시 감정 기록
- quote
- text-only Moment

이미지로 만들지 않는다.

**실제 DOM text**로 구현한다.

권장:
- narrow: span 3
- medium: span 4
- important quote: span 5~6

형태:
- portrait note
- wide quote
- compact text block

같은 메모 카드 템플릿 반복 금지.

## TYPE G — LINK / SOURCE

대상:
- YouTube
- SNS
- 기사
- 외부 링크
- 웹페이지
- source reference

권장:

`grid-column: span 3~5`

구성:
- thumbnail
- source
- short title
- domain/platform
- exact saved point가 있으면 time

Chrome browser frame처럼 과한 UI 금지.

## TYPE H — CONNECTION LANDMARK

LoveTree 고유 타입.

콘텐츠 자체가 아니라
**Moment A → Moment B로 이동한 이유**가 중요한 지점.

예:

`그 표정이 계속 생각나서 다음 무대를 찾아봤다.`

형태:
- 작은 typography tile
- horizontal separator tile
- text + thin directional line
- 감정 변화 표시

예:

`설렘 → 궁금함`

권장:

`grid-column: span 3~6`

Connection tile이 모든 Moment 사이에 들어가서 화면을 복잡하게 만들면 안 된다.

**중요한 전환점만 landmark처럼 사용.**

# 11. Main Canvas / Card Shape / White Space

배경은 Reference처럼:
- pure white
- 또는 near-white

권장:
`#FAFAF8 ~ #FFFFFF`

LoveTree의 기존 cream paper style을 이번 화면에 억지로 적용하지 않는다.

종이 질감, tape, pressed flower, wax seal을 기본 장식으로 붙이지 않는다.

모든 타일에 같은 rounded corner를 주지 않는다.

권장:
- radius `0~8px`
- 일부 video/card만 8~12px 가능
- shadow 최소

금지:
- 모든 card 24px radius
- glassmorphism panel
- 큰 drop shadow
- floating dashboard card 느낌

의도적으로:
- empty grid cells
- section breathing room
- large vertical gaps
- asymmetric whitespace

를 둔다.

### HARD RULE

한 화면을 이미지로 95% 이상 채우지 않는다.

Reference처럼 **비어 있는 부분도 composition의 일부**여야 한다.

# 12. Scroll / Motion

주 탐색은 **vertical scroll**이다.

필수:
- smooth but native-feeling
- scroll-jacking 금지
- section 강제 snap 금지
- horizontal drag를 기본 탐색으로 쓰지 않는다

이번 Track의 motion은 절제한다.

권장:
- image reveal
- subtle fade/translate on load
- video preview
- hover scale 1~2%
- metadata fade

금지:
- 전체 wall 자동 이동
- card orbit
- sphere rotation
- continuous floating
- 모든 카드 흔들기
- 과도한 showcase animation

**사용자는 작품을 보고 있어야지 animation engine을 보고 있으면 안 된다.**

# 13. VIDEO 동작

Video Moment 기본 상태:
- poster / first frame
- 작은 play indication
- duration

Desktop:
hover 또는 충분히 viewport에 들어온 경우
짧은 muted preview.

단:
**동시에 실제 재생하는 video는 최대 1~2개.**

Mobile:
poster 상태 유지.
tap으로 상세 진입.

모든 영상 autoplay 금지.

# 14. Hover / Click / Detail

Desktop hover:
- 작은 metadata 등장
- date
- emotion
- type
- optional one-line memo
- 아주 약한 scale

예:

`2025.04.16`
`설렘`
`VIDEO · 00:42`

타일 클릭 시 LoveTree detail overlay/viewer를 구현한다.

Detail:
- large original media
- title
- exact timestamp if applicable
- emotion
- user's one line
- date
- source
- previous / next Connection

핵심:
`왜 다음 순간으로 갔나요?`

Connection 문장을 확인할 수 있어야 한다.

복귀:
- `ESC`
- close
- 가능하면 browser back

**복귀 시 사용자가 보던 정확한 scroll position으로 돌아와야 한다.**

---

# 15. Filter 동작

Filter를 바꿀 때:
- 전체 reload 금지
- scroll 이상 jump 최소화
- items re-layout
- transition 절제

예:

`VIDEO`
→ video tiles만 남아 원본 ratio대로 재배치.

`MEMO`
→ text tiles만으로 별도 editorial wall.

이때 모든 타입을 같은 카드 규격으로 바꾸지 않는다.

# 23. 이번 Track의 핵심 차별점

Track 72의 차별점은 새로운 3D 효과가 아니다.

**다양한 Moment를 다양하게 보존하는 것 자체가 디자인이다.**

- 영상은 영상답게
- 세로 인물은 세로답게
- 사진은 사진답게
- 메모는 글답게
- 링크는 source답게
- 중요한 순간은 크게
- 작은 보조 순간은 작게
- Connection은 전환 landmark답게

보이게 한다.

> **“모든 기억은 같은 크기의 카드가 아니다.”**

이 문장을 이번 Track의 시각 설계 원칙으로 삼는다.

# 25. 최종 지시

이번 작업에서 디자인팀은 새로운 “멋있는 효과”를 발명하려고 하지 않는다.

Reference의 **Editorial Archive / Masonry Discovery** 형식을 먼저 정확히 구현한다.

특히 아래 다섯 가지를 절대 놓치지 않는다.

1. **원본 비율별로 다른 타일**
2. **콘텐츠 종류별로 다른 surface**
3. **중요도에 따른 크기 차등**
4. **white space가 살아 있는 editorial composition**
5. **vertical scroll로 편하게 수많은 Moment를 발견하는 경험**

첫 작업은 GATE A 정지 화면까지만 한다.
