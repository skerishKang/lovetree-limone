# 0. 왜 A1이 Reference와 달라졌는가

A1의 가장 큰 문제는 Grid 기술이 아니다.

**사용한 시각 자산의 종류가 너무 좁다.**

Reference는 한 화면에:

- 영상 장면
- 웹사이트/UI
- 그래픽
- 오브젝트
- 타이포 작업
- 세로 인물
- 가로 사진
- 추상 이미지
- 화면 캡처

가 동시에 섞여 있다.

그래서 각 타일이 서로 다른 “작품”으로 읽힌다.

반면 A1은 첫 화면에서 사람 얼굴/인물 이미지가 주도한다.

결과적으로:

> `다양한 Moment Archive`

가 아니라

> `인물 포트폴리오 / 패션 룩북`

처럼 보였다.

이번 A2는 레이아웃만 고치는 작업이 아니다.

**자산 선택부터 다시 한다.**

# 16. 실제 영상 Frame 선택 규칙

각 MP4를 그냥 0초 frame으로 쓰지 않는다.

반드시 영상을 직접 보고:

- 형태가 가장 잘 보이는 frame
- 인물만 크게 나온 frame보다 interface/visual이 드러나는 frame
- 다른 타일과 색/구도가 겹치지 않는 frame

을 골라 `currentTime`으로 고정.

예:

### 69
black landing / LoveTree typography / white portal state 등
서로 성격이 분명한 frame 선택.

### 67
Memory Tape ribbon / network / spatial scene 중
