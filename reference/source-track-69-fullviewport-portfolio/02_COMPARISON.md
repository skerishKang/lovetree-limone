## B — LoveTree adaptation
Purpose: test whether the exact visual skeleton can become a LoveTree entry portal without losing the source template's strength.

Changes only the semantic layer:
- GP logo → minimal LoveTree branch/path mark
- ADAM ROBERTS → LOVE TREE

- hero → SAVE THE / MOMENTS THAT / GROW INTO / PATHS
- PLAY SHOWREEL → PLAY MEMORY PATH
- award claims → DISCOVER 01 / CONNECT 02 / REPLAY 03
- portfolio availability footer → Moment / Emotion / Connection / Replay

## Design-team judgment
B works best as a **cinematic portal / experimental entry surface**, not as LoveTree's canonical everyday workspace. The canonical product baseline uses warm paper/plant language in the main experience, while dark cinematic assets are appropriate as parallel viewing or portal assets. The critical LoveTree meaning in B is therefore concentrated in the copy and journey hierarchy, not by adding literal tree graphics everywhere.

The female face is treated as the subject of an emotional path: "the person who first stopped my attention". This makes the unchanged source video compatible with LoveTree's fandom-first use case while preserving prompt fidelity.
