# 작업 범위 및 결정

## 목표
무료 템플릿을 소재만 바꿔 복제하지 않고, LoveTree 전용 시네마틱 진입 포털을 제작한다.

## 확정된 작업 판단
- 영상: 필수 아님. V4는 정지 키비주얼 + CSS motion으로 진행.
- 주인공: 정면을 바라보는 남성 AI-human. 인간이지만 얼굴 위 미세한 기하학/기계적 trace가 보이는 상태.
- 기존 여성 후보: 폐기.
- 68번에서 이미 사용한 캐릭터 자산: V4 대표 이미지로 재사용하지 않음.
- 수치/수상: 근거 없는 지표 사용 금지.
- 제품 의미: Moment → Connection → Replay가 첫 화면에서 읽혀야 함.
