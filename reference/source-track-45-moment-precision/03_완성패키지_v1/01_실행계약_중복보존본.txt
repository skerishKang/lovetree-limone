2. LoveTree에서의 공식 역할
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

공식 기능명:

Moment Polish Lab

전체 표시명:

LoveTree Moment Polish Lab

기능 목적:

사용자가 이미 저장한 Moment, Season 또는 Course의
표현 방식과 미세한 인터랙션을 확인하고 적용하는 선택형 공간.

공식 사용자 흐름:

Moment 저장
→ 필요한 경우 나중에 정리
→ Share 또는 Course 편집
→ Refine presentation
→ Moment Polish Lab
→ 프리셋 적용

중요:

이 화면은 첫 순간 저장 전에 나타나면 안 된다.

LoveTree 핵심 원칙:

Save first.
Polish later.

이 화면을 사용하지 않아도
Moment 저장과 LoveTree 사용은 완전하게 가능해야 한다.

내부 활용:

LoveTree의 카드, 아이콘, 제목, 버튼, 전환과
터치 반응을 검증하는 살아 있는 디자인 시스템.

border:

shadow:

32. 완료 판정 기준
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

다음 조건을 모두 충족해야 완료다.

1. 결과가 단일 HTML로 실행됨
2. 검은 외곽 무대와 중앙 아이보리 아트보드가 있음
3. Hero가 참고 영상과 유사한 검은 패널로 구현됨
4. Hero에 큰 외곽 숫자 12가 있음
5. cue strip과 파란 진행선이 있음
6. Apply bar가 Hero 아래에 있음
7. 3열 × 4행의 12개 카드가 있음
8. 모든 카드가 실제로 조작 가능함
9. 활성 카드에 파란 outline이 표시됨
10. 10번 태그가 stagger로 진입함
11. 10번 태그가 blur와 이동으로 퇴장함
12. 11번 기본·균형 줄바꿈 차이가 보임
13. 12번 잘못된 전체 전환과 정확한 전환 차이가 보임
14. 마지막에 Apply bar가 활성화됨
15. Apply 결과가 localStorage에 저장됨
16. 첫 Moment 저장 흐름을 방해하지 않음
17. 콘텐츠 데이터가 아닌 presentation preset만 저장함
18. 영어 화면이 짧고 세련되게 구성됨
19. 모바일에서도 모든 데모를 실제 조작할 수 있음
20. 데스크톱 콘솔 오류 0
21. 모바일 콘솔 오류 0
22. 페이지 오류 0

성장 트리나 공개 Course에 즉시 통합하지 말고
사용자 검토를 기다린다.
