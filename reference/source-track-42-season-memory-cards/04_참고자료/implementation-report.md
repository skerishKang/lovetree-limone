큰 제품 제목, 사이드바, 통계 패널, 성장 트리와 입력 폼은 추가하지 않았다.

## 카드 렌더링

9개 Moment는 JavaScript 배열로 분리했다. DOM에는 현재 인덱스를 중심으로 `-2, -1, 0, 1, 2`의 5개 슬롯만 렌더링한다.

- 실제로 읽히는 슬롯: `-1, 0, 1`
- 전환 대기 슬롯: `-2, 2`
- 중앙 카드: scale 1, 강화된 shadow
- 좌우 카드: scale .978
- 외곽 카드: opacity 0, blur 4px

다음 이동에서는 모든 슬롯이 한 자리 왼쪽으로 이동하고, 전환 종료 후 현재 인덱스를 변경해 5개 슬롯을 다시 구성한다. 이전 이동은 반대 방향이다.

## 썸네일 우선순위

1. 기존 LoveTree 샘플에서 사용한 YouTube ID의 실제 `i.ytimg.com` 썸네일
2. 네트워크 실패 시 HTML에 내장된 LoveTree 시네마틱 이미지
3. 내장 이미지까지 실패할 때 동적 SVG fallback

따라서 온라인 환경에서는 실제 YouTube 썸네일을 우선 표시하고, 오프라인에서도 깨진 카드가 남지 않는다.

## 상태 관리

상태 모델은 최소 두 단계로 구분했다.

- `IDLE`
- `TRANSITIONING`

전환 중에는 다음 입력을 무시해 카드 순서가 중복 입력으로 꼬이지 않게 했다.

순환 인덱스:

- 페이지 1의 이전: 9
- 페이지 9의 다음: 1

## 페이지네이션

페이지 번호는 현재 위치에 따라 압축한다.

- 1: `1 2 3 … 9`
- 5: `1 … 4 5 6 … 9`
- 9: `1 … 7 8 9`

활성 상태는 하나의 `.active-indicator`를 현재 버튼 위치로 transform 이동시킨다. 현재 표기는 항상 `01 / 09` 형식을 사용한다.

## WIDE / FOCUS 카메라

카드 UI 자체의 치수를 바꾸지 않고 전체 `.presentation` transform만 변경한다.

- WIDE: scale .82
- FOCUS: scale 1.27
- 전환: 650ms
- easing: `cubic-bezier(.22,.72,.16,1)`

9→1 순환에서는 WIDE 축소 후 중앙→왼쪽→오른쪽 순으로 카드를 stagger 재정렬하고 다시 FOCUS로 확대한다.

## 입력

- 이전·다음 버튼
- 페이지 숫자
- 키보드 좌우 방향키
- Home / End
- 모바일 좌우 스와이프
- 트랙패드 수평 wheel
- R 자동 데모 재시작

사용자 입력이 발생하면 자동 데모를 즉시 중단하고 상태를 저장한다.

## 기억 상세와 영상

`기억 열기`는 현재 페이지를 유지한 채 상세 모달을 연다.

- 썸네일, 제목, 사람, 날짜, 마음 기록, 감정, 연결 이유 표시
- 재생 버튼을 눌렀을 때만 YouTube iframe 생성
- `autoplay=1`, `playsinline=1`, `rel=0`
- 모달 닫기 시 iframe `src`를 비우고 DOM을 제거
- 닫은 뒤 원래 페이지와 카드 위치 유지

## 검증 환경 관련 고지

검증 컨테이너는 외부 YouTube 요청이 차단된다. 캡처에서는 썸네일 우선순위의 두 번째 단계인 내장 LoveTree 이미지가 사용됐다. 전달 HTML은 온라인 브라우저에서 실제 YouTube 썸네일을 먼저 요청한다.

실행 영상의 플레이어 구간은 iframe 생성·교체·제거 동작을 증명하기 위해 검증 전용 `srcdoc` 애니메이션을 사용했다. 전달 HTML의 실제 코드는 YouTube embed URL을 생성한다.
