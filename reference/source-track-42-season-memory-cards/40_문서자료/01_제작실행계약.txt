1. 작업 목표
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

첨부 참고 영상:

녹화_2026_08_03_18_53_45_489.mp4

의 카드 크기, 공간 비율, 페이지네이션, 카드 이동 방향,
전환 속도, 화면 확대·축소, 여백과 색감을 최대한 동일하게 재현한다.

콘텐츠 의미만 LoveTree에 맞게 변경한다.

목표:

참고 영상과 결과물을 나란히 놓았을 때
“같은 인터페이스를 LoveTree의 시즌 기억 보기로 다시 만든 것 같다”
는 인상을 주어야 한다.

이번 작업의 우선순위:

1. 참고 영상과 닮은 전체 화면
2. 카드 이동과 페이지네이션 모션
3. LoveTree 콘텐츠 치환
4. 실제 조작
5. 모바일 기본 대응

처음부터 성장 트리, 그래프, 일기, 새 Moment 입력 폼 등
다른 LoveTree 기능을 통합하지 않는다.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

4. 외곽 배경과 흰색 무대
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

4-1. 외곽 그라데이션

참고 영상의 축소 장면처럼 다음 색이 자연스럽게 연결된다.

- 좌상단: 코랄·주황
- 좌하단: 핑크·마젠타
- 우하단: 시안·블루
- 일부 가장자리: 보라

단순한 직선 그라데이션 하나가 아니라
여러 radial-gradient를 겹쳐 부드러운 빛 번짐을 만든다.

권장 색:

#ff6a55
#ff4f86
#be4dde
#3189ea
#27c6d1

그라데이션은 강하지만 카드보다 먼저 눈에 띄면 안 된다.

4-2. 흰색 무대

데스크톱 기본:

- 정사각형에 가까운 비율
- 크기: min(880px, 88vh, 82vw)
- 배경: 완전한 흰색 또는 #fffefd
- 모서리: 약 10~14px
- 외곽 그림자: 넓고 부드러운 회색 그림자
- 그라데이션 배경과 약 42~55px 간격
- 내용은 정중앙보다 약간 아래에 배치
- 위쪽과 아래쪽에 넓은 빈 공간 유지

참고 영상의 큰 여백을 없애지 않는다.

흰색 무대 안을 일반적인 대시보드처럼 가득 채우면 실패다.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
5. LoveTree 서비스의 의미
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

이 화면의 공식 기능명:

시즌 기억 카드

설명:

한 사람에게 빠져든 과정에서 저장한 Moment를
이전·현재·다음 순서로 넘겨보는 시즌형 기억 탐색 화면.

기본 데이터:

- 한 사람
- 첫 번째 Season
- 총 9개의 Moment
- 현재 Moment를 중앙에 표시
- 이전 Moment는 왼쪽
- 다음 Moment는 오른쪽

공식 화면 제목을 별도 대형 헤더로 추가하지 않는다.

LoveTree라는 의미는 다음 요소로 표현한다.

- 카드 콘텐츠
- 페이지네이션 왼쪽 라벨
- Moment·감정·연결 이유
- 기억 열기 동작

페이지네이션 왼쪽 라벨:

MOMENTS

또는:

SEASON 01

둘 중 하나만 사용한다.

권장:

SEASON 01

6. 카드 3장 배치
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

항상 3장의 카드만 중심적으로 보인다.

왼쪽:

현재 Moment의 이전 Moment

중앙:

현재 선택된 Moment

오른쪽:

현재 Moment의 다음 Moment

페이지가 1일 때:

왼쪽 = 9
중앙 = 1
오른쪽 = 2

페이지가 9일 때:

왼쪽 = 8
중앙 = 9
오른쪽 = 1

즉 완전한 순환 구조다.

배치:

- 카드 폭: 전체 흰색 무대의 약 27~29%
- 카드 높이: 카드 폭의 약 1.42~1.48배
- 카드 사이 간격: 약 16~22px
- 3장 전체가 수평 중앙 정렬
- 왼쪽·오른쪽 카드도 충분히 읽을 수 있음
- 카드 일부를 의도 없이 잘라내지 않음

확대 프레젠테이션 상태에서는:

- 왼쪽 카드의 왼쪽 일부가 화면 밖으로 나갈 수 있음
- 오른쪽 카드의 오른쪽 일부가 화면 밖으로 나갈 수 있음
- 중앙 카드는 반드시 완전히 보임

안정 상태의 크기:

중앙 카드:

scale(1)

좌우 카드:

scale(.97~.985)

좌우 카드를 지나치게 작게 만들지 않는다.

7. 카드 외형
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

카드는 참고 영상과 같은 세로 여행 카드 구조를 사용한다.

7-1. 카드 전체

- 세로형
- 모서리 반경: 약 27~31px
- 전체 배경은 영상 썸네일
- overflow: hidden
- 밝고 부드러운 그림자
- 얇은 반투명 테두리
- 카드마다 감정색을 나타내는 아주 얇은 하단 또는 측면 포인트

카드 색상은 과도한 네온이 아니라
영상 이미지와 어울리는 절제된 감정색을 사용한다.

7-2. 영상 썸네일

- 카드 전체 영역을 채움
- object-fit: cover
- 이미지 초점은 상단 또는 중앙
- 하단 정보 패널 뒤에도 이미지가 이어질 수 있음
- 이미지 위에 너무 강한 검은 오버레이를 깔지 않음

실제 LoveTree 샘플 영상의 YouTube 썸네일을 사용한다.

가능하면 기존 LoveTree 작업물에 사용된 실제 영상 ID를 사용한다.

외부 임의 여행 사진을 그대로 사용하지 않는다.

썸네일 실패 시:

- 사람별 색상 그라데이션
- 제목 첫 글자
- 작은 LoveTree 꽃·잎 표시

로 대체한다.

7-3. 상단 날짜 칩

카드 왼쪽 위에 작은 회색 반투명 캡슐을 둔다.

내용 예:

2026.02.14
DAY 01
FEB 14

한 카드에는 한 가지 방식만 사용한다.

권장:

DAY 01
DAY 12
DAY 27

구조:

- 작은 캘린더 아이콘
- 대문자 또는 숫자
- 흰색 글자
- 어두운 반투명 배경
- backdrop-filter blur
- 지나치게 크지 않음

7-4. 하단 정보 패널

카드 높이의 약 47~52%를 차지한다.

- 반투명이 거의 없는 크림·오프화이트
- 색상: #f8f5f2 또는 rgba(255,252,248,.94)
- 위쪽 모서리: 약 22~25px
- 아래쪽은 카드 전체 모서리를 따름
- 카드 이미지 위에 겹쳐 올라감
- 내부 여백 약 17~21px

정보 순서:

1. 플랫폼·사람
2. Moment 제목
3. 마음 기록
4. 감정 태그
5. 하단 버튼 영역

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

8-2. 제목

예:

WHISPER로 시작된 마음

춤선을 다시 보게 된 밤

표정이 궁금해진 직캠

댓글을 따라 찾은 다음 영상

첫 번째 계절의 현재

제목은 2줄 이내다.

- 굵은 산세리프
- 카드에서 가장 큰 텍스트
- 18~22px 수준
- 줄 간격 촘촘하게
- 말줄임 처리 가능

8-3. 마음 기록

예:

처음에는 짧은 무대 영상 하나였지만,
이 장면 이후 다른 직캠까지 찾아보기 시작했다.

2~3줄로 제한한다.

- 11~13px
- 회색
- 줄 간격 1.45~1.55
- 넘치는 내용은 말줄임

8-4. 감정 태그

참고 영상처럼 한 줄에 3개 정도 표시한다.

예:

태그를 둥근 칩 여러 개로 만들지 않는다.
참고 영상처럼 작은 아이콘과 단어가 한 줄에 놓여야 한다.

참고 영상의 `EXPLORE` 위치·크기와 유사하게 만든다.

9. 9개의 샘플 Moment
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

한 사람의 첫 Season을 나타내는 9개의 Moment를 구성한다.

예시 흐름:

01. 처음 멈춰 본 영상
02. 목소리가 궁금해진 순간
03. 춤선을 다시 보게 된 밤
04. 표정이 기억에 남은 직캠
05. 다음 무대를 찾아본 날
06. 무대 밖의 다정함
07. 인터뷰까지 찾아본 순간
08. 편안함이 커진 오늘
09. 첫 번째 계절의 현재

각 데이터는 JavaScript 배열로 분리한다.

예시 구조:

const moments = [
  {
    id: 1,
    person: "이주연",
    platform: "youtube",
    videoId: "...",
    title: "처음 멈춰 본 영상",
    note: "...",
    dayLabel: "DAY 01",
    feelings: ["설렘", "눈빛", "첫 순간"],
    branch: "첫 순간",
    accent: "#d77b8c"
  }
]

HTML에 카드 9장을 직접 반복 작성하지 않는다.

데이터 배열을 기반으로 렌더링한다.

10. 페이지 이동의 핵심 구조
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

현재 페이지를 `currentIndex`로 관리한다.

항상 다음 세 인덱스를 계산한다.

previousIndex
currentIndex
nextIndex

순환 계산:

previousIndex =
(currentIndex - 1 + total) % total

nextIndex =
(currentIndex + 1) % total

페이지 9에서 다음을 누르면 1로 이동한다.

페이지 1에서 이전을 누르면 9로 이동한다.

카드 전환 중 중복 입력이 들어와도
카드가 겹치거나 순서가 꼬이지 않아야 한다.

IDLE
TRANSITIONING

11. 카드 이동 애니메이션
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

참고 영상에서 가장 중요한 부분이다.

페이지를 다음으로 넘길 때:

1. 왼쪽 이전 카드가 화면 왼쪽으로 이동하며 흐려짐
2. 중앙 카드가 왼쪽 자리로 이동
3. 오른쪽 카드가 중앙 자리로 이동
4. 새로운 다음 카드가 오른쪽에서 진입
5. 카드 내부 정보도 함께 이동
6. 전환 종료 후 DOM 상태 정리

이전 페이지로 이동할 때는 방향을 반대로 한다.

권장 시간:

전체 이동 480~620ms

권장 easing:

cubic-bezier(.22,.72,.16,1)

또는:

cubic-bezier(.2,.8,.2,1)

단순히 카드 내용을 제자리에서 교체하거나
전체를 fade-out/fade-in 하면 실패다.

각 카드가 실제 공간을 이동해야 한다.

진입 카드:

- opacity: 0 → 1
- translateX: ±45% → 0
- scale: .94 → .98 또는 1
- blur: 4px → 0

퇴장 카드:

- opacity: 1 → 0
- translateX: 0 → ±45%
- scale: .98 → .94
- blur: 0 → 3px

중앙으로 오는 카드:

- scale: .98 → 1
- 밝기 약간 증가
- 그림자 약간 강해짐

중앙에서 왼쪽·오른쪽으로 나가는 카드:

- scale: 1 → .98
- 그림자 약간 약해짐

과도한 bounce는 사용하지 않는다.

15. 확대·축소 프레젠테이션 모션
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

참고 영상은 카드 화면을 가까이 보여주다가,
중간에 화면을 축소해 외곽 그라데이션과 흰색 무대 전체를 보여준다.

이를 선택 가능한 자동 데모로 구현한다.

두 카메라 상태:

WIDE:

- 외곽 그라데이션이 넓게 보임
- 흰색 무대 전체가 보임
- 카드 3장과 페이지네이션이 작게 보임
- scale 약 .78~.84

FOCUS:

- 카드와 페이지네이션이 크게 보임
- 외곽 그라데이션은 대부분 화면 밖
- 좌우 카드의 외곽 일부가 잘릴 수 있음
- scale 약 1.22~1.32

전환:

- 500~700ms
- 부드러운 ease
- 중심점은 카드 캐러셀 중앙
- transform-origin을 변경하지 않음
- 확대 중 카드가 흐릿해지지 않음

자동 데모 예시:

1. WIDE에서 페이지 1
2. FOCUS로 확대
3. 1 → 2 → 3 → 4 → 5 → 6 → 7 → 8 → 9
4. 페이지 9에서 잠시 정지
5. WIDE로 축소
6. 페이지 1로 순환
7. 카드가 짧은 stagger로 다시 정렬
8. FOCUS로 확대
9. 다시 순환

자동 진행 간격:

약 650~850ms

사용자가 클릭·키보드·스와이프를 사용하면
자동 데모는 즉시 중단한다.

다시 보기 버튼을 화면에 크게 추가하지 않는다.

키보드 `R`을 눌렀을 때만 자동 데모를 처음부터 다시 실행해도 된다.

16. 9번에서 1번으로 돌아가는 모션
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

9번에서 1번으로 이동할 때
일반적인 왼쪽 슬라이드만 반복하지 않는다.

1. 카메라가 WIDE 상태로 축소
2. 기존 카드가 약간 작아지며 투명도 감소

6. 2번 다음 카드가 오른쪽에 나타남
7. 세 카드가 60~100ms 간격으로 정렬
8. 카메라가 다시 FOCUS로 확대

중앙 → 왼쪽 → 오른쪽

또는:

왼쪽 → 중앙 → 오른쪽

중 한 가지를 일관되게 사용한다.
