## V1이 원본과 달랐던 점

V1은 cluster당 14~15 Moment를 거의 동일한 각도로 나누고, 3단 ring에 배치한 뒤 hub → Moment spoke를 반복했다.

실제 화면에서는:

- 원형 hub
- 방사형 spoke
- 비슷한 ring radius
- cluster마다 유사한 node 수
- cluster 사이 긴 단일 연결

이 반복되어 꽃잎 / 불가사리 / 위성 구조처럼 보였다.

원본의 핵심인 불규칙한 network mass, cluster 중첩, density 편차, 여러 hub/anchor, 복수 bridge가 부족했다.

## V1.1에서 고친 점

### Graph silhouette

- 6개 cluster가 서로 다른 silhouette를 갖도록 생성 규칙을 분리했다.
- cluster별 Moment 수를 28 / 56 / 68 / 44 / 32 / 60으로 다르게 했다.
- 세로 진행 중 폭이 넓어졌다 좁아지고, 좌우 중심이 이동하도록 cluster center와 extent를 다르게 했다.
- cluster를 완전히 분리된 원형 섬이 아니라 일부 겹치는 유기적 덩어리로 구성했다.

### Density

- 전체 Moment를 288개로 확대했다.
- 19개의 중형 anchor를 추가했다.
- Connection은 1,274개이며 path / local neighbor / cross-link / anchor / bridge가 혼합된다.
- cluster 사이에는 hub 1개짜리 단일 직선이 아니라 여러 bridge와 cross-connection이 존재한다.

### Hub

- main hub 크기를 서로 다르게 했다.
- 일부 hub는 solid color core, 일부는 pearl core + outline으로 구분했다.
- 모든 node가 hub에 spoke로 붙는 구조를 제거했다.

### Connection Focus

원본의 높은 density는 가져오되 모든 선을 같은 밝기로 유지하지 않았다.

- Overview: 전체 skeleton 저광량
- Cluster Focus: 선택 cluster 구조 상승
- Moment Focus: 선택 Moment / neighbor / 다음 path 우선
- WHY NEXT와 다음 목적지 유지

## 의도적으로 원본과 다르게 유지한 LoveTree 요소

원본은 검은 배경과 강한 neon graph가 중심이다.

제품오너 최신 결정에 따라 V1.1은 이를 복제하지 않고:

- Light Pearl / Warm Ivory background
- LoveTree rose / violet / cyan / amber / mint / blue emotion cluster
- 실제 Moment / Connection 의미
- WHY NEXT
- `이 경로 따라가기`
- cluster focus / Moment focus

를 유지했다.

즉 fidelity 대상은 **검은 테마가 아니라 유기적 형상·밀도·다중 bridge·세로 macro scan 문법**이다.

## 배경 변경

V1의 `#05060b`, `#090b14`, dark gradient, vignette를 V1.1 기본 theme에서 제거했다.

V1.1은 `#F8F5F2` 중심의 밝고 따뜻한 Pearl 공간을 사용한다. 밝은 배경에서 선이 날아가지 않도록 기본 Connection은 muted gray 계열 core를 갖고, 선택 path만 cluster color를 강하게 사용한다.
