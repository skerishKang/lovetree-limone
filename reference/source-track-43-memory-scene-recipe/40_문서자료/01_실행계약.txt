이 화면의 공식 기능명:

기억 장면 레시피

영문 표시명:

LoveTree MemoryCraft

기능 목적:

사용자가 저장한 Moment, Branch, Season, Course를
어떤 방식으로 보여주고 공유할지 선택하는
시네마틱 장면·모션 템플릿 라이브러리다.

사용자는 다음과 같은 표현 방식을 고른다.

- 첫 순간을 따라가는 선
- 한 사람을 도는 Moment
- 계절처럼 쌓이는 기억
- 어둠 속에서 나타나는 장면
- 감정이 파동처럼 퍼지는 표현
- 공유 코스로 연결되는 이동

이 화면은 영상 편집 프로그램이 아니다.

영상 자체를 자르고 편집하는 것이 아니라,
LoveTree에 저장한 기억을 보여주는 방식과 모션을 선택한다.

공식 사용자 흐름:

기억 장면 탐색
→ 미리보기
→ 감정 온도 필터
→ 레시피 선택
→ 내 Season 또는 Course에 적용

5. SCENE 01 · 단일 레시피 카드
약 00:00~00:04
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

참고 영상의 첫 장면은
세로로 긴 하나의 레시피 카드가 중앙 오른쪽에 있고,
왼쪽에는 짧고 굵은 설명 문장이 있다.

전체 배치:

- 어두운 검정 공간
- 왼쪽 설명 약 35%
- 오른쪽 카드 약 65%
- 카드 주변에 아주 약한 금빛 반사
- 화면을 가득 채우지 않고 넓은 검은 여백 유지

왼쪽 문구:

A deck of
living memory recipes.

또는 한국어:

살아 있는 기억을 위한
장면 레시피 한 벌.

영문 문구를 우선 사용하고,
작은 한국어 설명을 아래에 둘 수 있다.

첫 카드 이름:

first-moment-awakening

카드 구조:

상단 미리보기 영역
→ 어두운 영상 썸네일 또는 짧은 SVG 모션

카드 제목
→ first-moment-awakening

상단 버튼
→ Select
→ Preview
→ Apply

분류:

STYLE 01
MOMENT REVEAL

설명:

첫 영상이 천천히 나타나고,
그 순간의 감정과 다음 기억이 뒤이어 열립니다.

태그:

first moment
soft reveal
emotion trace

하단 속성:

Duration    4.5s
Energy      Medium-soft
Samples     3

카드는 참고 영상처럼:

- 짙은 갈색·검정
- 금빛 얇은 외곽선
- 모서리 18~22px
- 내부 구획을 얇은 선으로 나눔
- 금빛 버튼
- 작은 모노스페이스 글자
- 약간 뒤로 기울어진 3D 상태

로 만든다.

초기 모션:

1. 검은 화면에서 작은 금빛 점 등장
2. 카드 외곽선이 순서대로 그려짐
3. 카드가 아래에서 올라옴
4. 왼쪽 문장이 늦게 등장
5. 미리보기 영역의 작은 모션 시작

카드를 단순히 opacity로만 나타내면 안 된다.

translateZ, rotateY, rotateX를 함께 사용한다.

6. SCENE 02 · 기억 장면 라이브러리 보드
약 00:04~00:08
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

첫 카드가 회전하고 뒤로 물러나면서
여러 레시피 카드가 있는 전체 보드로 변환된다.

화면 제목:

Memory Scene Recipes

보조 문구:

Choose how your moments move, connect and return.

보드 구조:

- 상단 헤더
- 검색
- 감정 온도 필터
- 카드 그리드
- 하단 상태 문구
- 우상단 보기 전환 버튼

보드 전체:

- 가로형 대형 프레임
- 약간 사선으로 기울어져 있음
- 금빛 테두리
- 프레임 바깥쪽에 번지는 오렌지 광원
- 검은 공간 속에 떠 있음
- 뒤쪽에 얇은 사각형 선 여러 개
- 사각형 선은 서로 다른 깊이에 위치

카드 그리드:

- 3열 × 3행 또는 4열 × 2행
- 흰색 또는 밝은 미리보기 패널
- 아래쪽은 짙은 카드 정보
- 선택된 카드는 민트 또는 로즈 테두리
- 전체 카드 스타일은 동일하지만 미리보기 모션은 서로 다름

보드가 나타날 때:

1. 첫 카드가 작아지며 보드의 한 칸으로 이동
2. 다른 카드가 40~70ms 간격으로 등장
3. 외곽 금빛 프레임이 그려짐
4. 카메라가 보드 정면으로 이동
5. 보드가 짧게 호흡하듯 확대

단순히 새 화면으로 잘라 전환하지 않는다.

첫 카드가 실제로 보드 안으로 합쳐지는
shared-object transition처럼 보여야 한다.

9. SCENE 04 · 3D 카드 갤러리 비행
약 00:14~00:19
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

라이브러리 보드가 다시 등장하지만
이번에는 정면이 아니라 큰 3D 공간 안에 배치된다.

중요한 장면:

- 카메라가 보드 왼쪽에서 오른쪽으로 이동
- 카드가 여러 깊이에 떠 있음
- 일부 카드는 보드 바깥으로 돌출
- 아래쪽에 반사 또는 그림자
- 오른쪽에 선택 레시피 상세 카드
- 공간 전체가 약간 휘어 보이는 원근감
- 금빛 얇은 라인이 배경을 통과

하단 문구:

12 recipes,
every feeling tuned.

또는 데이터 수와 맞추어:

12 recipes.
24 motion samples.
Still growing.

실제 데이터 수와 문구 숫자가 일치해야 한다.

구현 방식:

- CSS perspective
- transform-style: preserve-3d
- translateZ
- rotateY
- rotateX
- requestAnimationFrame 기반 카메라 이동

갤러리 전체를 평면 이미지로 회전시키지 않는다.

각 카드 또는 카드 그룹이
서로 다른 Z축 위치를 가져야 한다.

카메라 경로:

1. 왼쪽 측면에서 진입
2. 선택 카드 가까이 이동
3. 중앙 통로를 지나감
