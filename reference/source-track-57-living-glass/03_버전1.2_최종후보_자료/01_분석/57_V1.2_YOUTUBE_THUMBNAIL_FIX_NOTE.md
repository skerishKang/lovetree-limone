# Track 57 V1.2 — YouTube Live Thumbnail Sync

## Owner defect reproduced
V1.1 updated `sourceUrl/mediaUrl` but did not update `thumbnailUrl` or the Living Glass Card `<img>` after save.

## Baseline copied behavior
`01_러브트리_첫여정통합_v1.html` uses:
- URL input event
- `youtubeId()` parsing
- `https://img.youtube.com/vi/{ID}/hqdefault.jpg`
- immediate preview before save

## V1.2 patch
- `youtubeThumbnail(id)` helper
- edit modal Live Preview on every input event
- watch / youtu.be / shorts parsing preserved
- save updates `thumbnailUrl`
- save updates actual `.card-media img` and detail image
- subsequent YouTube URL replaces thumbnail immediately
- YouTube viewer keeps inline iframe attempt and always exposes `YouTube에서 재생 ↗` fallback
- V1.1 selected bloom / tilt / glare / spring / Connection arrival are untouched.
