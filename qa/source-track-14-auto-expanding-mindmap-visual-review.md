# Track14 source ↔ native visual review rubric

This file defines the human review vocabulary for Issue #488 evidence.

## MATCH

Use when source and native preserve the same visible design grammar:
- paper/cream atmospheric field;
- rounded translucent stage shell;
- root-first spatial hierarchy;
- curved branches and compact relation labels;
- premium light node cards with rose/sage/lavender/gold accents;
- staged unfold rhythm and progress rail;
- selected-branch emphasis with unrelated context dimming;
- compact top toolbar;
- mobile progressive vertical hierarchy.

## AUTHORIZED_NATIVE_DELTA

Allowed only for:
- canonical Moment copy/data replacing source sample content;
- Branch/Orbit/Journey/Timeline as presentation-only layouts instead of source demo entity templates;
- canonical Graph back-navigation;
- keyboard-visible focus;
- touch-safe interaction;
- reduced-motion behavior;
- mobile reflow;
- removal of source-local media/editor writes that would duplicate canonical persistence.

## FIDELITY_DEFECT

Must be repaired before `VISUAL_FIDELITY=PASS`:
- paper composition flattened into a generic dashboard;
- stage loses rounded translucent spatial shell;
- hierarchy becomes a flat list/grid;
- node geometry loses root/child scale distinction;
- branches/WHY NEXT labels become visually weak or absent;
- selected branch no longer isolates related descendants;
- mobile becomes a shrunken desktop canvas;
- unfold sequencing is missing or unrelated to hierarchy;
- typography/spacing materially loses the source's quiet editorial density.

## UNKNOWN

Anything not visually classifiable from the evidence remains `UNKNOWN` and cannot be counted as PASS.
