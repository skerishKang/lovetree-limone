# LoveTree Mainframe-style Hero V1

Mainframe hero prompt의 레이아웃/모션 구조를 유지하면서 LoveTree 문구로 교체한 독립 후보입니다.

## 실행

```bash
npm install
npm run dev
```

## 핵심

- React + TypeScript + Vite + Tailwind CSS
- 전체화면 background video
- 가로 마우스 이동 기반 seek queue 방식 video scrub
- 모바일 메뉴 overlay
- LoveTree 제품 철학 기반 한국어 typewriter copy
- 400ms 후 독립적으로 등장하는 CTA pills
- reduced-motion 대응

## 문구 방향

- 첫 순간 심기
- 러브트리 둘러보기
- 내 러브트리 보기
- 처음부터 다시 걷기
- 발견 → 마음 → 연결 → 다시 걷기

이 파일은 디자인 후보이며 기존 승인본을 덮어쓰지 않습니다.
