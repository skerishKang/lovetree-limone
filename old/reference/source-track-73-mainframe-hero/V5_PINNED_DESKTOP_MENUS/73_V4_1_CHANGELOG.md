# Track 73 V4.1 변경 기록

## 변경 목적
- 데스크톱 상단 `둘러보기`, `내 러브트리`, `이야기`, `가이드` 하위 메뉴가 너무 빨리 사라져 항목 클릭이 어려운 문제 수정.

## 적용
- hover 자동 열림/자동 닫힘 제거.
- 메뉴 제목을 클릭하면 해당 하위 메뉴가 고정됨.
- 같은 메뉴 제목을 다시 클릭하면 닫힘.
- 다른 상단 메뉴를 클릭하면 이전 메뉴는 닫히고 새 메뉴만 고정됨.
- 메뉴 바깥 클릭 또는 ESC에서 닫힘.
- 메뉴 내부 클릭은 바깥 클릭으로 처리하지 않음.
- 실제 항목 선택 뒤에만 메뉴가 닫힘.
- 팝오버 간격 16px → 8px로 축소.

## 타자기 효과음
- Google Drive에서 `typewriter`, `타자기`, `타자기 소리` 이름의 오디오 자산을 검색했으나 실제 오디오 파일을 찾지 못함.
- 외부 음원을 임의 추가하지 않음.
- V4 합성 효과음 및 기본 OFF 상태 유지.
