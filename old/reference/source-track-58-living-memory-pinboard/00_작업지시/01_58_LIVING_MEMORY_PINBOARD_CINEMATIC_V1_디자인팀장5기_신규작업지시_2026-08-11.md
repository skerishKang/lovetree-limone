**Moment가 콘텐츠보다 먼저다.**
사진, 영상, 링크는 Moment 안에 들어가는 Source/Media다.

# 11. 실제 PIN TO BOARD 플로우

버튼:

**`+ MOMENT 꽂기`**
또는 한국어 우선:
**`+ 순간 꽂기`**

누르면:

- 사진
- 영상
- 링크
- YouTube
- 글/메모

선택.

## 새 Moment 생성 연출

이 장면이 핵심 브랜드 모션이다.

1. board가 아주 조금 depth blur
2. 새 media가 화면 앞쪽에서 materialize
3. card frame이 형성됨
4. card가 3~7° 정도 자연스러운 각도로 board에 내려앉음
5. **Memory Pin이 위에서 내려와 card를 실제로 고정**
6. 작은 spring impact
7. pin 주변에 emotion-colored light pulse
8. card shadow가 settle
9. `저장됨` 대신 아주 짧은 `Moment saved` / `순간이 꽂혔어요` 피드백
10. 선택된 parent Moment가 있으면 Connection이 이어서 자람

단순 `opacity:0 → 1` 금지.

# 12. Card Landing Physics

하지만 무질서해서도 안 된다.

중요:

**같은 카드가 매번 흔들리는 장난감 UI가 아니라
한 번 “착지하고 기억판에 정착”하는 느낌이어야 한다.**

# 14. Connection 생성 모션

사용자가 카드 A의 pin에서
카드 B의 pin으로 연결.

단, 55의 전문 free-wiring router를 다시 만들지 않는다.

58에서는 **간단하고 아름다운 연결**이면 된다.

### Gesture

Desktop:

`pin A drag → pin B`

Mobile:

`pin A tap → pin B tap`

### 생성 연출

1. A pin halo
2. luminous tip이 cursor/touch를 따라옴
3. B pin 근접 시 magnetic glow
4. 놓는 순간 thread가 tension을 잡으며 settle
5. 작은 light wave가 A→B로 한 번 흐름
6. WHY NEXT 입력 sheet 열림

# 15. WHY NEXT

Connection은 장식선이 아니다.

사용자에게:

**`왜 이 순간 다음으로 이어졌나요?`**

입력.

예:

`표정이 계속 생각나서 다른 직캠을 찾아봤어요.`

LUPT가 관계를 정하지 않듯,
58에서도 시스템이 사용자의 감정 인과를 마음대로 만들지 않는다.

# 19. CINEMATIC REPLAY 시퀀스

단순히 선 색만 바꾸는 Replay 금지.

최소 20~30초 데모.

## SCENE 0 — Darkness / Memory Awake

- dark plum space
- board silhouette
- ambient particles/petal dust
- 0.5~1초 정적

## SCENE 1 — First Moment

camera/viewport가 First Moment로 천천히 push.

- surrounding cards dim
- First Moment media comes alive
- photo subtle depth
- video면 muted short preview
- emotion halo

## SCENE 2 — Connection Awakens

First pin에서 thread가 빛남.

- hot tip
- soft trail
- WHY NEXT phrase reveal
- camera follows thread

53의 path-travel 원리는 참고 가능하지만
기존 엔진을 억지로 복사하지 않는다.

## SCENE 3 — Next Moment Arrival

다음 card로 camera glide.

- card lifts 4~10px
- pin pulse
- media preview
- note fragment
- source/date

## SCENE 4 — Branch

분기 Moment에서는
두 thread가 각각 잠깐 살아난다.

사용자가 선택한 path가 메인으로 이어짐.

## SCENE 5 — Memory Montage

2~4개의 Moment를:

- macro close-up
- card edge
- moving photo depth
- video fragment
- link thumbnail
- handwriting/note fragment
- pin halo
- thread travel

로 빠르게 연결.

## SCENE 6 — Whole Board Bloom

camera zoom-out.

여러 Moment와 Connection 전체가 보임.

Connection들이 잠깐 더 밝아지며
**나뭇가지처럼 하나의 살아 있는 감정 구조**로 읽힌다.

억지로 나무 그림을 overlay하지 않는다.

실제 pin/thread 구조 자체가
Tree처럼 느껴져야 한다.

## SCENE 7 — CTA

`내 러브트리로 돌아가기`
`이 경로 다시 걷기`
`Moment 열기`
