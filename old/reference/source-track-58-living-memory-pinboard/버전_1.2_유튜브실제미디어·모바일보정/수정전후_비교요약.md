## 정확한 검증 경계
현재 실행 컨테이너는 외부 DNS/네트워크가 차단되어 있습니다.
따라서 로컬 Chromium에서는 YouTube 요청 실패 → fallback 경로를 실제 검증했고, 실제 public thumbnail URL은 별도 웹 접근으로 존재/이미지 반환을 확인했습니다.
실제 YouTube embed 재생은 네트워크 가능한 제품 오너 브라우저에서 최종 spotcheck가 필요합니다.
