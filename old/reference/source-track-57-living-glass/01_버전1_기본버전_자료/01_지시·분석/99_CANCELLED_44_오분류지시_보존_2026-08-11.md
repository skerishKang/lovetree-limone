# 1. 새 참고영상 실제 분석

## 영상 메타데이터

실제 업로드 원본:

- 해상도: **1904×1068**
- 프레임레이트: **30fps**
- 길이: **약 32.3초**
- 총 프레임: **969**

## 영상에서 실제 확인되는 화면

### 1) Dark graphite full-screen canvas

검은색에 가까운 charcoal/graphite 배경 위에
3개의 컬러 카드가 중앙에 놓인다.

배경은 완전한 단색이 아니다.

- 아주 약한 smoke/cloud
- 넓게 번지는 soft light
- 곡선형 광선/리본처럼 보이는 배경 구조
- 중심 콘텐츠 주변 vignette

가 겹쳐진다.

### 2) 3개의 컬러 Glass Card

대표 색:

- 왼쪽: **violet / indigo**
- 중앙: **rose / magenta**
- 오른쪽: **amber / warm gold**

각 카드는:

- 둥근 모서리
- 반투명 glass surface
- 카드 안쪽 그라데이션
- 카드 주변 넓은 glow
- 작은 icon
- 제목
- 짧은 설명
- 하단 pill CTA

구조다.

### 3) 색이 카드 전체를 칠하는 방식이 아님

색은 flat solid fill이 아니라:

`dark base + translucent color + local bloom + bottom glow`

형태다.

그래서 카드가 네온 사각형이라기보다
어두운 공간에 떠 있는 반투명 기억 조각처럼 읽힌다.

### 4) Pointer / hover 반응

영상에서 커서가 각 카드와 CTA를 오가며
카드가 미세하게 강조되는 상태를 확인할 수 있다.

과도한 flip/zoom이 아니라:

- 작은 brightness lift
- glow 증가
- CTA emphasis
- subtle float/depth

정도가 적절하다.

### 5) 중요한 주의 — 영상만으로 “완전한 자동 마인드맵 전개 엔진”을 확정하지 말 것

영상의 실제 데모 구간에서
수십 개의 노드가 seed에서 순차 생성되는 완전한 auto-unfold 과정은 명확하게 확인되지 않는다.

파일명만 보고 기능을 만들어내지 않는다.

이 영상에서 확실히 가져갈 것은:

**컬러 Glass Card 시각체계 + 어두운 공간감 + 집중/선택 상태 + compact card layout**

이다.

자동전개 기능은 이미 LoveTree 44 v2.4 계열이 가진 기존 엔진을 사용한다.

# 2. 기존 LoveTree 44와의 관계

기존 44는 이미 다음 방향을 가진다.

- seed에서 노드 순차 전개
- Moment / Emotion / Season / Note 시각 구분
- Connection 이유를 선 위 라벨로 표시
- pan / zoom / 선택 / 가지 강조
- Tree Composer / Structure View
- Path / Person / Emotion / Season projection
- 실제 Moment 추가·편집 방향
- 미디어 / YouTube / drag 관련 v2.x 발전

따라서 새 참고영상 때문에
새 마인드맵을 처음부터 만들지 않는다.

이번 V2.5의 공식 결합식:

> **44의 AUTO-UNFOLD ENGINE**
> +
> **새 영상의 COLOR GLASS CARD VISUAL SYSTEM**
> =
> **LoveTree Color Path View V2.5**

# 3. 제품 역할

이번 화면은 일반적인 brainstorming mind map이 아니다.

LoveTree의 핵심 데이터:

`Moment → Connection → Next Moment → Emotional Path → Tree`

를 카드와 선으로 보여주는 **감정경로 구조 보기 / 편집 보기**다.

사용자가 보자마자 이해해야 할 것:

> “내가 저장한 순간들이 감정에 따라 컬러 카드로 펼쳐지고,
> 왜 다음 순간으로 갔는지가 선으로 연결되는구나.”

# 4. 이번 V2.5의 핵심 변화

## 기존 v2.4 데이터/기능은 유지

# 5. 카드 의미 — 랜덤 컬러 금지

참고영상의:

- violet
- rose
- amber

색을 그대로 예쁜 장식으로 랜덤 배정하면 안 된다.

LoveTree에서는 **감정 상태**와 연결한다.

예시:

- 궁금함 / 신비 / 탐색 → violet / indigo
- 설렘 / 애정 / 감동 → rose / magenta
- 확신 / 따뜻함 / 기억의 정착 → amber / gold
- 편안함 / 안정 → cyan/soft blue 보조 가능
- 그리움 → muted violet/rose

정확한 emotion taxonomy는 제품 데이터와 맞춰 적용한다.

중요:

**색은 Moment의 감정을 보여주는 보조 정보다.**
색만 보고 내용을 추측하게 하지 않는다.

카드 안에 감정 텍스트를 반드시 표시한다.

# 6. Moment Card 구조

각 Glass Card는 최소:

- media thumbnail 또는 작은 media cue
- Moment title
- date
- emotion text
- source/media
- 짧은 내 메모
- optional person/season
- Connection 다음 방향 cue

를 가진다.

하지만 첫 화면에서 정보를 너무 많이 노출하지 않는다.

## Compact

평소:

- 작은 미디어 cue
- Moment title
- emotion
- date
- 다음 Connection 개수

## Selected

클릭/선택:

- 카드 크기 약간 확장
- note
- source
- WHY NEXT
- `Moment 열기`
- `다음 경로 보기`

노출.

# 7. First Moment = Seed

일반 마인드맵처럼 가운데 generic topic을 놓지 않는다.

중심 seed는 반드시:

**First Moment**

다.

예:

`처음 눈에 들어온 무대`
`4월 6일`
`설렘`

이 첫 카드에서 시작한다.

초기 상태:

- First Moment만 선명
- 주변은 어둡게
- 0.4~0.8초 정도 hold
- 다음 Connection이 먼저 빛남
- 다음 Moment 카드가 생성

# 8. Auto-Unfold 규칙

이번 V2.5의 핵심 모션.

## 전개 순서

`Moment`
→ `Connection line`
→ `WHY NEXT label`
→ `Next Moment card`
→ `branch`
→ `next cards`

순서다.

카드가 먼저 랜덤하게 튀어나오고
나중에 선을 그으면 안 된다.

**감정 인과관계가 먼저 느껴져야 한다.**

## 추천 타이밍

한 단계당:

1. source Moment focus: 150~250ms
2. Connection line draw: 350~550ms
3. WHY NEXT label reveal: 180~280ms
4. target card bloom-in: 320~500ms
5. settle: 150~250ms

전체는 너무 느리게 하지 않는다.

---

# 9. 카드 등장 모션

금지:

- 큰 bounce
- 3D flip
- 과도한 spring
- 카드가 화면 밖에서 날아오기
- casino UI처럼 glow 폭발

권장:

- opacity 0 → 1
- scale .94 → 1
- y 8~14px → 0
- blur 8~12px → 0
- 해당 emotion color glow가 뒤에서 짧게 bloom

“생성된다”보다
**“기억이 밝혀진다”**는 느낌.

# 10. Connection 시각

참고영상에는 카드 자체가 핵심이지만
LoveTree에서는 선이 더 중요하다.

Connection은:

- 1.5~2.5px
- soft luminous bezier
- idle 상태에서도 끊기지 않고 보임
- selected path는 확실히 밝아짐
- inactive path도 거의 사라지지 않음

색은 카드 컬러를 그대로 이어붙이지 말고
두 Moment 사이를 부드럽게 blend 가능.

## WHY NEXT

선 가운데 또는 curve 가까이에:

`왜 다음으로 갔나요?`

내용:

`이 표정이 계속 생각나서 다른 영상을 찾아봤어요.`

처럼 실제 감정 인과를 보여준다.

---

# 11. Branch

한 Moment에서 다음 Moment가 여러 개라면
실제 나뭇가지처럼 분기한다.

예:

Moment A
→ Connection A-B → Moment B
→ Connection A-C → Moment C
→ Connection A-D → Moment D

분기 시:

- 부모 카드가 잠깐 focus
- 여러 Connection이 순차적으로 갈라짐
- target card들이 fan-out
- 자동 layout이 겹침 방지

단순 가로 3개 고정 배치로 끝내지 않는다.

---

# 12. Auto Layout

카드 수가 늘어나도
겹치거나 화면 밖으로 밀리면 안 된다.

## Desktop

초기 3~7 Moment:

- center seed
- left/right 또는 radial asymmetric fan-out

많아질 때:

- depth/branch hierarchy
- compact spacing
- pan/zoom

## Mobile

desktop 좌표를 축소하지 않는다.

모바일 전용:

- 세로 Path
- 현재 branch 중심
- 다음 Moment 1~2개만 전개
- 다른 branch는 접힘

# 13. Collapse / Expand

많은 Moment를 한 번에 펼치면 복잡해진다.

각 branch에:

- `경로 펼치기`
- `접기`
- `이 경로만 보기`

기능을 둔다.

카드 숫자가 많아질수록
모든 카드를 계속 표시하는 것이 목표가 아니다.

**사용자가 자신의 감정경로를 이해하기 쉬운 상태가 목표다.**

---

# 14. Focus Mode

참고영상의 강점은
중앙 카드 집중감이다.

이를 LoveTree에 적극 적용.

Moment 클릭:

- 선택 카드 100%
- 직접 연결된 카드 80~90%
- 2-hop 이후 45~60%
- 비관련 branch 25~40%

단, 완전히 invisible 금지.

선택한 Moment와 관련 Connection이
즉시 읽혀야 한다.

# 15. Path Replay

기존 44가 가진 자동전개를
단순 “그래프 등장 데모”가 아니라
실제 Path Replay로 사용한다.

버튼:

**`이 경로 다시보기`**

누르면:

1. First Moment focus
2. Connection 흐름
3. WHY NEXT
4. Next Moment
5. 다음 Connection
6. Tree까지

순차 재생.

현재 53에서 검증된 hot-tip/trail engine을
필요할 경우 참고할 수 있으나,
44의 현재 안정 엔진을 불필요하게 교체하지 않는다.

# 24. 첫 화면 Visual Gate

이번에는 56처럼
기술기능만 통과하고 화면이 나빠지는 것을 허용하지 않는다.

코드 완성 전에
**첫 화면 static visual gate**를 먼저 만든다.

Gate 기준:

- 참고영상의 premium glass depth가 느껴지는가
- 카드가 싸구려 neon box처럼 보이지 않는가
- violet/rose/amber가 과포화되지 않는가
- 글자가 충분히 읽히는가
- Connection이 카드보다 약하지만 분명히 존재하는가
- LoveTree Moment라는 의미가 보이는가

Gate가 나쁘면 기능 구현 전에 수정.
