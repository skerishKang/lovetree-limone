이번 V1.1은 제품 행동을 한 단계 더 올리는 수정이다.

# 2. V1.1 핵심 목표

## 목표 A — REAL MEDIA MOMENT

Moment가 다음 media source를 실제로 가질 수 있게 한다.

- image
- local video
- YouTube URL
- general web link
- text-only fallback

특히 YouTube/video Moment는:

**카드 → Moment 열기 → 실제 player → 재생**

까지 연결되어야 한다.

## 목표 B — SELECTED LIGHT BLOOM

카드 click/select 시:

**“내가 이 기억을 선택했다”**

는 감정적 피드백이 한눈에 보여야 한다.

hover와 selected를 명확하게 구분한다.

# 3. 데이터 모델 수정

각 Moment에 다음 필드를 추가한다.

```js
{
  id,
  title,
  date,
  emotion,
  tone,

  mediaKind: 'image' | 'video' | 'youtube' | 'link' | 'text',

  thumbnailUrl,
  mediaUrl,
  sourceUrl,
  sourceLabel,
  startSeconds,

  note,
  privacy,
  next,
  why
}
```

중요:

- `thumbnailUrl`과 `mediaUrl`은 분리한다.
- YouTube는 `sourceUrl` 또는 `mediaUrl`에 실제 URL을 보존한다.
- 원본 URL provenance를 버리지 않는다.
- 사용자 입력 URL과 데모 이미지가 서로 다른데 같은 것처럼 표시하지 않는다.

---

# 4. 카드에 실제 URL 입력 기능 추가

Prototype에서 최소한의 편집 UI를 추가한다.

방법은 둘 중 하나:

### A. `Moment 편집` 작은 sheet/modal
선택한 카드에서:
`편집`

→

- 제목
- 미디어 종류
- `영상/링크 URL`
- 출처
- 내 메모

### B. `미디어 링크 연결`
Detail panel에:
`미디어 링크 연결`

버튼을 두고 URL 입력.

V1.1에서는 A 또는 B 중 하나를 구현하면 된다.

단, **실제로 입력한 URL이 player와 연결되어야 한다.**

입력폼만 있고 카드가 계속 demo image만 보여주면 FAIL.

# 5. YouTube 실제 재생

YouTube URL 형태 최소 지원:

- `https://www.youtube.com/watch?v=VIDEO_ID`
- `https://youtu.be/VIDEO_ID`
- 가능하면 `shorts/VIDEO_ID`

URL에서 video ID를 파싱한다.

`Moment 열기` 클릭 전에는 iframe을 로드하지 않는다.

사용자가 명시적으로 `Moment 열기` 또는 play를 눌렀을 때:

- modal viewer open
- YouTube iframe/player 생성
- 영상 재생 가능

중요:

**카드 전체를 클릭했다고 즉시 영상 autoplay 하지 않는다.**

카드 click = select  
Play / Moment 열기 = playback

역할을 분리한다.

# 6. Local Video 실제 재생

local/demo MP4 Moment도 하나 포함한다.

```html

```

를 사용.

- poster = card thumbnail
- controls 표시

- 다른 Moment 이동 시 기존 재생 stop

실행영상에서 실제 playback이 확인되어야 한다.

# 8. 카드 안의 Play Affordance

`mediaKind === 'video' || 'youtube'`이면
thumbnail 위에 작은 play affordance를 추가한다.

디자인:

- glass circular play button
- 중앙을 가리지 않게 작게
- hover 시 tone halo
- duration 또는 `VIDEO` badge 가능

금지:

- 거대한 YouTube 빨간 버튼
- generic media player skin
- 참고영상보다 카드가 싸 보이는 control

LoveTree glass language 안에 들어가야 한다.

# 9. 카드 클릭 = SELECTED LIGHT BLOOM

현재 selected state는 scale + shadow + 주변 dim이 있으나
제품 오너는 더 확실한 “빛의 선택 반응”을 원한다.

V1.1 selected motion:

## 순간 반응 — 500~800ms

click 순간:

1. card 내부 중심 또는 media 영역에서 emotion light가 켜짐
2. 빛이 card edge까지 빠르게 확산
3. glass border를 한 번 따라 흐르는 edge shimmer
4. back glow가 짧게 bloom
5. card가 1.02~1.04 정도 lift
6. selected state로 settle

느낌:

**“이 기억이 깨어났다.”**

폭발/번쩍임 금지.

# 10. Persistent Selected State

선택 이후에는 hover보다 명확히 강해야 한다.

Selected card:

- back aura +25~45%
- glass border brighter
- tone-colored outer bloom
- media inner highlight
- title contrast slightly up
- selected pin/light mark 또는 작은 `SELECTED MOMENT` cue 가능
- 주변 카드 dim은 현재처럼 유지하되 너무 죽이지 않는다

선택이 유지되는 동안
작은 breathing glow는 가능.

주기:

약 2.8~4.2초의 매우 느린 pulse.

금지:

- 빠른 깜빡임
- continuous neon flicker
- 눈 아픈 white pulse

# 11. Hover vs Selected 분리

반드시 상태가 달라야 한다.

## IDLE
아름답지만 조용함.

## HOVER
- tilt
- cursor glare
- slight glow lift

## SELECTED
- persistent aura
- edge light
- clear depth lift
- detail panel
- selected-state indicator

## PLAYING
영상 재생 중이면
selected 상태 위에 아주 작은 추가 cue.

예:
- play glyph → pause/playing dot
- edge에서 천천히 흐르는 progress-like light

영상 재생 자체보다 UI가 더 시끄러워지면 안 된다.

# 12. Selected → Next Moment Transition

`다음 순간 보기` 시 기존 Connection thread는 유지한다.

추가:

1. 현재 selected card의 bloom이 Connection 출발 edge로 모임
2. luminous thread travel
3. WHY NEXT
4. target card에서 arrival bloom
5. target card가 새로운 selected state가 됨
6. 이전 card는 idle 또는 related state로 내려감

즉:

**Selection Light → Connection Light → Arrival Light**

가 하나의 문법으로 이어져야 한다.

이게 LoveTree다운 차별점이다.

# 15. 외부 리소스 정책

V1 standalone 원칙은 유지하되
**사용자가 명시적으로 입력하거나 demo로 지정한 실제 media URL**은 예외다.

중요:

- 외부 JS/CSS library hotlink 금지
- 외부 폰트 hotlink 금지
- 무관한 image hotlink 금지
- 실제 YouTube/media source URL은 제품 기능상 허용

QA에서 `external_http_refs = 0`을 억지로 유지하기 위해
실제 링크 재생 기능을 막지 않는다.

대신 QA를 분리한다.

- external dependency: 0
- user media/source request: expected

# 16. 보안/UX 기본

Prototype 범위에서도:

- URL scheme은 http/https만 허용
- `javascript:` 등 실행 URL 거부
- external link에는 `rel="noopener noreferrer"`
- 새 창 열기 여부 명시
- iframe은 허용된 video provider만 embed
- 일반 URL을 임의 iframe embed하지 않는다
