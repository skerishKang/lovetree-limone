LoveTree Track 57 — LIVING GLASS MOMENT CARDS V1.1 사용설명서
====================================================================
REAL MEDIA + SELECTED LIGHT BLOOM

1. 이 화면이 무엇인가요?
----------------------
V1에서 승인 대기 중인 Living Glass Moment Card의 시각 방향을 그대로 유지하면서,
두 가지 제품 행동만 보강한 V1.1 후보입니다.

1) 실제 미디어 URL이 Moment의 원본으로 연결되고 `Moment 열기`에서 mediaKind에 맞는 viewer가 열립니다.
2) 카드 선택 순간의 감정색 빛이 더 강하게 깨어나고, 선택 상태가 지속되며,
   그 빛이 Connection을 타고 다음 Moment의 도착 빛으로 이어집니다.

V1 카드의 dark graphite / violet·rose·amber / tilt / glare / spring / glass depth /
layered parallax / Moment 정보 / WHY NEXT는 재설계하지 않았습니다.

2. 30초 빠른 시작
----------------
1) 첫 카드 표면에 마우스를 움직여 기존 tilt / glare를 확인합니다.
2) 카드를 클릭합니다. 카드 전체가 재생되는 것이 아니라 해당 Moment가 선택됩니다.
3) 선택 순간 감정색 bloom, edge shimmer, persistent selected aura를 확인합니다.
4) 상세의 `ORIGINAL SOURCE`에서 실제 연결된 원본을 확인합니다.
5) `미디어 링크 연결`에서 YouTube 또는 일반 http/https URL을 연결할 수 있습니다.
6) `Moment 열기 · 재생`을 눌러 video/youtube Moment viewer를 엽니다.
7) rose 카드의 local demo video는 실제 `<video controls playsinline>`로 재생됩니다.
8) `다음 순간 보기`를 누르면 선택 빛 → Connection 빛 → 도착 빛 순서를 확인합니다.

3. 카드 클릭과 재생은 분리됩니다
-------------------------------
카드 클릭 = Moment 선택
Moment 열기 = 실제 media viewer / playback

카드를 선택했다고 영상이 자동재생되지 않습니다.
이 구분으로 Living Glass Card의 감상성과 실제 재생 행동을 분리했습니다.

4. 실제 미디어 데이터
--------------------
V1.1 Moment에는 다음 필드를 사용합니다.

- mediaKind: image / video / youtube / link / text
- thumbnailUrl
- mediaUrl
- sourceUrl
- sourceLabel
- startSeconds

thumbnail과 실제 원본 URL은 별개입니다.
첫 YouTube 데모 카드는 카드 visual을 보존하기 위해 DEMO POSTER를 사용하되,
`DEMO POSTER · REAL SOURCE`라고 명확히 표시합니다.

5. YouTube URL
-------------
지원 파싱:
- youtube.com/watch?v=...
- youtu.be/...
- youtube.com/shorts/...

`Moment 열기`를 누를 때만 허용된 YouTube embed iframe을 생성합니다.
startSeconds가 있으면 embed의 시작 시점에 전달합니다.

중요 QA 환경 제한:
이 작업 환경의 관리형 Chromium은 외부 YouTube iframe 자체를 관리자 정책으로 차단합니다.
따라서 여기서는 URL 파싱, 실제 Moment 데이터 반영, allowlisted YouTube iframe 생성 계약까지 검증했습니다.
외부 네트워크의 실제 YouTube 영상 프레임 재생은 이 환경에서 독립 확인하지 못했습니다.
실행영상의 실제 재생 증거는 local demo MP4로 검증했습니다.

6. Local / Video Moment
----------------------
두 번째 rose Moment는 실제 local MP4 demo를 가집니다.
viewer는 `<video controls playsinline preload="metadata">`를 생성하고 재생합니다.
viewer를 닫으면 video node를 제거해 재생을 정지합니다.
다른 Moment로 선택을 바꾸어도 기존 player를 정리합니다.

7. Image / Link / Text
---------------------
image → 실제 img viewer
link → 원본 도메인과 `원본 링크 열기` CTA. 임의 iframe embed 금지.
text → text Moment viewer

외부 링크는 http/https만 허용하며 `javascript:` 같은 실행 URL을 거부합니다.
외부 링크 CTA는 새 창 + `noopener noreferrer` 계약을 사용합니다.

8. 미디어 링크 연결
------------------
선택한 Moment 상세에서 `미디어 링크 연결`을 누릅니다.

입력:
- 미디어 종류
- 영상 / 링크 URL
- 시작 초
- 출처 표시

저장 후 현재 Prototype 세션의 Moment 객체가 즉시 바뀌며 `Moment 열기` renderer도 같은 URL을 사용합니다.
V1.1은 서버/DB 편집기가 아니므로 새로고침 후 사용자 입력 URL을 영구 저장하지 않습니다.

9. Selected Light Bloom
----------------------
카드 클릭 순간:
- emotion light wake
- back glow 강화
- border / edge shimmer
- card lift
- selected mark

선택 후:
- emotion aura 유지
- 더 밝은 border
- 느린 breathing glow
- 주변 카드는 약간만 dim

hover는 tilt/glare 중심이고 selected는 persistent aura 중심이라 서로 다른 상태로 읽힙니다.

10. Selection → Connection → Arrival
-----------------------------------
`다음 순간 보기`:
1) 선택 카드의 bloom이 출발 edge로 모임
2) 현재 감정색에서 다음 감정색으로 이어지는 luminous thread
3) 작은 traveling light
4) WHY NEXT 표시
5) 다음 카드 arrival bloom
6) 다음 카드가 persistent selected state가 됨

이것이 V1.1의 LoveTree motion language입니다.

11. 모바일
----------
- touch + small drag: 기존 tilt / glare
- release: spring return
- tap: selected bloom + detail bottom sheet
- video Moment의 `Moment 열기`: playsinline video viewer
- horizontal card collection 유지

12. Reduced Motion
-----------------
prefers-reduced-motion에서는 tilt amplitude를 제거하고 강한 motion animation을 줄이지만,
Moment 선택 / 상세 / media viewer / Connection 정보 기능은 유지합니다.

13. Prototype 한계
-----------------
- V1.1은 아직 제품 오너 승인 전 후보입니다.
- 실제 사용자 DB와 연결되지 않았습니다.
- 사용자 URL 편집은 현재 세션용 Prototype 상태입니다.
- 첫 카드의 visual thumbnail은 DEMO POSTER이고 실제 YouTube 원본과 동일 이미지라고 주장하지 않습니다.
- 관리형 Chromium 정책 때문에 외부 YouTube live playback은 본 QA 환경에서 확인하지 못했습니다.
- local MP4 actual playback은 실제 Chromium에서 반복 검증했습니다.
- Production 배포 / main merge / 실제 사용자 데이터 변경은 없습니다.

V1 원본은 그대로 보존됩니다.
