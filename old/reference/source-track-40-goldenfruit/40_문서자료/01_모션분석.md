# LoveTree 시네마틱 v5.1 — 레퍼런스 재분석 및 보정

기준 영상: `참고-녹화_2026_08_04_00_09_36_547(1).mp4` (70.15초)

## 재분석에서 바로잡은 부분

- 42–49초 구간은 메뉴 카드가 원형으로 빠르게 회전하는 장면이 아니라, 배나무 사이의 열린 하늘에 질문과 가는 연결선이 차례로 배치되는 편집 장면입니다. v5.1은 회전 메뉴를 삭제하고 세 개의 질문과 포인터 선이 순차적으로 나타나도록 수정했습니다.
- 53–61초 구간의 핵심은 남자의 손끝을 따라 별과 선이 그려지는 동작입니다. 생성 폼은 제거하고 별자리 드로잉과 짧은 설명만 남겼습니다.
- 61–69초 구간은 원화 안에 이미 물주기 장면이 있으므로, 별도의 점선형 CSS 물줄기는 중복 장식이었습니다. 해당 오버레이를 제거했습니다.
- 장면 교차 구간에서 다음 장면의 문구가 미리 나타나면서 글씨가 두 겹으로 보였습니다. v5.1에서는 다음 장면의 배경만 먼저 교차되고 문구는 해당 장면이 활성화된 뒤에만 나타납니다.
- 하늘 장면의 문구는 조작 방법을 설명하는 메타 문장 대신 LoveTree의 시간 서사를 설명하는 문장으로 교체했습니다.

## 모션 보정

- 장면 교차를 14% 구간으로 축소하고 텍스트는 단일 장면에서만 표시
- 파편 수 24개에서 12개로 축소
- 금빛 입자 90개에서 38개, 낙엽 38개에서 24개로 축소
- 캔버스 효과를 30fps로 제한하고 관련 장면에서만 렌더링
- 대형 이미지의 상시 `will-change` 제거 및 캔버스 DPR 상한 1.5 적용
