## 3. Moment bubble rule

Each cast uses **one canonical identity source** for Hero and four identity-safe bubble treatments:

- Stage: higher contrast / saturation
- Smile: brighter / warmer crop
- Backstage: quieter monochrome treatment
- Walking: warmer sepia / offset crop

This V2.3 intentionally favors **identity safety and interaction validation** over inventing four unrelated AI faces. The four bubbles are contextual derived crops of the same canonical portrait, not claims of four separately photographed real-world moments.
