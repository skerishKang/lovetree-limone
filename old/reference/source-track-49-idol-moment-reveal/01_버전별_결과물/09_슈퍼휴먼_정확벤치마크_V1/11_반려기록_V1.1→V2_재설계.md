# 1. 실제 V1.1 판정 — 왜 반려하는가

설계팀장이 보고서만 보고 판단하지 않고,
`desktop-visual-gate-v1.1.mp4` 실제 실행본을 직접 검토한 결과다.

현재 영상은 다음처럼 읽힌다.

- 어두운 generic portal/tunnel
- 남성 portrait 한 장
- 흰 배경에 여러 남성 얼굴 cutout
- `MANY MOMENTS`
- 또 다른 portrait
- magenta 배경에 남성 머리 cutout 군집
- 흰 화면
- 또 portrait
- 단순 cyan radial line/tunnel
- 다시 남성 얼굴 군집
- 마지막에 흰빛 Tree
- 작은 portrait들이 Tree fruit처럼 붙음
- `LOVETREE`

이것은 LoveTree cinematic이 아니다.

## 1.1 가장 큰 오류 — MANY MOMENTS를 MANY PEOPLE로 만들었다

LoveTree에서 Moment는 사람이 아니다.

Moment는:

> **내 마음이 실제로 움직인 정확한 장면**

이다.

따라서:

```text
남자 A 얼굴
남자 B 얼굴
남자 C 얼굴
남자 D 얼굴
남자 E 얼굴
```

을 보여준다고 `Many Moments`가 되지 않는다.

현재 결과는:

> **여러 남자 모델 얼굴 쇼릴**

처럼 읽힌다.

---

## 1.2 인물이 장면 안에 존재하지 않는다

현재 group 장면은 full cinematic scene이 아니라
alpha cutout / portrait crop / head collage에 가깝다.

- 바닥이 없음
- 실제 environment 없음
- 인물 간 lighting 통일 없음
- foreground/midground/background가 사진 크기 차이로만 표현됨
- 몸이 없는 얼굴 cutout이 많음
- group choreography가 없음

그래서 K-pop teaser가 아니라:

- 팬 편집 영상
- 포스터 합성
- Canva collage
- PowerPoint motion graphic

처럼 보인다.

---

## 1.3 NCT Superhuman의 핵심을 놓쳤다

Superhuman의 힘은 단순히:

- red
- cyan
- white
- portal

을 쓰는 데 있지 않다.

중요한 것은:

- 실제 공간 안에서 인물이 존재함
- close와 wide 사이의 공간 충격
- group formation
- 인물과 카메라가 동시에 움직이는 장면감
- glass / liquid / aperture가 실제 공간전환으로 작동
- shot마다 조명·세트·인물·카메라가 하나의 사건을 만듦
- 짧은 컷도 "사진 한 장"이 아니라 "장면 한 개"임

이다.

현재 V1.1은 이 구조를
portrait + CSS movement + graphic effect로 축소했다.

---

## 1.4 Connection이 없다

`KEEP THE MOMENT`, `OPEN THE NEXT`라는 글자는 있으나,
관객은 다음 질문에 답할 수 없다.

> **왜 이 순간 때문에 다음 순간을 찾아갔는가?**

그 이유가 영상에 없다.

따라서 LoveTree의 가장 중요한 `Connection`이 없다.

---

## 1.5 마지막 Tree가 앞 장면의 결과가 아니다

현재 Tree는 마지막에 별도의 완성 asset으로 등장한다.

앞서 지나온:

- Moment
- 감정 변화
- Save
- Connection

이 Tree의 가지가 되었다는 인과관계가 약하다.

그래서 마지막 Tree가:

> "이제 LoveTree 로고 보여줄 차례"

처럼 느껴진다.

# 3. LoveTree는 이미 충분히 만들어져 있다

이번에 새 제품 컨셉을 발명하지 않는다.

기존 LoveTree에는 이미 다음 구조가 있다.

## First Journey

```text
첫 순간
→ 마음 남기기
→ 다음 영상 잇기
→ 러브트리 성장
```

## Moment

영상 전체가 아니라:

- 정확한 시간
- 표정
- 말
- 행동
- 무대가 끝난 직후
- 특정 인터뷰 답변
- 특정 웃음
- 특정 손짓

처럼 **내 감정이 움직인 구간**이다.

## Connection

단순 `NEXT`가 아니다.

예:

```text
처음 본 쇼츠
→ 표정이 계속 생각나서 무대를 검색

무대
→ 실력이 예상보다 좋아서 인터뷰 검색

인터뷰
→ 말투가 궁금해서 예능 검색

예능
→ 인간적인 모습이 좋아져 다른 라이브 검색
```

## Tree

콘텐츠 목록이 아니다.

> **내가 그 사람에게 빠져온 감정 경로를 다시 걷는 재생 장치**

다.

# 4. 49 V2의 Semantic Master

49 V2는 아래 10-beat 감정 구조를 고정한다.

Superhuman의 21 shot은 이 10개 의미를 표현하기 위해 재배치한다.

---

## 01 — FIRST GLIMPSE

처음 그 사람을 본다.

아직 팬이 아니다.

한 장면이 이상하게 신경 쓰인다.

### 화면
- PRIMARY male idol 1명
- dark / silver / cyan
- 아주 짧은 close 또는 medium
- 시선, 표정, 움직임 중 하나가 hook

### 감정
`낯섦 → 시선 고정`

### 금지
- 첫 3초부터 여러 남자 얼굴
- 멤버 소개 영상처럼 시작
- 텍스트 설명

---

## 02 — AFTERIMAGE / MEMORY BREATH

첫 장면이 머릿속에 남는다.

같은 PRIMARY다.

### 화면
- reflection
- glass
- half-seen silhouette
- white room glimpse
- frame-within-frame
- 반복되는 한 표정의 잔상

### 감정
`시선 고정 → 궁금함`

---

## 03 — PERSON REVEAL

"저 사람 누구지?"

같은 사람을 더 선명하게 본다.

### 화면
- PRIMARY close
- white / glass 공간
- 얼굴 quality 최우선
- 억지 warp로 얼굴 손상 금지

---

## 04 — DELICATE MOMENTS

사람에게 빠지는 것은 얼굴 한 장 때문만이 아니다.

작은 Moment들이 생긴다.

예:

- microphone 잡는 손
- 공연 직전 숨
- 재킷 detail
- 웃기 전 표정
- 무대 위 발걸음
- 고개 돌리는 0.3초
- interview 중 손짓
- backstage에서 걷는 모습

Superhuman의 rapid cut 에너지는 여기에 사용한다.

### 핵심

> **다른 사람 얼굴 7개가 아니라 같은 PRIMARY의 서로 다른 순간 7개.**

---

## 05 — SAVE THIS MOMENT

처음으로:

> "이건 남겨두고 싶다."

는 사건이 발생한다.

### 표현
- 시간을 멈추는 듯한 exposure shift
- 특정 Moment에 light lock
- glass frame이 잠깐 닫힘
- 작은 pulse
- saved trace가 공간에 남음

SAVE 버튼 UI를 크게 띄우지 않는다.

---

## 06 — CONNECTION / WHY NEXT?

이 영상의 제품 핵심.

Save한 순간 때문에 다른 영상을 찾는다.

예:

```text
무대에서 웃은 순간
→ 평소에는 어떤 사람인지 궁금해짐
→ 인터뷰로 이동
```

### 화면

Superhuman portal 문법을 사용한다.

- saved trace에서 빛이 출발
- light path가 화면 깊이로 뻗음
- camera가 그 길을 따라감
- glass/liquid aperture 통과
- 다음 scene이 실제로 열림

### 절대 조건

Connection은 "예쁜 선"이 아니다.

> **다음 탐색을 일으키는 힘**

처럼 보여야 한다.

---

## 07 — NEXT MOMENT

Connection이 연 다음 장면.

PRIMARY의 다른 면이다.

예:

- Stage → Interview
- Stage → Backstage
- Interview → Live
- Live → Walking
- Walking → Smile

관객이:

> "아, 그래서 이걸 또 보게 됐구나."

를 이해해야 한다.

---

## 08 — DEEPENING / MANY MOMENTS

이제 Moment가 여러 개 쌓인다.

하지만 `MANY PEOPLE`이 아니다.

### 구성

PRIMARY의:

- Stage
- Interview
- Backstage
- Live
- Smile
- Detail
- Performance
- Walking

등이 서로 연결된다.

같은 fictional group의 secondary member는
group/performance context에서만 등장 가능하다.

---

## 09 — MEMORY FIELD / PATH REVEAL

앞서 저장했던 Moment trace들이 공간에 남아 있다.

사진 카드가 둥둥 떠다니는 갤러리가 아니다.

- 먼 곳의 작은 portal
- 빛의 잔상
- 공간 속 saved points
- 지난 Connection path
- 서로 다른 깊이의 기억 흔적

이들이 하나의 경로로 읽힌다.

---

## 10 — TREE EMERGES / LOVETREE

마지막에 새 Tree asset을 갑자기 꺼내지 않는다.

앞의:

- First Moment trace
- Save trace
- Connection 1
- Connection 2
- Connection 3
- Next Moment glow

> **"지금까지 따라온 길이 바로 이 사람에게 빠져온 나의 Tree였구나."**

라고 느껴야 한다.

# 10. Superhuman 21-shot 적용법

21-shot timing을 폐기하지 않는다.

그러나 **21개의 의미를 만들지 않는다.**

10개의 LoveTree beat 안에서
Superhuman shot을 촬영문법으로 배치한다.

예시:

```text
S01–S02  FIRST GLIMPSE
S03      WORLD OPENS / GROUP CONTEXT
S04–S07  DELICATE MOMENT RAPID BURST
S08      PERSON REVEAL HOLD
S09–S10  SAVE → CONNECTION IGNITION
S11–S12  NEXT MOMENT / DIFFERENT SIDE
S13      MEMORY LOCK / GLASS IRIS
S14      PRIMARY HOLD
S15–S18  CONNECTION TRAVEL / PORTAL DIVE
S19      EMOTIONAL CONFIRMATION CLOSE
S20      DEEPENING / GROUP CLIMAX
S21      PATH → TREE → LOVETREE
```

정확한 shot duration은 원본 Superhuman을 참고하되,
LoveTree 의미 전달을 깨뜨리면 ±15~20% 조정 가능하다.

- 전혀 다른 scale의 화면이 연속 등장
- 강한 end-card impact

하지만 금지:

- aircraft
- cockpit
- pilot suit
- radar
- lime HUD
- tactical scan

49는 **Superhuman의 인간·공간·glass·portal 세계**다.

# 13. 기존 LoveTree 디자인에서 가져올 것

LoveTree는 이미 다양한 보기와 성장 구조를 가지고 있다.

이번 49가 새로 발명해야 할 것이 아니다.

다음 의미를 시네마틱으로 압축한다.

- 첫 순간
- 정확한 감정
- 다음 순간으로 간 이유
- 사람별 기억
- 여러 영상기억
- 기억 감상
- connection map
- 대규모 memory field
- 성장하는 Tree
- 다시 재생 가능한 경로

특히 기존 LoveTree의 강점은:

> **콘텐츠를 보여주는 것보다 "내가 왜 이걸 계속 보게 됐는가"를 구조화했다는 점**

이다.

49에서 이것을 잃으면 어떤 K-pop 영상처럼 보여도 FAIL이다.
