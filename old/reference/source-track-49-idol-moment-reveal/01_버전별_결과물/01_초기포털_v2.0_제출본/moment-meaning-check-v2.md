# LoveTree 49 V2 · Moment Meaning Check

## Hero Moment
The Hero is a quiet editorial standing moment. It is treated as the first saved-worthy encounter, not as a profile portrait or identity card.

## What the Reveal opens
Pointer/tap exploration opens four different moments of the same fictional cast: stage performance, smile, backstage candid, and walking-toward-camera. The revealed content is photographic memory content rather than an acrylic or chromatic ornament attached to the face.

## Why this reads as a LoveTree Connection
The interaction establishes the product grammar before any dashboard appears: one moment creates curiosity about another moment. The Field then makes that causality explicit by showing `THIS MOMENT → emotional cause → NEXT MOMENT`. Save follows later, so the user first experiences why moments connect and then records the moment.

## Product meaning sequence
`Hero Moment → Another Moment opens → Follow this moment → Moment Field → Connection reason → Tree Overview → Save Moment`

This directly maps to `Moment → Save → Connection → Next Moment → Tree`, while keeping Save lightweight and Connection emotional rather than graphical.
