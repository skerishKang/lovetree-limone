# LoveTree 49 · 아이돌 모먼트 리빌 포털
## 참고영상 구간별 분석 및 LoveTree 적용맵 v1

- 분석대상: `웹디자인레퍼런스_다중사이트분석.mp4`
- 영상길이: 약 11분 21초
- 해상도: 1904×1068
- 분석목적: 영상 속 여러 웹 레퍼런스의 시각문법을 LoveTree 신규 시안으로 통합하기 위한 설계 근거
- 성격: 참고영상은 하나의 완성 사이트가 아니라, 여러 웹사이트·이미지·AI 제작과정을 넘나들며 디자인을 변형하는 작업 녹화다.
- 따라서 최종 결과는 각 사이트를 그대로 병렬 복사하는 것이 아니라, 영상에서 반복적으로 강했던 시각문법을 하나의 LoveTree 사용자 여정으로 통합한다.

# 1. 구간별 관찰

## A. 00:00~00:40 · 레퍼런스 탐색 / Brandy형 Editorial Hero / Spatial Glass Board

영상 초반에는 여러 레퍼런스가 빠르게 교차한다.

핵심 요소:
- 거의 흰색에 가까운 배경
- 화면 중앙을 압도하는 대형 인물 사진
- 인물을 하단에서 잘라 올려다보는 low-angle portrait
- 좌측의 굵고 큰 Editorial Typography
- 상단 중앙의 검정 pill navigation
- 우측 상단의 숫자/성과형 headline 영역
- 장식이 적고 여백이 매우 큼
- 별도의 레퍼런스로 초원/언덕 사진 위에 반투명 glass card가 떠 있는 공간형 board가 보임
- day/night 상태에 따라 glass card가 white/black으로 바뀌는 구조가 관찰됨

LoveTree 적용:
- 첫 진입은 “기능 설명”보다 한 사람의 강한 Moment를 보여주는 Editorial Hero로 시작
- 거대한 아이돌 얼굴/상반신이 중앙을 점유
- 텍스트는 왼쪽에 최소화
- 상단은 작고 단정한 pill nav
- 이후 자연 배경 위 floating Moment cards로 이동

---

## B. 00:40~02:35 · 동일 인물의 얼굴에 미래형 마스크/컨셉 레이어 합성

영상은 기존 남성 portrait를 유지한 채:
- 하관 중심의 futuristic mask/respirator 계열 이미지를 찾고
- Figma/디자인 툴에서 원본 얼굴과 합성하며
- 같은 인물이 “원본 얼굴 ↔ 마스크가 덧씌워진 버전”으로 변하는 효과를 준비한다.

중요한 점:
- 인물 전체를 새로 그리지 않고 원본 정체성을 유지
- 얼굴 일부만 바뀜
- 합성 오브젝트의 윤곽이 인물 얼굴에 정확히 맞음
- 변화 자체가 Hero의 핵심 인터랙션이 됨

LoveTree 적용:
- literal한 방독면을 필수로 할 필요는 없지만 “Moment Reveal Layer”라는 개념으로 동일한 효과를 사용
- 기본 portrait 위에 concept layer / memory interface / album concept mask가 스크롤 또는 포인터에 따라 나타남
- v1은 SVG/PNG overlay로 구현해 인물 이미지 2장을 새로 만들 필요가 없게 함
- 얼굴 전체를 바꾸는 AI 이미지 전환보다 동일 인물 위에 한 겹이 올라오는 것이 더 중요

---

## C. 02:40~03:35 · 어두운 AI prompt shell

검정 배경 위 중앙에 아주 작은 입력창/카드가 존재하고, 생성 결과가 주변에 붙는다.

LoveTree 적용:
- 최종 화면 자체로 쓰기보다는 “Moment를 부르는 명령/입력”의 미니 인터랙션에 참고
- 과도한 검정 AI 채팅 UI는 LoveTree 메인 스타일로 채택하지 않음

---

## D. 03:35~05:55 · Brandy형 Hero 반복 검증

동일 Hero를 여러 번 수정/재실행한다.

확실한 구조:
- 전체 배경: ivory/white
- 인물: 중앙 대형, viewport 하단을 크게 점유
- 좌측: 대형 2~3줄 headline
- 상단: 로고 + nav
- 우측: 짧은 secondary statement
- 하단 양쪽: 작은 설명/메타
- 인터랙션의 중심은 얼굴의 mask reveal
- 모바일에서는 데스크톱 구조를 단순 축소하지 않고 headline/portrait의 우선순위를 재배치함

LoveTree 적용:
- 신규 49번의 1번 화면은 이 구조를 가장 높은 충실도로 재현
- 여기서는 종이 카드/트리 일러스트를 넣지 않음
- LoveTree의 의미는 copy와 interaction으로만 주입

## E. 05:55~06:20 · Spatial Project Board

강한 두 번째 레퍼런스.

구조:
- full-bleed 자연 사진/초원 배경
- 상단 중앙 floating pill status
- 좌상단 user/avatar 및 작은 toggle
- 카드 6~8개가 일정하지만 기계적이지 않은 grid로 떠 있음
- card는 배경을 비추는 glassmorphism
- 카드 하단에 작은 avatar group
- 일부 카드에 play/action button
- 하단 중앙에 원형 avatar/action dock
- light / dark 전환에서 같은 spatial layout을 유지하고 재질만 바뀜

LoveTree 적용:
- “내 트리의 방(Room)”이 아니라 “Moment Field”로 해석
- 각 glass card = 하나의 Moment
- 배경의 자연 풍경 = 기억을 걷는 공간
- 하단 dock = 사람/멤버/작품/감정 filter
- 카드 클릭 → Moment detail / Connection route

## F. 06:25~08:10 · Dribbble/AI 탐색 과정

다양한 dashboard / futuristic / nature UI를 찾아보고 AI 프롬프트에 참고이미지를 붙이는 구간.

LoveTree 적용:
- 특정 Dribbble 카드 디자인 자체보다, 여러 레퍼런스를 조합하여 결과를 만드는 제작방식만 참고
- 최종 49번 화면에는 검색/Dribbble UI를 모사하지 않음

---

## G. 08:10~10:35 · Nature Overview Dashboard

영상 후반에서 가장 중요한 세 번째 레퍼런스.

관찰:
- background 자체가 강한 tropical/nature cinematic photo
- 그 위에 거의 투명한 frame, statistics, side list가 겹침
- 중앙에 `Overview`와 숫자/요약 정보
- left side에 preview/설명 panel
- right side에 action/list
- 요소들이 완전한 solid card가 아니라 배경에 녹아드는 glass/outline 재질
- 배경이 tropical → mountain dusk/night로 교체되어도 동일 UI 구조가 유지됨
- 색상은 배경에 맞춰 자동으로 cool blue / white / green 계열로 적응함

LoveTree 적용:
- 개인 Tree의 “Overview” 화면
- 숫자는 실제 로컬 mock data에서 계산한 값만 사용
- `Moments / Connections / Routes / Replayed`
- 배경은 한 Tree를 대표하는 cinematic landscape
- 카드보다 scenery가 우선
- UI는 scenery 위의 얇은 HUD/Glass
- Tree를 열었을 때 “관리 페이지”가 아니라 “내 기억 속 풍경에 들어온 느낌”을 목표로 함

---

## H. 10:40~11:05 · Social Post / Save Modal

dark social shell 중앙에 post composer가 떠 있고, 저장 동작 후 작은 confirmation modal이 나타남.

LoveTree 적용:
- 마지막 CTA를 `Save this Moment`
- centered composer/modal
- 현재 image preview
- 한 줄 feeling
- visibility
- person/work tag
- Save
- 저장 후 작은 confirmation
- 메인 페이지의 고급 비주얼과 동일한 radius/blur/timing 유지

# 2. 통합 제품 개념

## 이름
**LoveTree 49 · Moment Reveal Portal**

## 핵심 경험
1. 한 아이돌의 강한 Moment를 Editorial Hero로 만난다.
2. 얼굴/컨셉이 부분적으로 Reveal되며 “이 순간을 더 보고 싶다”는 감각을 만든다.
3. 스크롤하면 화면이 자연 풍경으로 변한다.
4. 풍경 위에 내가 저장한 Moment들이 반투명 카드로 떠 있다.
5. 카드에서 Connection을 따라 다른 Moment로 이동한다.
6. Tree Overview에서는 풍경 속에 내 경로가 녹아 있다.
7. 어디서든 Save Moment modal로 새로운 순간을 추가한다.

LoveTree의 제품철학과의 연결:
- 기본 단위는 Moment
- card는 단순 콘텐츠 카드가 아니라 기억의 입구
- 여러 Moment의 연쇄가 Connection
- landscape는 Tree의 기억 경로를 재생하는 공간
- 저장은 언제나 짧고 쉬운 modal
- 숫자/관리 UI가 scenery를 압도하지 않음

# 3. 채택할 것 / 채택하지 않을 것

## 반드시 채택
- white editorial hero
- 중앙 대형 portrait
- 부분 reveal/mask interaction
- floating pill nav
- full-bleed cinematic landscape
- spatial glass Moment cards
- day/night material switch
- nature Overview
- centered Save Moment modal
- mobile 재배치
- 고급스럽고 느린 cursor/scroll motion

## 채택하지 않음
- 영상 속 원 브랜드명/로고
- Brandy/Kimi/Dribbble/X의 실제 서비스 UI와 텍스트
- 기업 성과 숫자
- 임의의 fake traction
- AI prompt 화면 자체를 LoveTree 메인으로 사용
- 일반 SaaS dashboard처럼 짙은 card wall
- 과도한 neon/SF HUD
- LoveTree 48의 cockpit/aircraft 문법

# 4. 신규 이미지 요구

v1은 기존 자산을 우선 사용한다.

필수 후보:
1. HERO_PORTRAIT
   - 청년 남성 아이돌/연습생 느낌
   - low-angle
   - head + shoulder
   - ivory/white background
   - 정면 또는 아주 약한 3/4
   - 감정은 차분하고 자신감
   - 텍스트/로고 없음
   - 4:5~3:4
   - 2000px 이상

2. HERO_REVEAL_OVERLAY
   - 인물 자체를 새로 생성하지 말고 transparent PNG/SVG overlay 권장
   - 하관/턱/볼 일부를 감싸는 futuristic concept layer
   - 투명/금속/유리 혼합
   - 원본 얼굴을 가리지 않고 identity 유지

3. LANDSCAPE_DAY / LANDSCAPE_NIGHT
   - 같은 구도의 언덕·들판·산·계곡
   - 한 쌍
   - 16:9 또는 21:9
   - 사람이 없어야 함
   - day/night morph가 자연스럽게 읽혀야 함

4. MOMENT_THUMBNAILS
   - 신규 생성 금지 우선
   - 기존 LoveTree 48의 승인 및 재활용 승격 이미지에서 8~16개 사용
   - 서로 다른 얼굴/각도/전신/무대/클로즈업을 섞음

---

# 5. 최종 판단

이 영상의 LoveTree 적용 핵심은 “예쁜 대시보드”가 아니다.

**사람 → Reveal → 풍경 → 떠 있는 순간들 → 기억의 Overview → Save**

라는 시각 여정이다.

신규 49번은 이 흐름을 하나의 실제 작동 HTML로 구현해야 한다.
