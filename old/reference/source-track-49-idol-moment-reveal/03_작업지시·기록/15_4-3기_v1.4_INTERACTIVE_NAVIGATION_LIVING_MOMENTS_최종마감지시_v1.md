## 1. 상단 Navigation

얇은 cinematic chrome으로 다음을 실제 동작하게 한다.

`LOVETREE | HOME | CHAPTERS | MOMENTS | TREE`

우측에는 `SOUND | REPLAY | ENTER`.

- HOME → 0초
- CHAPTERS → chapter selector
- MOMENTS → Moment navigator
- TREE → Tree Climax 시작점
- REPLAY → 0초부터 재시작

## 2. Seek Bar + Chapter Marker

전체 timeline을 클릭/드래그해 이동할 수 있게 한다. 단순 `<video>` seek가 아니라 timeline engine state를 해당 시점에 복원해야 한다.

권장 chapter:

FIRST GLIMPSE / AFTERIMAGE / DETAIL / SAVE / CONNECTION / NEXT MOMENT / MEMORY FIELD / TREE.

PREV/NEXT는 chapter 기준으로 이동한다.

## 3. Moment Grid

기존 8개 PRIMARY Moment를 grid/navigator로 보여주고 클릭 시 해당 teaser time으로 seek한다.

Tree의 8개 Moment도 clickable media node로 바꾼다.

## 4. Living Moment

GIF를 기본으로 쓰지 않는다. 가능하면 2~5초 MP4/WebM micro-loop + poster fallback을 사용한다.

권장 v1.4:

- 4개 Living Moment: singing / smile / looking back / stage performance
- 4개 premium still: eye / profile / white room / corridor

모든 카드가 동시에 움직이면 산만하므로 최종 안정 상태에서는 hover한 Moment만 재생하거나 1개씩 순차 재생한다.

실제 motion source가 없고 video generation을 사용할 수 없으면 정지 이미지를 허위 영상처럼 처리하지 않는다.

## 5. Broken Media = 0

현재처럼 사진이 보이다가 broken icon으로 바뀌는 상태는 절대 허용하지 않는다.

원인 조사:

- initial src vs Tree-state src
- relative path
- standalone embedded asset
- lazy loading/preload
- object URL lifecycle
- state transition source replacement

Fallback chain:

VIDEO → POSTER → EMBEDDED FALLBACK.

CSS로 broken icon만 숨기는 것은 금지한다.
