# 3. LoveTree 의미 구조는 변경 금지

LoveTree의 기본 단위는 사람이 아니라 **마음이 움직인 Moment**다.

Connection은 단순 다음 컷이나 사람 관계가 아니라:

> **이 Moment 때문에 왜 다음 Moment를 찾아갔는가**

라는 감정의 인과관계다.

이번 49는 반드시 다음처럼 읽혀야 한다.

```text
한 사람을 처음 봄
→ 이상하게 기억에 남음
→ 더 자세히 봄
→ 작은 행동과 디테일이 마음에 걸림
→ 이 순간을 저장하고 싶어짐
→ 그 순간 때문에 다음 콘텐츠를 찾음
→ 같은 사람의 새로운 면을 발견
→ 여러 Moment가 누적
→ 그 Connection 경로가 하나의 LoveTree가 됨
```

절대 규칙:

> **MANY MOMENTS ≠ MANY PEOPLE**

---

## 4.2 PRIMARY MASTER REFERENCE PACK 먼저 만든다

새로운 캐릭터를 생성하는 단계가 아니다.

현재 POC와 storyboard에서 가장 잘 나온 동일 인물 frame을 추려 **identity reference pack**을 만든다.

필수 6~8장:

1. clean medium
2. clean 3/4 face
3. profile
4. dark cyan
5. white/high-key
6. red/magenta
7. stage/performance
8. natural human expression

### 제외

- 해상도가 낮아 얼굴이 뭉개진 frame
- 극단적인 close-up으로 비율이 달라진 frame
- motion artifact가 있는 frame
- 같은 사람인지 애매한 frame

이 Reference Pack은 이후 모든 scene generation / video generation의 **강제 identity anchor**다.

# 7. STEP 1 — HIGH-RES SCENE MASTER

각 storyboard 핵심 frame을 먼저 **고해상도 16:9 Scene Master**로 복원한다.

## 중요

Storyboard를 text prompt로 설명하고 처음부터 새로 생성하지 않는다.

반드시:

1. 해당 storyboard frame을 visual reference로 사용
2. PRIMARY_MASTER_V2 reference pack 동시 사용
3. 구도 유지
4. camera distance 유지
5. color/lighting 유지
6. environment 유지
7. facial identity 유지

한다.

### 권장 최소 해상도

```text
1920×1080 이상
```

가능하면 더 높은 원본 master를 사용한다.

### Scene Master PASS 질문

> Storyboard 왼쪽, Scene Master 오른쪽에 놓았을 때  
> **“같은 장면을 고해상도로 다시 만든 것”**처럼 보이는가?

NO면 다시 만든다.

# 8. STEP 2 — Shot Motion Clip

Scene Master가 통과한 뒤에만 움직인다.

각 shot을 독립 영상 clip으로 만든다.

권장:

```text
1920×1080+
30fps 이상
가능하면 60fps master
```

## 핵심

정지 이미지를 화면 안에서 이동시키는 것이 아니라:

- subject micro-motion
- eye/head movement
- hair/cloth response
- body turn
- walking
- stage movement
- camera push/pull
- parallax
- foreground pass
- lighting shift
- reflection change
- glass refraction
- environmental depth

를 만든다.

# 9. 생성형 영상 사용 시 강제 규칙

스토리보드와 얼굴이 영상 생성 단계에서 변질되는 것이 가장 큰 위험이다.

따라서 shot 생성 시:

## 필수

- PRIMARY reference image 사용
- Scene Master를 first-frame 또는 강한 visual reference로 사용
- 가능한 경우 start/end frame anchor 사용
- 한 shot에서 motion을 과도하게 요구하지 않음
- 얼굴이 크게 변형되는 camera rotation 금지
- 필요한 motion만 짧게 생성

## 금지

- text prompt only
- "비슷한 남자 아이돌" 재생성
- extreme facial morph
- 새 hairstyle
- 새 clothing design
- 과도한 head turn로 identity 붕괴
- 필요 없는 lip movement
- AI가 임의로 background person 생성

# 10. Close-up 규칙

제품 오너는 현재 남성 identity 자체는 긍정했지만,
**지나치게 가까운 close-up과 품질 저하 shot은 별도 보완 대상**으로 봤다.

따라서:

- extreme close-up 남발 금지
- 눈/코/입만 남는 crop 금지
- 얼굴이 화면 높이의 대부분을 차지하는 장면 최소화
- close가 필요한 경우 clean face fidelity가 확보된 shot만 사용

권장 중심:

```text
medium close
chest-up
3/4 close
medium
full/half-body spatial shot
```

즉:

> **좋은 얼굴을 더 크게 보여주는 것이 아니라, 좋은 인물이 멋있는 장면 안에 존재하게 한다.**

# 11. 화질 Gate

이번 12초 POC에서 제품 오너가 지적한 가장 명확한 기술 문제 중 하나는 **일부 shot의 화질 저하**다.

Full 제작 전 모든 shot은 다음을 통과해야 한다.

- 얼굴 선명도
- 눈/입 artifact 없음
- skin texture 무너짐 없음
- hair edge 안정
- background compression 없음
- body anatomy 이상 없음
- motion smear 과다 없음
- low-res 확대 없음

### 절대 금지

저해상도 원본을:

```text
cover
scale(1.2)
blur
grain
```

으로 감춰 사용하지 않는다.

# 12. 10-Beat Semantic Master

현재 storyboard의 의미 구조는 그대로 유지한다.

## Beat 1 — FIRST GLIMPSE
처음 눈이 멈춘 순간.

## Beat 2 — AFTERIMAGE / MEMORY BREATH
첫 장면이 계속 기억에 남음.

## Beat 3 — PERSON REVEAL
"저 사람 누구지?"가 선명해짐.

## Beat 4 — DELICATE MOMENTS
손, 마이크, 시선, 움직임, stage detail 등 작은 순간.

## Beat 5 — SAVE THIS MOMENT
"이 순간은 남겨두고 싶다."

## Beat 6 — CONNECTION / WHY NEXT?
이 순간 때문에 다음 콘텐츠를 찾음.

## Beat 7 — NEXT MOMENT
같은 PRIMARY의 새로운 면.

## Beat 8 — DEEPENING / MANY MOMENTS
한 사람의 여러 Moment가 축적.

## Beat 9 — MEMORY FIELD / PATH
Saved Moment와 Connection이 하나의 경로로 누적.

## Beat 10 — TREE EMERGES / LOVETREE
그 경로가 마지막에 LoveTree였음을 reveal.

# 20. HTML의 역할을 제한한다

HTML은 영화 제작 도구가 아니다.

Final cinematic이 승인된 뒤 HTML은:

- preload
- play
- sound
- skip
- replay
- ENTER LOVETREE
- responsive framing
- Moment detail interaction

만 담당한다.

### 금지

- HTML에서 portrait를 움직여 missing shot을 대체
- CSS `scale/translate`로 camera motion 재제작
- DOM panel을 추가해 storyboard를 수정
- video 품질 부족을 glow/blur로 가림
