# LoveTree 49 / 4-3기 — v1.1 페이싱·SAVE 정지·Tree Climax 강화 수정지시

**문서 상태:** 대화 지시 복원본  
**적용 대상:** 49 첫 dynamic website 후보 이후 수정  

## 문제

첫 후보는 전체 재생이 너무 빠르게 느껴졌고, SAVE UI가 실제 사용자 클릭을 기다리지 않았으며 마지막 LoveTree가 약했다.

## 수정 원칙

전체 사이트를 다시 설계하지 않는다. 기존 컷과 자산을 보존한 채 다음만 고친다.

### 1. Pacing

- 본편은 약 34초 수준으로 여유를 확보
- impact microcut은 유지하되 beauty hold를 더 확보
- SAVE 이후 Connection/Tree로 갈수록 의미를 읽을 시간을 준다

### 2. SAVE

SAVE는 자동 통과가 아니라 **interactive gate**다.

- timeline 실제 정지
- 사용자가 `SAVE THIS MOMENT` 클릭할 때까지 기다림
- 클릭 후 `SAVED ✓`
- Connection 점등
- 그 다음에 재생 재개
- Desktop/Mobile 모두 실제 클릭 검증

### 3. TREE CLIMAX

Tree는 짧은 ending icon이 아니라 충분한 climax 구간을 갖는다.

- root ignition
- trunk activation
- branch spread
- Moment frame border glow
- moving light tip/trail
- final LOVETREE hold

Tree 구간은 약 9초 수준까지 허용한다.

## 보존

- 기존 PRIMARY
- 기존 storyboard/shot order
- teaser takeover
- Save → Connection → Next Moment → Tree 인과
- 기존 버튼 및 기본 사이트 쉘

## 금지

- 새 캐릭터 생성
- 새 storyboard
- 컷 전체 재제작
- Tree 때문에 앞부분 teaser를 희생

## PASS

사용자가 실제 SAVE를 누를 수 있고, 재생이 그 순간 멈춰 기다리며, 마지막 Tree가 충분한 시간과 존재감을 갖는다.
