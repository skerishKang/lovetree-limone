# V1.2 UX Changelog

## 문제
엔진은 임의의 Moment pair를 막지 않았지만 V1.1은 `OUT → IN`만 시작 가능했고 exact port drop 의존도가 높아 사용자가 일부 연결이 안 된다고 느낄 수 있었다.

## 변경
1. 어느 socket에서든 wiring 시작
2. 내부 semantics는 OUT=source / IN=target 유지
3. 반대편 socket과 card-edge magnetic snap
4. OUT→OUT / IN→IN / SELF / DUPLICATE 이유를 pointer 근처에 표시
5. duplicate는 기존 edge 자동 선택
6. WALK 중 socket pointerdown이 LUPT보다 우선
7. idle/dim/memory opacity 가독성 상향
8. HOW TO WIRE / state legend 추가
9. endpoint 계산을 실제 socket 중심과 일치하도록 보정

## 유지
V1.1 Memory Patchbay visual template, one-to-many, many-to-one, Moment live reflow, LUPT shared-route drag, manual bend, rewire, delete/undo, SVG path walk, hot tip/trail/arrival.
