# 작업 과정

1. 무료 MotionSites 원본 구조를 A/B 비교용으로 재현.
2. LoveTree 문구로 단순 치환했으나, 원본 여성 영상과 레이아웃 의존성이 높아 독창성 부족 판단.
3. A/B/C 세 방향 제안:
   - A 인물 중심 시네마틱 포털
   - B 기억 파편 중심
   - C 제품 감정경로 인터페이스
4. 사용자는 A안부터 제작 지시.
5. `02_디자인팀/캐릭터` 폴더를 조사했으나 여러 후보가 이미 68 등에서 사용되었고, 일부는 시각 수준 미달로 폐기.
6. 제품 오너 피드백에 따라 여성 대신 남성으로 전환.
7. 정면 응시, AI/기계성과 인간성이 동시에 느껴지는 남성 키비주얼 신규 생성.
8. 해당 비주얼을 기준으로 영상 없는 정적 시네마틱 HTML V4 구현.
9. 현재 V4는 visual direction 후보이며, 다음 단계는 실제 디자인채택본 링크 연결.
