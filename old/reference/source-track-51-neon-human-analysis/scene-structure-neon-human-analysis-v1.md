# LOVETREE · NEON HUMAN ANALYSIS PROMO GATE v1
## Scene Structure

상태: 신규 병행 홍보 대문 시안 / 기존 Neon Pilot 수정선과 분리  
결과물: `lovetree-neon-human-analysis-promo-gate-v1.html`

## 1. HERO / ANALYSIS GATE
목표: 첫 화면만 보아도 LOVETREE 홍보 대문으로 읽히면서 참고티저 계열의 이상한 분석미를 즉시 전달.

구성:
- Core 5 synthetic cast low-key group hook
- 단일 lead synthetic face
- neon-lime radial burst
- orbit / lens / route line / signal chips
- headline: `KEEP THE MOMENT THAT MOVED YOU`
- CTA: `SCAN THE MOMENT`, `FOLLOW THE SIGNAL`

해석:
- 사람은 분석 대상이면서 동시에 감정적으로 끌리는 Moment의 중심.
- 멤버 소개표가 아니라 한 장면이 신호가 되는 입구.

## 2. HUMAN ANALYSIS / SIGNAL REVEAL
목표: LoveTree를 단순 저장 서비스가 아니라 순간의 흔적을 읽고 다시 연결하는 지능형 아카이브처럼 보이게 함.

구성:
- body scan / scanbar
- skeleton-like grid
- waveform
- radar sweep
- replay / afterimage / next moment state
- multi-panel dossier
- White Exhibition
- clean face / eye lens

스크롤 phase:
1. biometric / radar
2. white exhibition
3. face / eye focus

금지:
- POWER / CHARM / 능력치표
- 캐릭터 이력서
- 눈알 단독 극단 확대
- black fringe / dirty skin

## 3. THERMAL CITY / MOMENT DESTINATION
목표: 포착된 순간이 향하는 감정적 목적지.

구성:
- black 기반에서 thermal event color로 전환
- synthetic lead full-body silhouette
- city silhouette
- luminous route
- `MOMENT DESTINATION`

팔레트:
- 기본: black / charcoal / neon-lime
- 이벤트: cyan / magenta / violet / orange-red

## 4. MOMENT CONNECTION / MOMENT FLOW
목표: LoveTree의 핵심 철학을 서비스 대문 안에서 분명히 연결.

중앙:
- 현재 Moment 1개

주변:
- LIVE STAGE
- FANCAM
- NEXT MOMENT
- SHORTS
- INTERVIEW
- SAVED

의미:
`사람 A → 사람 B`가 아니라
`좋아했던 한 장면 → 다음 탐색 → 다음 감정`

메시지:
`ONE MOMENT OPENS THE NEXT`

## 5. MOMENT SAVED / BRAND CLOSE
목표: 저장되는 것이 사람 목록이 아니라 단 하나의 Moment라는 인상으로 마감.

구성:
- Thermal Moment 1개
- 작은 `MOMENT SAVED` signal
- glowing heart core
- 대형 `LOVETREE`
- `SAVE THE MOMENT THAT MOVED YOU`
- `FOLLOW THE MOMENT`

## Interaction
- pointer movement → Hero parallax / orbit response
- Hero face zone → lens focus emphasis
- dossier hover → selected fragment lift / glow
- network node hover → route node emphasis
- CTA click → saved heart / logo pulse
- scroll → analysis phase switch + global progress
