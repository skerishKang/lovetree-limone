## Visual strategy
This V6 final deliberately stops shader iteration. The visual authority is the Reference 18s frame. The candidate uses a static, pre-rendered composition so the right-side Jelly/Glass cluster reads immediately in the same design family.

## Composition
- Black viewport border and centered white editorial page retained.
- Left layout retained: LoveTree logo, short copy, black circular MY TREE CTA.
- Giant typography uses PATH / MOMENT / MEMORY / LOVE with aggressive crop and overlap.
- Right cluster uses six independent solid transparent jelly/glass surfaces, not rings/donuts/annuli.
- Six objects vary in bounding box, rotation, overlap and viewport crop.

## Optical surface
For this final candidate, the priority is appearance rather than WebGL physics. The Jelly cluster is pre-rendered from the Reference optical family and composited over the LoveTree layout. Optical cues retained include:
- clear center
- strong local refraction/distorted typography
- double-edge optical thickness
- local black reflection
- blue / amber / red caustic accents
- thin white specular
