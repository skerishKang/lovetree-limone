# Track16 V1 구현요약

## 엔진
- Vanilla WebGL2. Three.js/CDN 불사용.
- 420 subdivision의 연속 helix ribbon 1개와 companion ribbon 2개.
- 8개 Moment는 하나의 8192×1024 atlas에서 연속 UV로 배치되어 card gap 없이 구조물 표면에 붙는다.
- Drag yaw/pitch + inertia, wheel focus navigation, screen-space hover/focus.

## LoveTree 문법
- 각 Moment: 번호 / 날짜 / 이미지 / 감정 / 한 줄 기억.
- 각 Connection: `왜 다음 순간으로 갔는가` 문장을 명시.
- 상세 전환은 modal fade가 아니라 taper ribbon clip-path가 화면 전체로 펴지는 방식.

## 성능
- 첫 화면 비디오는 autoplay하지 않음.
- detail에서 Moment 03만 로컬 MP4 재생.
- atlas는 단일 GPU texture로 사용.
