# 2. C1 PASS 사유

## 2.1 Connection과 Archive Order가 분리됨

C1 Viewer는 다음 위계를 지킨다.

1. Connection reason
2. 연결된 순간으로
3. Replay
4. Archive 이전/다음

따라서 단순 목록 순서와 감정 인과가 UI에서 섞이지 않는다.

---

## 2.2 대표 Emotional Path가 metadata 근거를 가짐

대표 경로:

```text
m14 설렘
→ m16 궁금함
→ m17 궁금함
→ m22 궁금함
→ m23 놀람
→ m26 호감
→ m33 확신
→ m35 확신
```

36 Moment 전체를 임의로 graph화하지 않고,
기존 metadata와 Connection surface에서 감정 인과를 읽을 수 있는 8 Moment만 prototype path로 연결했다.

별도 backend/DB/schema를 확정하지 않았다.

---

## 2.3 Viewer 안에서 Connection traversal이 실제 동작

Connected CTA를 누르면 modal을 닫고 Archive를 다시 찾게 하지 않고,
viewer 안에서 다음 Moment로 이어진다.

이는 LoveTree의:

> Moment → Connection → 다음 Moment

흐름을 실제 감상 경험으로 만든다.

---

## 2.4 Replay가 실제 경로 재생으로 동작

`처음부터 다시 걷기` 실행 시:

- root `m14`로 복귀
- `REPLAY 01 / 08`
- 8단계 pathOrder 순서 traversal
- 최종 `m35`
- Replay 종료
- Archive 복귀

흐름이 확인됐다.

---

## 2.5 Filter를 넘어가는 Connection이 막히지 않음

Archive filter는 목록 표시 조건일 뿐
Connection traversal을 제한하지 않는다.

Object filter 상태에서 다른 type Moment로 연결 이동할 수 있고,
종료 후 원래 filter를 복원한다.

---

## 2.6 Archive 상태 복구

Replay 종료 후:

- original filter
- scrollY
- trigger context

를 복원한다.

QA 기준 `1331 → 1331`, delta 0px.

# 3. 제품 원칙 적합 판정

C1은 콘텐츠 추천의 `Next Content`가 아니라:

> **왜 이 순간 때문에 다음 순간을 찾아갔는가**

를 전면에 둔다.

또한 Replay는 단순 슬라이드 쇼가 아니라:

> **처음의 감정 경로를 다시 걷는 기능**

으로 구현됐다.

따라서 Track 72가 단순 Masonry Archive를 넘어
LoveTree의 Moment / Connection / Playback 구조를 실제로 표현하기 시작한 단계로 판정한다.

# 5. 아직 승인하지 않는 범위

C1 PASS가 다음을 승인하는 것은 아니다.

- 공개 트리
- 링크 공유
- `내 첫 순간으로 심기`
- Derive
- 파생 트리
- public/unlisted/private 정책 변경
- 실제 backend Connection schema
- 실제 Route schema
- analytics/conversion tracking
- production routing

위 범위는 별도 설계/제품오너 승인 전 금지한다.
