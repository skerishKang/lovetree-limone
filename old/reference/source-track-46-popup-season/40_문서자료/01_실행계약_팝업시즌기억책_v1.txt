1. 참고 영상의 성격
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

전체 녹화 길이:

약 14.93초

제작 제외:

- 시작 약 1초의 X 게시물 화면
- 종료 후 X 게시물 화면

실제 참고 영상 범위:

약 1.0초~13.2초

참고 영상의 원래 표현 방식:

- 오래된 동양 고서
- 어두운 전시대
- 책 표지가 열림
- 종이로 된 산·구름·숲이 팝업 구조로 솟아남
- 중앙에서 신화적 존재가 등장
- 존재의 여러 꼬리가 부채처럼 펼쳐짐
- 장면이 절정에 도달함
- 다시 책이 닫힘

이번 작업에서는 원본의 산해경 문구,
구미호 외형, 표지 그림과 종이조각 자산을 복사하지 않는다.

복사할 것은 자산이 아니라 다음 모션 문법이다.

- 닫힌 책
- 표지 개방
- 다층 종이 풍경 전개
- 중앙 주인공 등장
- 여러 갈래의 부채형 확장
- 절정 장면
- 책으로 복귀

2. LoveTree에서의 공식 역할
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

공식 기능명:

Popup Season Book

전체 표시명:

LoveTree Popup Season Book

한국어 기능명:

팝업 시즌 기억책

기능 목적:

한 사람의 특정 Season에 저장된 Moment와 Connection을
한 권의 입체적인 종이 기억책으로 펼쳐 보는 시네마틱 경험.

제품 내 권장 위치:

Person LoveTree
→ Seasons
→ Select a Season
→ Open the Popup Book

또는:

사람별 기억책장
→ Season 책 선택
→ 팝업 시즌 기억책

활용 가능 위치:

- Season 완료 기념 화면
- 사람별 LoveTree 대표 대문
- 공개 Course의 오프닝 장면
- 공유용 Season 미리보기
- 100 Moment 이후의 특별한 회고 방식

기본 홈이나 로그인 대시보드로 사용하지 않는다.

중요:

Moment는 단순 영상 카드가 아니다.

각 가지는 사용자가 감정을 발견한 순간이며,
가지 사이의 길과 실선은
왜 다음 Moment로 이어졌는지를 뜻한다.

5. 기본 실행 모드
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

두 가지 실행 모드를 제공한다.

NORMAL MODE

페이지를 열면 닫힌 책이 보인다.

사용자가 책을 클릭하거나
`Open this Season`을 누르면 책이 열린다.

책이 완전히 열린 뒤에는 자동으로 닫히지 않고,
사용자가 Moment 가지를 탐색할 수 있다.

DEMO MODE

URL:

?demo=1

참고 영상과 같은 약 11.5~12.5초의 자동 쇼릴을 실행한다.

순서:

닫힌 책
→ 책 열림
→ 풍경 전개
→ LoveTree 성장
→ 아홉 가지 전개
→ 절정
→ 책 닫힘

사용자 입력이 발생하면 자동 데모를 중단한다.

키보드:

Space
→ 열기·정지·재생

R
→ 데모 처음부터 다시 실행

Esc
→ 열린 Moment 또는 책 닫기

6. 전체 장면과 카메라
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

전체 브라우저 배경:

- 거의 검정에 가까운 따뜻한 차콜
- 어두운 박물관 또는 서재 분위기
- 중앙에 낮은 전시대
- 주변은 얕은 심도로 흐림
- 화면 중앙의 책에만 따뜻한 조명
- 불필요한 인터페이스 패널 없음

권장 배경색:

#0b0a08
#11100d
#17140f

전시대:

- 짙은 흑갈색
- 미세한 목재 또는 돌 질감
- 책 아래 부드러운 그림자
- 화면 아래쪽 약 55~62% 지점에 배치

가상 카메라:

- 초기에는 책을 위에서 약 25~32도 내려다봄
- 책이 열릴수록 카메라가 조금 낮아짐
- 풍경이 완성될 때 정면에 가까운 시점
- LoveTree 성장 시 5~9% 천천히 근접
- 절정에서 미세하게 위로 이동
- 과도한 회전 금지
- 멀미를 유발하는 빠른 카메라 이동 금지

참고 영상처럼 책과 풍경이 화면의 주인공이어야 한다.

7. 책 외형
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

책은 단순한 갈색 직육면체가 아니다.

필수 구성:

- 두꺼운 앞표지
- 뒤표지
- 책등
- 여러 겹의 페이지 블록
- 낡은 종이 가장자리
- 실 제본 또는 노출된 바인딩
- 금속 또는 가죽 모서리 보강
- 표지 안쪽
- 페이지 사이 미세한 틈
- 책 아래 그림자

표지 기본 디자인:

상단 작은 표시:

LOVETREE ARCHIVE

중앙:

FELIX
SEASON 03

부제:

THE VOICE THAT STARTED EVERYTHING

하단:

127 MOMENTS · 18 BRANCHES

또는 샘플 데이터에 맞는 실제 숫자를 사용한다.

원본 고서의 한자 표지와 지도 그림을 그대로 복사하지 않는다.

LoveTree 표지는 다음 요소로 구성한다.

- 얇은 나뭇가지 지도
- 작은 꽃과 잎
- Season의 감정 경로
- 오래된 종이에 인쇄된 선
- 세이지·로즈·청회색의 절제된 색
- LoveTree 공식 마크

재질:

- paper roughness
- fabric or worn leather
- subtle emboss
- warm edge wear

플라스틱 장난감처럼 보이면 실패다.

8. 종이 재질
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

팝업 요소는 실제 종이 공예처럼 보여야 한다.

필수 특징:

- 1~3mm 정도로 보이는 종이 두께
- 가장자리의 미세한 밝은 단면
- 앞면과 뒷면의 명도 차
- 겹친 종이 사이의 그림자
- 약한 섬유 질감
- 완벽하게 반듯하지 않은 작은 굴곡
- 무광 재질
- 조명 각도에 따라 달라지는 음영

금지:

- 모든 레이어가 두께 없는 평면 SVG처럼 보임
- 광택 플라스틱 재질
- 지나친 금속 반사
- 그림자 없는 종이 조각
- 모든 레이어가 동일한 색과 밝기
- 한 장의 합성 이미지로 전체 풍경 표현

──────────────────────────────────
