- 참고 영상: `참고-녹화_2026_08_03_21_08_54_949.mp4`

- 해상도: **1904×1068**
- 프레임률: **30fps**
- 제작에 반영한 유효 범위: 약 **1.0초~13.2초**

## 2. 참고 영상의 핵심 모션 문법

영상의 핵심은 특정 신화 소재가 아니라 다음 변환 구조다.

```text
닫힌 책
→ 표지와 페이지의 시간차 개방
→ 접혀 있던 종이 풍경의 깊이별 전개
→ 중앙 주인공의 등장과 이동
→ 여러 갈래의 부채형 확장
→ 화면 밀도가 최고점에 도달하는 절정
→ 매우 빠른 역방향 접힘
→ 닫힌 책으로 복귀
```

LoveTree 결과물에서는 이를 다음으로 번역했다.

```text
Season 기억책
→ 저장된 Moment가 만든 종이 풍경
→ 기억의 씨앗
→ 뿌리와 중앙 줄기
→ 9개의 Moment 가지
→ Season Full Bloom
→ 책으로 복귀
```

## 4. 카메라와 구도

### 닫힌 상태

- 책을 위에서 약 25~32도 내려다보는 3/4 구도
- 책은 화면 중앙보다 약간 아래쪽에 배치
- 전시대와 책 그림자가 화면 하단의 무게를 형성
- 배경은 박물관 또는 어두운 서재처럼 얕은 심도로 흐림

### 개방 과정

- 표지가 열릴수록 카메라가 서서히 낮아짐
- 풍경이 완성될 때 정면에 가까운 구도로 전환
- 중앙 형상이 등장할 때 약한 근접 이동
- 과도한 회전보다 **시점의 낮아짐 + 느린 돌리 인**이 중요함

### 절정과 복귀

- 부채형 구조가 화면의 가로 폭을 대부분 차지함
- 절정 후 긴 해체가 아니라 180~300ms 수준의 빠른 접힘 인상을 사용
- 단순 컷이 아니라 짧게라도 구조가 중심으로 모이는 움직임이 보임

## 5. 레이어와 시각 밀도

참고 영상은 한 장의 배경 이미지가 아니라 다음 깊이를 명확히 가진다.

1. 책과 페이지 블록
2. 앞쪽 바위·길
3. 전경 꽃과 낮은 식생
4. 좌우 숲
5. 중경 산
6. 후경 산
7. 서로 다른 높이의 구름
8. 뒤쪽 원형 광원
9. 중앙 주인공
10. 부채형 확장 구조

결과물은 이를 **15개의 독립 풍경 레이어**, 별도의 씨앗, 뿌리·줄기 SVG, 9개의 개별 가지로 재구성했다.

## 6. 재질 분석

참고 영상의 설득력은 다음에서 발생한다.

- 페이지 블록의 다층 가장자리
- 표지와 페이지 사이의 간격
- 종이 조각 하단의 접힘 축
- 레이어마다 다른 그림자 길이
- 무광 종이와 낮은 채도의 산·숲
- 중앙 주인공의 밝은 종이색 대비

따라서 결과물에서 광택 플라스틱, 네온 블룸, 평면 카드 그리드를 배제했다. 책은 별도 표지·뒤표지·책등·페이지 블록으로 나누고, 풍경은 개별 SVG와 CSS 3D 회전축으로 구성했다.

## 7. 원본과 의도적으로 달리한 부분

- 원본 표지의 한자·지도·문양을 사용하지 않음
- 구미호 또는 유사 동물 외형을 사용하지 않음
- 원본 영상 프레임을 텍스처·배경·캡처 자산으로 사용하지 않음
- 중앙 형상을 LoveTree 씨앗·뿌리·줄기·9개 Moment 가지로 대체
- 참고 영상에는 없는 Moment hover, 카드, YouTube 모달, Chapter 이동, 표지 테마, 저장 상태를 Normal Mode 확장 기능으로 추가

## 8. 기준 판정

참고 영상과 동일한 소재를 복제하는 것이 아니라, **닫힌 물체가 살아 있는 세계로 변하는 경험**을 보존했다. 이번 시안의 핵심 대응은 다음과 같다.

> a closed book becoming a living world  
> → a saved Season becoming a living memory tree
