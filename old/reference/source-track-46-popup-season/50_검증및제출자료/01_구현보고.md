# LoveTree Popup Season Memory Book v1 — Implementation Report

## 1. 결과물 상태

- 작업 번호: **43.팝업시즌기억책**
- 결과 파일: `lovetree-popup-season-memory-book-v1.html`
- 상태: **독립 신규 후보 / design-review**
- 기존 LoveTree HTML 수정: 없음
- 기존 채택본 덮어쓰기: 없음
- 기존 사람별 기억책장·Season Archive 통합: 수행하지 않음
- 참고 영상·프레임을 배경 또는 텍스처로 사용: 없음

## 2. 구현 방식

이번 v1은 외부 3D 라이브러리 없이 다음 기술로 구성했다.

- 단일 HTML
- CSS 3D transforms
- 인라인 SVG paper-cut assets
- JavaScript 상태 머신
- Pointer / Keyboard Events
- requestAnimationFrame 기반 주변 움직임
- localStorage 상태 저장
- Web Audio API 기반 선택형 종이·가지 효과음
- 런타임 YouTube iframe 생성·제거

Three.js는 권장 기술이었지만 필수 계약은 아니었다. 외부 CDN 실패 위험을 제거하고 단일 HTML 휴대성을 높이기 위해 CSS 3D와 SVG를 선택했다.

## 7. 확인된 제한

### YouTube 네트워크

샘플 영상은 YouTube 외부 접속이 가능한 브라우저에서 재생된다. 자동 검증 환경에서는 외부 요청을 차단하고 **iframe 생성·제거 계약**만 확인했다.

### localStorage 자동 검증 환경

Playwright의 `set_content/about:blank` 검증 환경은 저장소 접근이 제한된다. HTML은 해당 예외를 안전하게 처리하며, 일반 `http(s)` 또는 로컬 파일 실행 브라우저에서는 지정 키로 저장하도록 구현돼 있다.

### 종이 두께 표현

책 표지·페이지 블록은 실제 CSS 3D 면과 두께를 가진다. 풍경 조각은 인라인 SVG에 외곽선·drop-shadow·깊이 변환을 적용한 방식이며, Three.js ExtrudeGeometry 수준의 실제 메시 두께는 사용하지 않았다. 따라서 다음 버전에서 극접사 카메라가 필요하면 WebGL extrusion 후보를 별도 제작해야 한다.

### 성능 수치

Headless Chromium은 requestAnimationFrame을 제한해 실사용 FPS를 신뢰성 있게 인증할 수 없었다. 데스크톱·모바일 실행 영상은 정상적으로 기록됐지만, 45~60fps/30fps 목표는 실제 기기 브라우저에서 별도 측정해야 한다.
