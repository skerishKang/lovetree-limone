## 2. 책 구조

| 파트 | 구현 | 역할 |
|---|---|---|
| 앞표지 | `.front-cover`의 양면 구조 | 닫힌 상태의 표지, 열린 상태의 안쪽 표지 |
| 뒤표지 | 좌·우 `.back-cover` | 책 전체 두께와 바닥 구조 |
| 책등 | `.spine` | 중앙 회전축과 실 제본 인상 |
| 페이지 블록 | 좌·우 `.page-block` | 반복 선형 그라디언트로 다층 페이지 가장자리 표현 |
| 펼쳐지는 페이지 | `.turning-page` 3개 | 표지와 다른 탄성·지연으로 순차 회전 |
| 좌우 본문 페이지 | `.page-surface` | 열린 Season 풍경의 바닥 |

닫힌 상태에서는 왼쪽 절반이 `rotateY(180deg)`로 오른쪽 뒤에 접혀 있고, 열릴 때 왼쪽 페이지와 앞표지가 서로 다른 방향·속도로 전개된다.

## 3. 독립 종이 풍경 레이어

총 **15개**다.

| 번호 | 클래스 | 깊이 역할 | 전개 순서 |
|---:|---|---|---:|
| 01 | `.stones` | 최전경 바위와 돌 | 1 |
| 02 | `.path-layer` | Moment를 잇는 중앙 감정 경로 | 2 |
| 03 | `.flowers` | 전경 꽃과 낮은 식생 | 3 |
| 04 | `.tree-left` | 왼쪽 전경 나무 | 4 |
| 05 | `.tree-right` | 오른쪽 전경 나무 | 4 |
| 06 | `.forest-left` | 왼쪽 숲 | 5 |
| 07 | `.forest-right` | 오른쪽 숲 | 5 |
| 08 | `.hill-center` | 중앙 낮은 언덕 | 6 |
| 09 | `.mountain-left` | 왼쪽 중경 산 | 7 |
| 10 | `.mountain-right` | 오른쪽 중경 산 | 7 |
| 11 | `.mountain-far` | 중앙 후경 산 | 8 |
| 12 | `.cloud-low` | 낮은 구름 | 9 |
| 13 | `.cloud-mid` | 중간 구름 | 10 |
| 14 | `.cloud-high` | 높은 구름 | 11 |
| 15 | `.moon` | Season 빛 원 | 12 |

각 레이어는 다음 속성을 독립적으로 가진다.

- `--x`, `--y`, `--z`: 화면 위치와 깊이
- `--delay`: 전개 지연
- 바닥 중심 `transform-origin`
- 닫힘 상태 `rotateX(-88deg)`
- 열린 상태 `rotateX(0deg)`
- 개별 SVG 색·외곽선·drop-shadow

한 장의 합성 PNG 또는 참고 영상 캡처는 사용하지 않는다.

## 4. LoveTree 구조

### 씨앗

- `.seed-wrap`과 `.seed`
- 중앙 길을 따라 올라오는 translate + scale
- 짧은 상하 움직임으로 단순 슬라이드 인상을 완화

### 뿌리와 줄기

- `root-svg`의 `.root-path`, `.trunk-path`
- `stroke-dasharray`와 `stroke-dashoffset`으로 성장
- 뿌리 먼저, 줄기 후속 전개

### 9개의 Moment 가지

각 가지는 JavaScript에서 독립 생성된다.

```text
.branch
├─ .paper-branch
│  └─ .twig
└─ button.moment-bloom
```

가지별 독립 변수:

- `--angle`: -72°에서 +72°까지 부채형 배치
- `--closed`: 접힌 초기 각도
- `--length`: 168~226px
- `--depth`: 앞·중간·뒤 깊이
- `--delay`: 가지당 약 85ms 시간차
- `--accent`: Moment 감정 포인트색

가지 전체를 하나의 이미지나 단일 scale 애니메이션으로 만들지 않았다.

## 5. 상태 머신

```text
closed
→ cover
→ world
→ seed
→ tree
→ bloom
→ closing / closed
```

### Demo Mode 관찰 타임라인

자동 검증에서 확인한 상태 변화:

- 0ms: closed
- 901ms: cover
- 2101ms: world
- 4201ms: seed
- 6101ms: tree
- 8201ms: bloom
- 10604ms: closed

전체 데모는 약 11.5초 안에 종료되며, 마지막 닫힌 상태를 유지한다.

```js
const seasonData = {
```

- 샘플 Chapter: 3개
- Chapter당 Moment: 9개
- 전체 샘플 Moment: 27개

- 중요도·애정 순위 자동 산정 없음

## 7. 탐색 구조

### Moment 선택

1. 가지 hover/focus
2. 해당 가지가 앞으로 이동
3. Moment 꽃이 빛남
4. 클릭 시 작은 종이 카드 표시
5. 카드에 제목·날짜·Feeling·Connection 이유 표시

### 영상 재생

1. 선택 Moment 유지
2. 중앙 16:9 종이 프레임 모달 열기
3. YouTube iframe을 런타임에 생성
4. 닫을 때 iframe DOM 제거
5. 책은 열린 상태 유지

### Chapter 이동

1. 현재 가지를 씨앗 상태로 접음
2. `currentChapter` 변경
3. 동일 중앙 줄기를 유지한 채 새 9개 가지 생성
4. 가지를 순차 재개방

## 8. 모바일 구조

- 390×844에서 별도 카메라 스케일과 중앙 정렬 적용
- 책을 화면 하단에 두고 풍경은 위로 성장
- 9개 Moment 꽃의 실제 bounding box가 모두 뷰포트 안에 존재함을 자동 검증
- Moment 카드는 우측 패널이 아니라 하단 sheet로 전환
- Chapter 버튼 최소 높이 44px
