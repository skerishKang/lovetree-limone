# Track 74 V2 변경 기록

- 이야기 메뉴의 Track 70 파일명을 `선택-...`에서 실제 존재하는 `선택1-...`로 교정.
- V2 하위 폴더 깊이에 맞게 디자인 Track 링크를 `../../`, Codex 링크를 `../../../../코덱스`로 재계산.
- 거대 LOVETREE를 Times 계열에서 Arial Black/Malgun Gothic 기반 굵은 고딕으로 변경.
- 글자 크기와 자간, 좌우 범위를 재조정하고 오른쪽 padding을 추가해 마지막 E 잘림 방지.

- 두 줄을 개별 span으로 분리하고 `gap: .30em`, `line-height: 1.42` 적용.
- 원본 Orbit의 4선 별표 SVG 제거.
- 흰색 나무 윤곽·줄기·가지와 핑크 열매 3개의 inline SVG 후보로 교체.
- 이 나무 심벌은 공식 로고 확정본이 아니라 Track 74용 디자인 후보임.
