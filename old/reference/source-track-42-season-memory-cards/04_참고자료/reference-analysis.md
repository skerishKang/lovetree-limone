## 모션 원칙

1. **공간 이동 우선**: 단순한 내용 교체나 페이드가 아니라 카드가 좌우 자리 사이를 이동한다.
2. **한 방향의 연속성**: 다음은 왼쪽, 이전은 오른쪽으로 움직인다.
3. **중앙 카드 강조**: 크기·밝기·그림자가 미세하게 강화된다.
4. **카메라와 UI 분리**: 카드 전환과 WIDE/FOCUS 카메라 전환은 별도 상태로 관리된다.
5. **순환 전환 차별화**: 9→1은 일반 슬라이드가 아니라 WIDE 축소와 stagger 재정렬을 사용한다.
6. **절제된 easing**: bounce 없이 감속이 분명한 `cubic-bezier(.22,.72,.16,1)` 계열이다.

## LoveTree 치환 기준

여행 카드의 국가·도시 정보는 다음 LoveTree 정보로 치환했다.

- 장소 → 사람과 플랫폼
- 여행 제목 → Moment 제목
- 여행 메모 → 마음 기록
- 여행 태그 → 감정과 기억 단서
- 장소 캡슐 → 연결 이유·가지 이름
- `EXPLORE` → `기억 열기`
- `ADVENTURES` → `SEASON 01`

카드 구조, 3장 배치, 순환 이동, 압축 페이지네이션, WIDE/FOCUS 모션은 참고 영상의 인터페이스 문법을 유지했다.
