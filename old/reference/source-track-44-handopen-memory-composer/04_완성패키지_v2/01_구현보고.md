# LoveTree Memory Window Composer v2 — Implementation Report

## Scope

Independent no-camera editor created from the interaction foundations of `lovetree-hand-frame-memory-window-v1.html` without modifying the original file.

## Removed

- Camera permission UI
- `getUserMedia`
- MediaPipe and hand tracking
- Camera filters and live camera pipeline

## Preserved and adapted

- Four independent corner handles
- Dashed perspective outline
- White circular control points
- 8×8 homography solver and CSS `matrix3d`
- Strong trapezoid perspective
- Coordinates extending beyond the viewport
- Mobile touch interaction
- Sliding six-mode dock

## New composer functions

- Three embedded LoveTree Moment samples
- Three selectable backgrounds plus local image upload
- Whole-window dragging
- Approximate 16:9 ratio lock and free-ratio mode
- Reset, center-fit, mirror, left/front/right tilt and scale controls
- FACE SIDE, OVER SHOULDER, LOWER THIRD, FULL POSTER, FLOATING RIGHT and FLOATING LEFT presets
- CLEAN, CINEMA, ARCHIVE, GLOW, COLLAGE and LIVE MOMENT styles
- Face-safe-area warning for the portrait sample
- Perspective-to-flat playback transition
- On-demand YouTube iframe insertion
- Return to saved perspective after closing playback
- Preview mode
- Save as cover, Save to Season, Use in Course and Copy share link actions
- `lovetree-memory-window-composer-v1` localStorage payload
- Mobile bottom sheets, 48px corner targets and pinch scaling logic

## Validation limitation

The generated HTML contains real YouTube embed URLs. The automated container cannot verify remote YouTube playback because external navigation is restricted. The validation recording therefore verifies the perspective flattening and restoration before the remote iframe is inserted. Runtime source inspection confirms that the iframe is created on demand with autoplay, playsinline and rel parameters.
