# 세로형 모먼트관계망 전체조망 · 버전1 후보 구현설명

상태: `VERTICAL_MOMENT_NETWORK_OVERVIEW_TEMPLATE_CANDIDATE_FOR_PRODUCT_OWNER_REVIEW`

## 1. 분류

- 신규 Track 60이 아님.
- 위치: `03_디자인채택본/04_홈탐색_관계지도/06_세로형_모먼트관계망_전체조망`
- 제품 역할: `MY TREE → OTHER VIEWS → 관계 지도 → 세로 전체조망`
- 기존 52 / 55 / 04-3 관측소 / 06-5 Live Map / 06-6 Topology / 53 Connection Flow 원본은 수정하지 않음.

## 2. 제품 질문

> 내가 이렇게 많이 쌓아온 Moment와 Connection 전체를 위에서 아래로 길게 훑으면 어떻게 이어져 있지?

작은 노드는 실제 Moment를 뜻한다.
대형 허브는 별도 Memory entity가 아니라 Season / Person / Emotion / Path를 묶어 보여주는 View-only cluster다.
선은 실제 Connection이며 Moment 선택 시 `WHY NEXT`를 표시한다.

## 3. 버전1의 핵심

- 세로 약 4,400px 규모의 긴 world.
- 6개 대형 cluster hub + 80개 이상의 Moment 노드.
- hub-to-hub와 Moment-to-Moment Connection skeleton.
- 기본 상태에서 전체 skeleton을 낮은 광량으로 유지.
- Cluster Focus 시 해당 군집의 node/Connection만 상승하고 나머지는 de-emphasis.
- Moment Focus 시 선택 Moment, 다음 목적지, 연결 이유를 우선 표시.
- `이 경로 따라가기` 실행 시 선택 Connection을 따라 빛이 이동하고 다음 Moment가 선택됨.
- 우측 세로 progress rail로 macro 위치를 표시.
- 데스크톱: wheel/drag vertical scan, cluster click, Moment focus, zoom.
- 모바일: 축소판이 아니라 cluster overview → focused sub-map → Moment bottom sheet.
- 모바일 bottom sheet에서 WHY NEXT / 다음 목적지 / 경로 따라가기 제공.

## 4. 기존 자산에서 참고한 capability

### 메모리그래프 관측소
- dense graph를 멀리서 보는 암흑 배경과 대규모 네트워크 감각을 비교함.
- 관측 콘솔 자체는 가져오지 않음.

### 러브트리 Live Map
- node/edge focus, dimming, 흐름이 살아 있는 표현을 capability 기준으로 참고함.
- Live Map의 AUTO/시간 흐름 제품 job은 가져오지 않음.

### Track 53 Connection Flow
- 선택 Connection의 light travel / arrival reaction 문법을 참고함.
- 기존 Track 53 파일은 수정하지 않음.

### Topology / Love Nebula
- 대량 노드·cluster·대규모 조망 원칙은 설계 문서의 기존 자산 재사용 판정에 따라 반영.
- 분석실 telemetry와 성운 은유는 이 View에 넣지 않음.

## 5. 시각 규칙

- 그래프 자체가 Hero.
- UI chrome은 낮은 대비.
- 비선택 edge는 저광량 skeleton.
- rose / violet / cyan / amber / mint / blue를 cluster 차이에 사용.
- 모든 Connection을 동일한 밝기로 켜 두지 않음.
- 선택 우선순위: Cluster → Moment → WHY NEXT → 다음 목적지.

## 6. 모바일

검증 viewport:
- 360×800
- 390×844
- 430×932
