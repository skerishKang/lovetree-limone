# 세로형 모먼트관계망 전체조망 V1.1 구현설명

상태: `VERTICAL_MOMENT_NETWORK_OVERVIEW_V1.1_VISUAL_RESCUE_CANDIDATE_FOR_PRODUCT_OWNER_REVIEW`

## 범위

V1의 기능 계약은 유지하고 시각 구조만 구조적으로 교정했다.

- vertical pan / scroll
- cluster focus
- Moment focus
- WHY NEXT
- `이 경로 따라가기`
- reset / overview
- 모바일 cluster ribbon → focused local map → Moment bottom sheet

기존 V1은 수정하지 않았다.

## 밝은 배경

제품오너 결정에 따라 V1의 dark full-screen theme를 제거하고 Light Pearl / Warm Ivory / Pale Blush 계열로 전환했다.

- base: `#F8F5F2`
- secondary: `#F3F1F7`
- rose / lilac / cyan ambient는 아주 약하게 사용
- UI panel은 translucent white
- Connection skeleton은 muted gray-rose 계열
- 선택 cluster / Moment / path만 색상과 선 굵기를 올린다.

## 그래프 생성 방식 교체

V1의 `동일 각도 radial + 3단 ring + hub spoke` 방식을 폐기했다.

V1.1 생성값:

- Moment: 288
- secondary anchor: 19
- Connection: 1,274
- cluster: 6
- cluster Moment 수: 28 / 56 / 68 / 44 / 32 / 60

cluster silhouette:

1. branching fan
2. overlapping double-lobe
3. compressed irregular knot
4. elongated asymmetric ellipse
5. open sparse branch
6. asymmetric cloud

모든 Moment가 hub에 직접 연결되지 않는다. path Connection, nearest local neighbor, cross-link, anchor Connection, inter-cluster multi-bridge를 혼합한다.

## Hub / Anchor

- main hub size를 서로 다르게 구성
- 일부 hub는 solid color core, 일부는 pearl core + color outline
- cluster 내부에 2~4개의 중형 anchor 배치
- anchor는 별도 Memory entity가 아니라 View-only 시각 집계점
- First Moment만 pearl/light treatment를 유지

## LOD / Focus

### Overview
전체 network mass와 cluster name / major hub만 읽힌다.

### Cluster Focus
선택 cluster의 local graph 대비를 높이고 나머지는 de-emphasis한다.

### Moment Focus
선택 Moment, local neighbor, 실제 다음 path, WHY NEXT를 우선 노출한다.

## 모바일

데스크톱 전체 world를 390px에 단순 축소하지 않는다.

- 하단 cluster ribbon
- 선택 cluster별 fit scale 계산
- 다른 cluster는 focused sub-map에서 숨김
- Moment 선택 시 bottom sheet
- WHY NEXT / path follow 유지

검증 viewport:

- 1440×900
- 1280×720
- 430×932
- 390×844
- 360×800
