# 04 관계지도 Template 06 · V1.2 구현설명

상태: `VERTICAL_MOMENT_NETWORK_OVERVIEW_V1.2_PATH_REVEAL_CANDIDATE_FOR_PRODUCT_OWNER_REVIEW`

## 1. 범위

- V1/V1.1/참고원본은 수정·삭제·덮어쓰기하지 않았다.
- V1.2는 `03_버전1.2_경로계층·전체경로표시_후보자료`에서만 제작했다.
- 밝은 Light Pearl / Warm Ivory 계열 배경과 V1.1의 색 체계는 유지했다.
- V1.1의 random irregular network를 `Controlled Organic` 경로 계층으로 재구성했다.

## 2. 원본·V1.1 대비 구조 변경

원본 참고영상은 완전 랜덤 cloud가 아니라 큰 중심에서 여러 방향으로 fan/tree 형태의 주요 branch가 퍼지고, branch 안에서 secondary branch가 다시 갈라지는 구조가 읽힌다.

V1.1은 밀도 확보를 위해 local/cross-link가 많아져 경로의 시작·중간·끝이 한눈에 읽히지 않았다.

V1.2에서는 각 cluster마다 3~4개의 Primary Path를 먼저 만들고 그 위에 Secondary Branch와 contextual Moment를 붙였다. 결과적으로 꽃/ring도 아니고 spaghetti도 아닌 방향성 있는 성장 뼈대를 유지한다.

## 4. 상태 모델

V1.1의 1-hop 중심 상태를 폐기하고 다음 상태를 사용한다.

- `OVERVIEW`
- `ORIGIN_REVEAL`
- `CLUSTER_PATH_OVERVIEW`
- `MOMENT_FOCUS`
- `PATH_PLAYBACK`

## 5. First Moment · 전체 분기 Reveal

First Moment 버튼 또는 First Moment 노드를 선택하면 `ORIGIN_REVEAL`에 진입한다.

- First Moment를 root seed로 유지한다.
- 01 / 02 / 03 주요 경로군을 동시에 활성화한다.
- 각 경로군의 Primary/Secondary branch skeleton을 함께 유지한다.
- 01/02/03 목적지는 서로 다른 cluster 색으로 구분한다.
- 나머지 관계망은 완전 소멸시키지 않고 낮은 opacity skeleton으로 남긴다.

모바일에서는 288개 전체를 축소하지 않고 First + 01/02/03 주요 path node/anchor 중심으로 progressive disclosure한다.

## 6. 01 / 02 / 03 Cluster 전체 경로 표시

Cluster 번호를 선택하면 `CLUSTER_PATH_OVERVIEW`가 된다.

- 해당 cluster Entry/Hub 강조
- 해당 cluster 모든 Primary Path 강조
- Secondary Branch 강조
- branch point ring 표시
- 다음 cluster로 이어지는 bridge 표시
- 다른 cluster/path de-emphasis

따라서 한 Moment 주변 1-hop이 아니라 cluster의 시작 → branch → 끝 구조가 한 번에 보인다.

## 7. Moment Focus

Moment를 선택하면 그 Moment가 속한 전체 Path sequence를 함께 강조한다.

WHY NEXT는 모든 edge에 문장으로 상시 노출하지 않고 detail에서 현재 path 맥락과 함께 표시한다.

## 8. `이 경로 끝까지 따라가기`

V1.1의 one-edge follow를 폐기했다.

V1.2 Path Playback은:

1. 현재 Moment 강조
2. 다음 Connection light travel
3. 다음 Moment 도착/pulse
4. 지나온 edge trail 유지
5. 앞으로 갈 edge faint preview 유지
6. 여러 Moment 연속 진행
7. Branch Point에서 정지
8. `주경로 계속` / `분기 선택` chooser 표시
9. 선택 후 같은 replay 문법으로 계속 진행

QA 경로는 최소 4개 이상 Moment를 연속 통과하도록 검증했다.

## 9. 모바일

모바일은 데스크톱 전체 world의 단순 축소판이 아니다.

- First / 01·02·03 route reveal
- cluster ribbon
- cluster 선택 → local path tree
- Moment 선택 → bottom sheet
- WHY NEXT
- full path playback
- Branch chooser

390×844 기준으로 전체 관계망을 한 화면에 모두 노출하지 않고 단계적으로 깊어진다.

## 10. 원본과 의도적으로 다르게 유지한 LoveTree 요소

- 원본의 dark neon background는 복제하지 않고 제품오너 결정에 따라 밝은 Pearl/Ivory 배경을 유지한다.
- 원본처럼 모든 Connection을 동일 밝기로 켜지 않는다.
- Overview skeleton은 낮은 광량, 선택 경로만 saturation/line weight를 올린다.
- Hub는 별도 Memory entity가 아니라 View-only cluster다.
- Edge는 단순 연관선이 아니라 실제 Connection/WHY NEXT 읽기 문법을 유지한다.
