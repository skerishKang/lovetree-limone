## LoveTree translation
- `Moment`는 얼굴이 아니라 감정이 붙잡힌 장면이다.
- `Save`는 버튼 기능 설명이 아니라 시간/빛이 잠깐 멈추는 사건이다.
- `Connection`은 관계도 선이 아니라 동일한 빛·형태·방향이 다음 Moment를 여는 인과로 표현한다.
- `Tree`는 초반 UI가 아니라 앞의 Moment가 남긴 빛점이 후반에 축적된 결과로만 등장한다.
