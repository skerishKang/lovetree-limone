## 사용 원칙

- 새로운 작업을 재개할 때는 `00_최종채택본...`을 먼저 확인합니다.
- `90_이전버전...`의 파일은 역사/비교용이며 최신 기준본으로 사용하지 않습니다.
- `10_최종제작_원본소스`는 후속 파생 디자인을 위한 원본 자산 보관소입니다.
- 승인 영상 파일은 임의로 수정하지 않습니다.
