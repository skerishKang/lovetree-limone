# LoveTree 50 — 제작과정 성공요인·주의사항 인수인계

## 현재 상태

50은 제품 오너가 충분히 좋다고 판단해 작업 종료 및 휴식 상태다. 별도 지시 없이 재작업하지 않는다.

## 성공 요인

1. Benchmark를 49와 섞지 않고 `aespa Supernova`로 고정했다.
2. 승인된 여성 identity를 유지하고 새 캐스팅을 반복하지 않았다.
3. 기존 10-scene 자산을 버리지 않고 film-led sequence로 편집했다.
4. Desktop/Mobile final master를 먼저 안정화했다.
5. Final video와 website layer를 구분했다.
6. 마지막에는 actual website structure와 portable Standalone을 모두 제공했다.

## 중요한 교훈

- 영상이 좋다고 홈페이지까지 완료된 것으로 선언하면 안 된다.
- `VIDEO MASTER`와 `CINEMATIC WEBSITE`는 별도 Gate다.
- Standalone은 별도 시안이 아니라 same design의 portable review artifact다.
- 승인 identity/scene/storyboard를 final polishing 단계에서 다시 바꾸지 않는다.
- 50은 LoveTree 전체 기본 UI가 아니라 Supernova film-led cinematic landing/homepage 템플릿 후보 중 하나다.
