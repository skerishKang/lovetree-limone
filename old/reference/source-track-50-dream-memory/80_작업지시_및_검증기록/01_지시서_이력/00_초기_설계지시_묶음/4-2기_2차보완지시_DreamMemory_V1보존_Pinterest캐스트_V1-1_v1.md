# 0. 중요 정정

현재 제출된 V1은 Pinterest 남녀 아이돌 무드보드 추가지시 이전에 제작된 구조/모션 프로토타입으로 본다.

현재 V1은 폐기하지 않는다.
현재 분석, 10 Scene 구조, Save/Connection, 모바일, reduced-motion, timeline engine은 유지한다.

그러나 현재 V1을 Pinterest 추가지시까지 반영한 최종 후보라고 보고하지 않는다.

# 1. 현재 V1에서 실제 확인된 장점

- Neon Pilot과 확실히 다른 자연/기억/필름 톤
- Moment → Save → Connection → Next Moment → Tree 흐름
- Memory Breath 장면
- UI가 전 장면을 지배하지 않는 방향
- desktop/mobile 별도 레이아웃
- self-contained HTML
- Save interaction
- Connection transition
- 단순 Tree 그림이 아니라 Moment 경로가 Tree로 귀결되는 구조

위 구조는 보존한다.

# 2. 현재 V1에서 실제 확인된 한계

실제 Drive 자산은 남성 portrait 6장뿐이다.

따라서 현재 화면은:
- 특정 남성 얼굴 반복 체감이 강함
- 여성 아이돌 0명
- 얼굴/반신 portrait 중심
- 전신/걷기/무대/그룹 Moment 부족
- 자연환경이 실사 사진이 아니라 CSS 추상 배경 위주
- Pinterest 무드보드가 요구한 K-pop 캐스트 다양성 미반영
- NewJeans/ILLIT 계열의 실제 자연광·거리·공간·친밀한 순간 질감이 아직 약함

# 3. 다음 버전의 목표

V1의 구조를 유지하면서 사진적 세계만 업그레이드한다.

목표:

> 같은 남자 얼굴 6장의 기억 프로토타입
> →
> 남녀 여러 K-pop 아이돌의 실제 순간이 저장되고 연결되는 Dream Memory world

# 4. Pinterest 무드보드 실제 반영

사용자가 제공한 다음 6종 무드보드를 공식 캐스트 레퍼런스로 사용한다.

- 여자아이돌 얼굴 검색 보드
- 여자아이돌 전신 검색 보드
- 여자아이돌 혼합 보드
- 남자아이돌 얼굴 검색 보드
- 남자아이돌 전신 검색 보드
- 남자아이돌 혼합 보드

특정 실존 인물을 그대로 복제하지 않는다.

참고하는 것은:
- K-pop 얼굴군
- 헤어
- 메이크업
- 체형/전신 비율
- 포즈
- 무대/사복/거리/이동/대기 순간
- 촬영 거리
- 자연스러운 활동감

# 5. Cast 목표

1차 V1.1에서 화면상 최소:

- 여성 캐스트 3명 이상
- 남성 캐스트 3명 이상
- 총 시각적으로 구분되는 인물 7~10명 권장
- 2인 또는 그룹 Moment 1개 이상
- 전신 또는 걷는 장면 2개 이상

단, 모든 장면을 다른 사람으로 바꾸지는 않는다.

Main Memory Thread는 같은 인물 2~3컷을 유지해 감정 연결을 만든다.
그 뒤 다른 아이돌 Moment로 확장한다.

# 6. Scene별 교체 방향

## Scene 01 First Moment
현재 남성 얼굴만 반복하지 말 것.
Main Memory Idol 1명을 선택.
남성 또는 여성 어느 쪽이든 가능.
자연광 candid hero 필요.

## Scene 02 Memory Breath
CSS-only curtain/water를 유지할 수 있으나,
실제 window / curtain / water / street / train / sky 중 1개의 clean 환경 plate를 섞어 사진적 질감 강화.

## Scene 03 Person Reveal
Main Memory Idol 동일 인물의 다른 순간.
정면 증명사진 금지.
옆얼굴, 창가, 뒤돌아봄, 웃음, 대기 중 장면 권장.

## Scene 04 Detail
현재 얼굴 3분할만 사용하지 말 것.
손 / 머리카락 / 마이크 / 의상 / 귀걸이 / 무대조명 / 뒷모습 등의 실제 detail을 1~2개 섞을 것.

## Scene 05 Save
Main Thread의 저장 순간 유지.
Save UI 구조 보존.

## Scene 06 Connection
같은 남성 얼굴 2명만 연결하지 말 것.
Main Memory → 다른 성별/다른 아이돌 Moment로 확장 가능.
Connection은 감정적 Match Cut 중심.

## Scene 07 Follow
현재 CSS road prototype을 실제 기억 공간 느낌으로 보강.
도로/기차창/복도/공연장 exit/거리 등의 실사환경 사용 권장.

## Scene 08 Memory Field
가장 크게 보강할 장면.
남녀 여러 아이돌 얼굴/전신/무대/거리/일상 Moment를 혼합.
현재 비슷한 남성 portrait 6개 반복 금지.

## Scene 09 Tree Emerges
작은 Moment thumbnail은 다양한 캐스트로 교체.
동일인 얼굴 반복을 줄이고 한 경로 안의 여러 Moment가 읽히게.

## Scene 10 End
현재 LOVETREE 단순 End Card 유지 가능.

# 7. 신규 이미지 생성 순서

대량 생성 금지.

먼저 제출:

`dream-memory-v1.1-scene-slot-map.md`

각 slot마다:
- CURRENT ASSET
- KEEP / REPLACE
- NEW IMAGE NEEDED
- MALE / FEMALE / GROUP / ENVIRONMENT
- SHOT TYPE
- REASON

그 다음 신규 생성.

1차 신규 이미지 권장:
- 여자 4~6장
- 남자 3~5장
- 그룹/2인 1~2장
- 환경/소품 3~4장

총 12~17장 내외.

이미 충분한 기존 portrait는 재활용 가능하므로 불필요하게 새 얼굴을 늘리지 않는다.

# 8. 사진 품질 기준

이번 V1.1의 핵심은 “예쁜 AI 사진”이 아니라 “K-pop 순간의 실제성”이다.

PASS:
- candid
- natural light
- stage spill light
- window / street / backstage
- asymmetry
- gaze away from camera
- movement
- group relationship
- full-body real proportion

FAIL:
- 증명사진
- 플라스틱 피부
- 모두 같은 얼굴형
- AI 패션모델 포즈
- 과도한 성숙/성적 포즈
- 팔다리/손 왜곡
- 불필요한 신체 부위 확대
- Pinterest 속 특정 실제 인물의 직접 복제
