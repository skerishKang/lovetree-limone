# 0. 제품 오너 최신 판정

제품 오너의 최신 지시는 다음과 같다.

> "여기 이미지 엄청 잘 뽑아놓고 왜 못만드는지 이해가 안돼. 여기 콘티대로 만들면 되잖아. 이미지도 이렇게 뽑고 러브트리의 컨셉대로 관계와 순간에 집중해야지."

이 지시가 최우선이다.

이번 50번은 **새로운 컨셉을 발명하는 작업이 아니다.**

이미 앞 단계에서 잘 만들어진 LoveTree 콘티와 이미지 방향을 다시 기준선으로 복구하고,
그 위에 Supernova의 시네마틱 연출 문법만 접목한다.

# 1. 이번 작업의 가장 중요한 결론

## 잘못한 것

기존 v1/v1.1은 다음 순서로 제작되었다.

```text
Supernova shot
→ 비슷한 여성 이미지 하나 배치
→ 다음 shot에 다른 여성 이미지 배치
→ 효과/scale/translate
→ 마지막에 Tree
```

그 결과:

- A/B/C/D/E/F 여성 이미지 쇼릴
- 인물 정체성 단절
- Moment 사이의 감정적 인과관계 소실
- Connection이 제품 의미가 아니라 장식 효과로 축소
- Tree가 앞선 경로의 결과가 아니라 마지막 장식으로 등장
- 좋은 원본 콘티와 이미지가 있었음에도 HTML에서는 사진 슬라이드쇼처럼 변질

되었다.

## 이번에 할 것

```text
기존 LoveTree 콘티의 감정 여정 고정
→ 같은 주인공의 여러 Moment 고정
→ Moment 간 Connection 이유 고정
→ 기존 수준의 고품질 장면 이미지 제작/선별
→ Supernova의 컷/카메라/렌즈/색/전환 문법을 입힘
→ 앞에서 생긴 Connection이 마지막 Tree가 됨
```

# 2. 절대 기준 A — LoveTree 서사 콘티

50번의 의미 구조는 아래 10단계를 그대로 사용한다.

이 10개는 페이지 섹션을 그대로 복제하라는 뜻이 아니라
**시네마틱의 의미 순서**다.

## 01. FIRST GLIMPSE

처음 그 사람을 본 순간.

핵심 감정:

> "방금 누구지?"

아직 팬이 아니다.

한 컷의 표정, 시선, 무대, 영상 일부가 마음에 걸리는 순간이다.

---

## 02. MEMORY BREATH

첫 장면이 머릿속에 남는다.

다른 인물을 보여주는 구간이 아니다.

**FIRST GLIMPSE에서 본 같은 사람의 잔상**이다.

- 창가
- 도시
- 조용한 공간
- 기억이 남아 있는 느낌
- 순간적인 lens distortion / reflection 가능

---

## 03. PERSON REVEAL

"저 사람이 누구지?"에서
그 사람 자체가 더 궁금해지는 단계.

같은 PRIMARY 인물의 다른 시점/거리/표정이어야 한다.

---

## 04. DELICATE DETAIL

팬이 빠지는 것은 얼굴 한 장 때문만이 아니다.

작은 디테일들이 다음 Moment를 만든다.

예:

- 손
- 마이크
- 액세서리
- 옷의 작은 디테일
- 웃을 때의 표정
- 무대 전후의 행동
- 창가/공간의 기억
- 인터뷰의 짧은 제스처

여기서 **Moment의 입자**가 생긴다.

---

## 05. SAVE THIS MOMENT

사용자가 처음으로:

> "이 순간은 남겨두고 싶다."

고 느끼는 지점.

LoveTree의 Save 의미가 처음 명확해진다.

단순 `SAVE IT` 텍스트가 아니라,
빛/잔상/프레임/시간 정지 같은 시각사건으로
"이 순간이 보존되었다"는 느낌을 준다.

---

## 06. CONNECTION

이 단계가 LoveTree의 핵심이다.

Connection은 사람 관계가 아니다.

> **이 Moment 때문에 왜 다음 Moment를 찾아갔는가**

라는 감정적 인과관계다.

예:

```text
무대에서 본 표정
→ 목소리가 궁금해짐
→ 인터뷰를 찾아봄
```

또는:

```text
짧은 직캠
→ 춤을 더 보고 싶음
→ 다른 무대를 찾아봄
```

화면에서는 Connection이:

- 빛
- motion trail
- camera travel
- 공간을 가르는 경로
- 다음 장면을 실제로 열어버리는 전환

으로 보여야 한다.

---

## 07. NEXT MOMENT

Connection이 실제로 다음 장면을 연다.

중요:

다른 랜덤 여자가 나오면 안 된다.

**앞에서 본 그 사람의 또 다른 Moment**다.

여기서:

> "아, 그래서 다음 것도 보게 됐구나."

가 느껴져야 한다.

---

## 08. MEMORY FIELD

여러 Moment가 쌓인다.

그러나 이것은 "여자 사진 카드 여러 장"이 아니다.

같은 PRIMARY 인물의:

- Stage
- Interview
- Backstage
- Live
- Detail
- Smile
- Walking
- Photo
- Performance

등 **서로 다른 Moment 기록**이 축적되는 장면이다.

필요하면 같은 그룹 멤버가 context로 등장할 수 있으나
주인공을 잃으면 안 된다.

Memory Field는 단순 카드 월이 아니라
"내가 이 사람에게 빠져온 순간들이 쌓인 공간"이어야 한다.

---

## 09. TREE EMERGES

Tree는 새 자산 한 장을 갑자기 띄우는 것이 아니다.

앞서 생긴:

- Save trace
- Connection path
- 다음 Moment로 이어진 light
- 여러 Moment의 잔상

이 하나의 구조로 수렴해야 한다.

관객이 이때 깨달아야 한다.

> "아까 계속 이어지던 저 빛들이 결국 이 Tree의 가지였구나."

---

## 10. LOVETREE

완성된 Tree를 짧게 보여준다.

의미:

> "이것은 사진 모음이 아니라 내가 사랑에 빠져온 경로다."

CTA는 마지막 짧은 hold에서만 사용한다.

---

# 3. 절대 기준 B — 지금 올린 이미지/콘티 품질

제품 오너가 이번 메시지에 첨부한 콘티 이미지 수준을
**시각 품질 기준선**으로 사용한다.

특히 좋은 점:

- 인물이 실제 장면 안에 존재함
- 얼굴만 계속 교체하는 AI portrait reel이 아님
- 창가 / 도시 / stage / microphone / hand / detail 등 장면 다양성
- 같은 인물을 여러 거리와 상황에서 다시 만남
- FIRST GLIMPSE와 NEXT MOMENT의 감정적 연결 가능
- Moment가 "사진 한 장"이 아니라 장면으로 읽힘
- Connection이 빛의 흐름으로 표현됨
- Memory Field → Tree로 확장되는 제품 의미가 보임

## 금지

기존 v1.1처럼:

```text
A 얼굴
→ B 얼굴
→ C 얼굴
→ D 얼굴
→ E 얼굴
→ F 얼굴
```

을 rapid montage라고 부르는 방식.

**이미지를 많이 교체하는 것 ≠ Moment가 많아지는 것.**

# 4. 캐릭터 규칙 — PRIMARY 1명 고정

## PRIMARY

이번 50번은 여성 PRIMARY 1명을 중심으로 한다.

모든 주요 solo Moment에서 같은 사람으로 인식되어야 한다.

필수 장면군:

- dark first glimpse
- distorted close
- city/night
- pink/intense
- white beauty
- stage
- interview
- backstage
- smile
- detail
- next moment
- final memory echo

이 장면들에서 얼굴 정체성이 유지되어야 한다.

## Secondary

같은 fictional group의 secondary 3~5명은 허용한다.

그러나 사용처는:

- group wide
- stage context
- backstage context

정도로 제한한다.

**solo rapid cut을 secondary 얼굴 릴레이로 채우지 않는다.**

# 5. 절대 기준 C — Supernova의 역할

Supernova는 **LoveTree 서사를 대신하지 않는다.**

Supernova에서 가져올 것은 연출 언어뿐이다.

## 가져올 것

- dark → vivid color → white의 강한 충돌
- close ↔ wide 거리 변화
- fisheye / distorted lens
- 빠른 micro-cut
- whip
- push
- pull
- scale shock
- flash
- 색온도 급변
- beauty hold ↔ rapid montage 대비
- 공간이 갑자기 열리고 닫히는 느낌
- 예측하기 어려운 컷 리듬
- 1~3초 안의 강한 hook

## 가져오지 않을 것

- Supernova에 도시가 나오니 의미 없이 도시 삽입
- fire가 나오니 fire portrait 삽입
- 여러 멤버 close가 나오니 랜덤 여성 close 교체
- group shot이 나오니 6인 사진 한 장
- wireframe title이 나오니 의미 없는 wireframe
- 원본 표면 요소를 체크리스트처럼 대응

# 6. 두 기준을 합치는 방식

## LoveTree가 "무엇을 말할지" 결정한다.

## Supernova가 "어떻게 보여줄지" 결정한다.

예:

### FIRST GLIMPSE
의미:
처음 마음이 멈춘 순간.

Supernova 문법:
- dark portrait
- abrupt close
- lens distortion
- low-key cyan

### DELICATE DETAIL
의미:
작은 행동까지 보고 싶어진 상태.

Supernova 문법:
- 0.1~0.4초 micro-cut
- hand / microphone / eye / accessory / movement
- flash cut

### CONNECTION
의미:
그 순간 때문에 다음 콘텐츠를 찾음.

Supernova 문법:
- light leak
- whip
- rapid push
- glowing line passes camera
- next scene opens from the trail

### TREE EMERGES
의미:
지금까지의 감정 경로가 구조로 드러남.

Supernova 문법:
- energy convergence
- flash
- pullback
- explosive scale reveal

# 7. 기존 첨부 콘티의 활용 규칙

제품 오너가 올린 두 종류의 자료를 서로 다른 목적으로 사용한다.

## A. 세로 LoveTree 콘티

`FIRST GLIMPSE → MEMORY BREATH → PERSON REVEAL → DELICATE DETAIL → SAVE THIS MOMENT → CONNECTION → NEXT MOMENT → MEMORY FIELD → TREE EMERGES → LOVETREE`

이것이 **SEMANTIC MASTER**다.

서사와 제품 의미는 이것을 따른다.

## B. Supernova Shot/Storyboard 보드

dark room / distorted close / object/detail / city / pink / street / white beauty / stage / interview / backstage / smile / hand / photo / live / light connection / tree bloom 등의 이미지 보드는

**VISUAL ASSET + CINEMATIC GRAMMAR MASTER**다.

장면 이미지 품질과 화면 강도는 이 수준을 기준으로 한다.

단, `6 female cast` 표시는 그대로 구현하는 명령이 아니다.

PRIMARY 1명 중심으로 재배치한다.

# 8. 이미지 제작 원칙

현재 잘 나온 콘티 이미지를 버리지 않는다.

사용 가능한 것은 실제 scene asset으로 활용하거나,
동일 수준의 새 scene asset 제작 기준으로 사용한다.

## 신규 이미지가 필요한 경우

단순 인물 portrait부터 만들지 않는다.

장면 단위로 만든다.

예:

- PRIMARY가 공연장 무대에서 빛을 받는 wide/medium
- 인터뷰 중 시선을 돌리는 PRIMARY
- backstage corridor를 걷는 PRIMARY
- 창문 앞의 PRIMARY
- microphone을 잡은 손
- necklace / outfit detail
- 공연 후 웃는 순간
- 도시 야간을 걷는 PRIMARY
- 같은 사람의 white beauty close

즉:

> **인물을 생성하는 것이 아니라 Moment scene을 생성한다.**

# 9. Motion 구현 규칙

기존 v1.1에서 사용한:

- background image `scale()`
- 단순 `translateX/Y`
- opacity
- hue rotate

만으로 장면을 움직이는 방식은 금지한다.

이것들은 보조효과로만 사용한다.

주된 운동은:

- multi-layer parallax
- foreground pass
- background depth
- camera push/pull
- lens warp
- dynamic crop
- depth mask
- light occlusion
- scene-to-scene morph
- connection trail
- flash reveal
- perspective shift

로 구성한다.

목표:

> **사진이 움직이는 느낌이 아니라, 장면 안의 카메라가 움직이는 느낌.**

# 10. 29초 전체 구조 권장

정확한 초는 Supernova 실제 cut rhythm에 맞춰 조정 가능하다.

## 0–3초
FIRST GLIMPSE

강한 hook.
PRIMARY 1명.

## 3–6초
MEMORY BREATH + PERSON REVEAL

같은 사람의 잔상 / distorted close / 새로운 시선.

## 6–10초
DELICATE DETAIL

손 / 마이크 / 의상 / 눈 / stage / 작은 행동.
빠른 micro-cut 허용.

## 10–12초
SAVE THIS MOMENT

첫 저장 사건.

## 12–16초
CONNECTION

왜 다음 영상을 찾아갔는지 보여주는 핵심 구간.
카메라가 빛의 경로를 따라 다음 Moment로 이동.

## 16–20초
NEXT MOMENT + DEEPENING

같은 PRIMARY의 다른 장면들:
Stage → Interview → Backstage → Smile 등.

## 20–24초
MEMORY FIELD

여러 Moment가 하나의 공간/경로로 쌓임.

카드 갤러리처럼 정렬하지 말 것.

## 24–27초
TREE EMERGES

앞의 Connection path가 실제 branch로 변환.

## 27–29초
LOVETREE

짧고 강한 완성 reveal.
