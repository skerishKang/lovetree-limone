# 8. '10 Moments'의 의미

현재 Gate 1처럼:

```text
같은 black hair
+ 같은 black outfit
+ 배경만 다르게
```

해서 10 Moments라고 부르지 않는다.

Moment마다 사용자의 감정이 달라질 수 있어야 한다.

예:

```text
First Glimpse — 처음 눈이 멈춤
Stage — 무대 실력이 예상보다 강함
Interview — 말투가 궁금해짐
Backstage — 무대 밖의 다른 면
Smile — 인간적인 매력
Detail — 작은 습관/손짓
Next Moment — 그래서 또 찾아봄
```

같은 사람이어도 **다른 이유로 마음이 움직이는 장면**이어야 한다.
