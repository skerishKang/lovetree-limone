# LoveTree 50 / 4-2기 — VIDEO MASTER APPROVED / CINEMATIC WEBSITE LAYER 완성지시

**문서 상태:** 대화 지시 복원본  
**선행:** Final Desktop/Mobile Supernova 영상 마스터 확보  

## 상태 정정

Final Master MP4가 완성되었다고 해서 시네마틱 홈페이지가 완성된 것은 아니다.

당시 상태를 명확히 분리한다.

- VIDEO MASTER = APPROVED / LOCK
- CINEMATIC WEBSITE = HOLD → 이번 지시로 완성

## 원칙

승인 영상은 재편집하지 않는다. 영상이 사이트의 시네마틱 핵심 자산이고, 그 위/주변에 실제 사이트 interaction layer를 추가한다.

## 사이트 필수 구조

### Top navigation

HOME / MY MOMENTS / MY TREE / ABOUT / SIGN IN

### Landing

- `PLAY THE STORY`
- `ENTER LOVETREE`

사용자가 사이트임을 즉시 이해해야 한다.

### Cinematic playback

- chapter timeline
- play/pause
- sound
- replay
- skip to bloom

### Save → Connection

- Save 버튼은 실제 동작
- Save 상태 전환
- Connection unlock이 시각적으로 읽힘

### Final

- Tree/LOVETREE climax 이후 `ENTER LOVETREE`
- `REPLAY`

## Responsive

Desktop과 Mobile 모두 실제 영상 master를 올바른 비율/크롭으로 사용한다. Mobile에서 Tree/title이 잘리지 않도록 한다.

## Main vs Standalone

### Main HTML

실제 package용. MP4/assets를 상대경로로 참조할 수 있다.

### Standalone HTML

제품 오너/메신저 검토용. HTML 하나만 열어도 영상과 핵심 asset이 보이도록 embed한다.

Standalone은 별도 디자인이 아니라 같은 사이트의 portable review variant다.
