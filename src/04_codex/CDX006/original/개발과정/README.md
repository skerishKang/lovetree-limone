# LoveTree 3D Experience Suite V1

세 개의 독립 실행형 로컬 웹 프로토타입과 통합 허브입니다.

## 실행

`index.html`을 열면 세 프로그램을 선택할 수 있습니다.

1. `01-memory-capsule.html` — 최애의 8방향 피규어를 캡슐 속에서 회전하고 색상·스티커·저장을 조작
2. `02-memory-stack.html` — 기억을 7개 레이어로 분해/조립하고 드래그·스크롤·자동 스토리 재생
3. `03-tree-keeper.html` — 오리지널 캐릭터 LUMI가 업로드→스캔→룩 선택→360° 제작→트리 개화를 안내

## 자산 원칙

- 인물은 기존 LoveTree Video Figure Atelier V2의 승인된 A–J 360° 자산만 사용했습니다.
- 외부 인물 사진이나 웹 이미지는 사용하지 않았습니다.
- LUMI는 실존 인물과 무관한 LoveTree 전용 오리지널 캐릭터입니다.
- 모든 페이지는 외부 라이브러리나 CDN 없이 로컬에서 실행됩니다.

## 프로토타입 범위

- Capsule과 Stack은 CSS 3D/perspective 기반의 실시간 브라우저 인터랙션입니다.
- Tree Keeper는 투명 3D 캐릭터 스프라이트를 이용한 2.5D 시네마틱 인터랙션입니다.
- 업로드 UI는 로컬 파일명을 받아 다음 단계로 진행하는 UX 프로토타입이며 실제 AI 영상 분석 백엔드는 포함하지 않습니다.
