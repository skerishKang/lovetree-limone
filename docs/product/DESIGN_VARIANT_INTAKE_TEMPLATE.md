# Design Variant Intake Template

This compatibility entry point remains for operators who were previously told to use a Variant-only intake template.

The canonical intake process now distinguishes both Scenario Variants and reusable cross-project Experience Capabilities.

Use:

`docs/product/DESIGN_VARIANT_AND_CAPABILITY_INTAKE_TEMPLATE.md`

Key rule: do not create a new V5/V6/V7 whole LoveTree product by default. Classify each new sibling artifact as a Scenario Variant, an Experience Capability contribution, both, reference-only, or history.
