## V2 source contract

The source header explicitly defines V2 as:

`V1 motion engine preserved + visible Connection skeleton + saturated energy + Living Tree climax`

The V1 engine remains the behavioral baseline. Source inspection confirms the following mechanics continue to exist:

- Moment perimeter/path pulse;
- Connection path travel;
- node arrival impact;
- `PLAY PATH`, `PAUSE`, `REPLAY`, and speed transport;
- `getTotalLength()` / `getPointAtLength()` path traversal;
- `ResizeObserver` geometry refresh;
- reduced-motion behavior;
- replay state API and replay-from-Moment behavior.

V2 adds or strengthens:

- an always-visible Connection skeleton;
- separate active outer bloom and active inner path;
- stronger cyan / violet / rose / gold saturation;
- stronger arrival core, halo, and wash response;
- persistent Connection memory trace;
- completed Living Tree glow/climax.
